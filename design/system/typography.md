# Typography

Use the existing system font stack with expressive but readable weights.

| Role | Size | Weight | Line height |
|---|---:|---:|---:|
| Display | 40px | 800 | 1.08 |
| Page title | 32px | 800 | 1.15 |
| Section title | 20px | 750 | 1.25 |
| Card title | 16px | 700 | 1.3 |
| Body | 15px | 450 | 1.5 |
| Secondary | 13px | 500 | 1.4 |
| Caption | 12px | 600 | 1.35 |
| Metric | 32px | 800 | 1 |
| Button | 14px | 700 | 1.2 |
| Label | 12px | 700 | 1.2 |

Use the CSS typography tokens and do not add arbitrary values such as `23px/750` for a standard role.
