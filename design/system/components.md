# Component primitives

Prefer existing shared/sandbox components before adding new ones. Canonical names are `BsAppShell`, `BsSidebar`, `BsTopbar`, `BsPageContainer`, `BsBentoGrid`, `BsBentoCard`, `BsCard`, `BsSurface`, `BsButton`, `BsIconButton`, `BsBadge`, `BsStatusBadge`, `BsInput`, `BsSearch`, `BsSelect`, `BsAvatar`, `BsProgress`, `BsMetric`, `BsSectionHeader`, `BsEmptyState`, `BsSkeleton`, `BsModal`, `BsTooltip`, `BsTabs` and `BsPageHeader`.

The current repository is Jinja/CSS rather than React. These names describe the component contract; implementation may remain in templates and shared CSS until a true shared component exists.
