# Canonical shell and bento grammar

Desktop uses a persistent left sidebar, a topbar and a constrained page container. The canonical bento grid is 12 columns on desktop, 8 on tablet and 4/single-column on mobile.

The reference grammar allows a hero to span 8 columns and a goal card 4 columns; metrics commonly span 3 columns each. These are reusable proportions, not a forced layout for every page.
