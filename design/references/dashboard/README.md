# BooStudy Dashboard — Golden Reference

STATUS: APPROVED

ROLE:

Этот dashboard является основным visual reference для product UI BooStudy. Он задаёт navigation, topbar, search placement, profile placement, notification placement, page shell, bento composition, card language, hierarchy, spacing rhythm, typography, radii, shadows and interaction character.

## Preserve

- левую desktop navigation и logo placement;
- search в верхней области;
- profile справа сверху и notifications рядом с profile;
- воздушную центральную область и bento card composition;
- отчётливое разделение карточек через gap, border, background и умеренную тень;
- визуальную иерархию, tactile interaction и мягкую светлую основу;
- semantic accents и Boo как premium 3D mascot.

## Do NOT blindly preserve

- конкретные данные, имена и числа;
- случайные decorative artifacts;
- generated-image inconsistencies;
- exact illustration contents.

Файл `golden-dashboard.png` — утверждённый reference mockup. Он ещё не является screenshot baseline для production implementation.
