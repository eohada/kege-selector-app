# BooStudy AI Lab — Sprint 10 report

## Результат

Sprint 10 добавляет проверяемые семейства синтетических Python-заданий и сохраняемые варианты, связанные с неизменяемыми версиями задания, рубрики и набора Code Judge. Все изменения и испытания выполнены в локальном workspace и изолированных SQLite-базах. Рабочая `instance/boostudy_dev.db` не мигрировалась и не использовалась тестами.

## Фактические прогоны

- Регрессия Sprint 3–10, AI Homework Studio, Rubric Builder и Code Judge: **117 passed, 1 skipped, 74 warnings**. Единственный пропуск — отдельно включаемый тест локального Runner; он затем был запущен и прошёл. Предупреждения — существующие предупреждения Flask/SQLAlchemy и `datetime.utcnow()`.
- После добавления второй межмодульной траектории оба параметризованных сценария прошли отдельно: **2 passed**; в итоговой регрессии они включены в число 117.
- Живой Runner + Code Judge + AI Homework: **1 passed** за 78.91 с. Два семейства, 10 запусков Runner и 50 исполненных тестовых случаев: **8 `accepted`** (эталон, альтернативы и привязанные Homework-запуски) и **2 `wrong_answer`** (контролируемые мутанты).
- AI Homework в этой интеграции использовал только синтетический провайдер: **2 синтетических completion**, **0 запросов GigaChat**.
- Отдельный рендер страницы семейства: **1 passed**.
- Изолированная миграция Sprint 9/10: успешно; проверка целостности SQLite `ok`, нарушений внешних ключей в тестовой базе нет.

## Ограничения

- Визуальная проверка desktop/mobile через браузер не выполнена; доступ к браузеру для этой задачи запрещён. Встроенная серверная отрисовка Jinja проверена, но она не заменяет визуальную приёмку.
- GigaChat не вызывался. Педагогический комментарий реальной модели и тарификация API этой серией не измерялись.
- Утверждение рубрики остаётся ручным. Автоматического создания или утверждения рубрик нет.
- Два генератора охватывают только указанные типы задач; для нового типа требуется добавить и версионировать доверенный генератор.
- Существующие human labels и результаты старых экспериментов не изменялись.
- Проблемы целостности исходной локальной БД не исправлялись. До Sprint 10 на read-only диагностике были обнаружены 159 нарушений FK в шести таблицах; причина и точный ущерб без исторического snapshot не устанавливаются. Данные не выгружались в отчёт.
