# BooStudy AI Lab Sprint 4 — демо-сценарий

## Запуск изолированного preview

В корне проекта выполните:

```powershell
python scripts/run_ai_lab_sprint4_preview.py
```

Preview слушает только `127.0.0.1:5058` и создаёт SQLite базу в памяти. По умолчанию используется локальный mock-провайдер. Для явного живого R&D-запуска GigaChat установите `AI_LAB_SPRINT4_LIVE_GIGACHAT=1`; серверный конфиг GigaChat должен быть настроен заранее. Реальный GigaChat расходует тарифную квоту. Не помещайте реальные данные учеников в синтетические формы.

Войдите администратором и откройте **AI Lab**.

## Сценарий AI Course

1. Откройте **Курс** и выберите синтетический пример с отсутствующим материалом и несогласованными prerequisite.
2. Запустите анализ. Сверьте структурные замечания и предложения модели с карточками исходных разделов и заданий.
3. Примите одно предложение и отклоните другое. Откройте историю: решения должны быть видны, исходный курс остаётся неизменным.
4. Откройте Practice, выберите сохранённый снимок Course и убедитесь, что каталог ограничен явно связанными темами. При отсутствии подтверждённых prerequisite рекомендация должна быть скрыта.

## Сценарий AI Lesson

1. Откройте **Урок** и выберите пример про граничное значение `x = 0`.
2. Запустите обработку текста. Проверьте, что темы и возможная трудность ссылаются на конкретный сегмент, а Speaker и timestamp не выдуманы.
3. Подтвердите одно наблюдение вручную. Откройте Analytics для синтетического профиля и проверьте, что оно отображается как качественное свидетельство без числового балла.
4. Попробуйте подтвердить другое наблюдение только после просмотра основания. Отправка только исходного вопроса или сомнения не должна автоматически превращаться в подтверждённую трудность.

## Границы демо

Все действия относятся только к локальным синтетическим данным. AI-предложения и наблюдения требуют ручного решения. Демо не подключает активные курсы и реальные работы, не запускает ASR и не меняет настройки Docker Runner. Остановка процесса уничтожает состояние in-memory preview.
