# BooStudy AI Lab Sprint 8 — демонстрация

Демонстрация выполняется локально на синтетических и уже сохранённых regression cases. Новые генерации модели не нужны; не запускайте эти сценарии с реальными работами учеников.

## 1. Homework: балл отдельно от комментария

1. Откройте локальную AI Homework Studio и выберите сохранённый синтетический сценарий, связанный с Code Judge.
2. Покажите результат детерминированной проверки и баллы по критериям отдельно от педагогического комментария.
3. На regression case с корректной альтернативной чётностью `n & 1` проверьте, что корректное решение не отвергается только за отличие от ожидаемой формы.
4. На case с условием `n > 0` проверьте, что рекомендация не требует заменить его на более широкое `n >= 0` без основания.
5. Для несогласованного комментария покажите отдельный статус конфликта и ручной эскалации. Числовой балл Code Judge при этом остаётся неизменным.

Если в конфигурации включена проверка предложенного исправления, допускается только один полный Python-фрагмент для связанного завершённого запуска. Итог содержит агрегат проверок, а не скрытые тесты или их входы/ожидаемые ответы.

## 2. Quality Review: Homework, Course, Lesson

Откройте `/admin/ai-lab/quality-review` с локальной административной учётной записью и выберите модуль и сохранённый случай. Для Homework сравните ожидаемый и предложенный баллы, распределение критериев, ошибки и доказательства. Для Course прочитайте исходный материал рядом с предложением и ссылками. Для Lesson проверьте выводы по репликам, включая вопрос, гипотезу и позднее разрешение затруднения.

Сырой JSON доступен в свёрнутом разделе. Метка эксперта появляется только после ручного выбора и сохранения; ничего не предзаполнено. Уже существующие 22 ответа Sprint 6–7 остаются неизменными.

## 3. Автоматическая регрессия

Для локальной проверки запускаются unit suites Sprint 3, 4, 6, 7 и 8. В отчёте Sprint 8 это дало 65 passed и 37 warnings. Эти результаты подтверждают кодовые инварианты и regressions, но не заменяют независимую содержательную оценку человека и не включают live generation.

## 4. Визуальная проверка

В этом запуске браузерная проверка не выполнена: доступ к текущей вкладке был отклонён browser policy. Не используйте обход через другой браузерный API, CDP или прямое извлечение содержимого страницы. Для завершения visual QA нужно повторить показ после того, как политика браузера разрешит доступ к текущей локальной вкладке.
