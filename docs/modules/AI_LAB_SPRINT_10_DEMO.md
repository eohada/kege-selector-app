# BooStudy AI Lab Sprint 10 — локальная демонстрация

Демонстрация использует только синтетические задания и отдельную AI Lab SQLite-базу с миграциями Sprint 9 и Sprint 10. Не направляйте её на `instance/boostudy_dev.db` или базу с реальными работами учеников.

## Предварительные условия

1. Запустить локальный AI Lab backend с отдельной SQLite-базой.
2. Применить к этой базе миграции Sprint 9 и Sprint 10.
3. В Code Judge убедиться, что loopback Runner готов и подтвердил полный профиль изоляции.
4. Создать и вручную утвердить рубрику, точно связанную с одной из двух базовых версий задания.
5. Сохранить набор тестов Code Judge с тем же assignment ID/version и запустить эталонный код до статуса `accepted`.

Готовые синтетические базовые наборы:

| Задание | Стабильный ID | Набор по умолчанию |
|---|---|---|
| Подсчёт кратных чисел на отрезке | `ai-lab.python.divisibility-count` v1 | `lower_bound=0`, `upper_bound=100`, `divisor=3` |
| Удаление выбранного символа | `ai-lab.python.remove-character` v1 | `target_character=a`, `max_length=80` |

## Сценарий

1. Откройте `/admin/ai-lab/assignment-families` на изолированной базе.
2. Выберите доверенный тип семейства. Сверьте точный ID задания, утверждённую рубрику, сохранённый тестовый набор и принятый эталонный запуск.
3. Сохраните черновик. Нажмите «Проверить связи» и убедитесь, что статус стал `verified`.
4. Нажмите «Утвердить вручную». Семейство должно перейти в `approved`; автоматического утверждения нет.
5. Раскройте форму параметров. Создайте вариант с параметрами по умолчанию. Ожидается последовательная проверка эталона, альтернативы и мутанта.
6. Убедитесь, что статус стал `available`, первые два решения приняты, мутант отклонён. Сравните ID набора и его версию в карточке варианта.
7. Измените параметры и создайте второй вариант. Он должен иметь отдельный стабильный ID, снимок и хеш.
8. Откройте Code Judge и завершите проверку кода для выбранного варианта. В AI Homework Studio выберите соответствующий сценарий и передайте ID завершённого запуска Code Judge.
9. В AI Homework проверьте блок `Criterion Evidence Report`: точную привязку к варианту, тестовому набору и версии; педагогический ответ модели не должен менять факты исполнения.
10. Обновите страницу и повторно откройте историю. Материализованный вариант и результаты должны остаться доступными.

## Ограничения демонстрации

- Тестовые случаи конечны и не доказывают корректность на всех входах.
- Скрытые случаи не включаются в выдаваемый список сценариев и очищаются из Code Judge отчёта перед запросом модели.
- Проверка AI Homework в интеграционном тесте выполняется синтетическим провайдером; этот документ не подтверждает живой вызов GigaChat.
- Страница проверена серверным рендером Jinja. Desktop/mobile браузерная приёмка остаётся ручным шагом.
