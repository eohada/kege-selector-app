# BooStudy AI Lab — Sprint 7.0: отчёт

Дата: 20 октября 2026. Область: локальная AI Lab, только синтетические данные. Реальные домашние работы, ученики, production и профиль Docker Runner не менялись. Ни один результат Sprint 6 не исправлялся задним числом.

## A. Причина четырёх противоречий Homework Sprint 6

Проверены четыре полных сохранённых запроса и ответа из исходного JSONL и локальной SQLite Sprint 6. Во всех четырёх обвязка выбрала `py-arithmetic-02` (`short_answer`) для Python-кода. Поэтому backend сравнил исходник функции с кратким текстовым ответом и передал модели ложный `verified_deterministic_check` с нулём. Code Judge в этих вызовах не участвовал. Одновременно адаптер сформировал строки критериев вида «`sum_digits: …, максимум 2 балл(а)`», тогда как парсер ожидает числовой вес в начале «`2 балла — …`». В структурированном `scoring_criteria` у всех критериев оказался `max_score: null`. Модель отвечала `insufficient_data` без балла, объясняя недостаток весов. Обвязка режима `short_answer` затем переводила ответ в `checked` с нулём, оставляя причину недостаточности данных. Вторая семантическая проверка верно заблокировала противоречие и отправила все четыре случая на `manual_review`.

Исправление для новой серии: использованы стабильное Python-задание `ai-lab.python.classify` v1, его четыре числовых критерия, сохранённый набор Code Judge и раздельные режимы AI-only/Hybrid. Добавлена отдельная инструкция Homework v2 с явным контрактом балла, критериев и ограничений доказательств; исходная v1 не изменена. При открытии локальной Studio v2 создаётся как новая сохранённая версия один раз. Семантический валидатор не ослаблен.

## B. Парное сравнение AI-only, Code Judge и Hybrid

Заморожены четыре решения `classify(n)`, по два вызова с одинаковым кодом и критериями. AI-only не получал `verified_code_judge_report`; Hybrid получал подтверждённый отчёт, из которого удалены скрытые входы, ожидаемые ответы и даже маркеры скрытых case ID. Проверено по сохранённым фактическим provider payload: размеры user message около 1.4 КБ против 5.2 КБ; авторизационного секрета в payload нет. Вызовы были последовательными, по одному на case ID, без автоматического повтора.

| Решение | Эталон / Judge | Сырой AI-only | Результат защитного слоя AI-only | Сырой Hybrid | Результат защитного слоя Hybrid |
|---|---:|---:|---|---:|---|
| Корректный альтернативный алгоритм | 4/4 | 3/4 | Балл скрыт, manual review | 4/4 | 4/4, checked |
| Частичная ошибка чётности | 3/4 | 2/4 | Балл скрыт, manual review | 3/4 | 3/4, partially checked |
| Несколько независимых ошибок | 1/4 | 1/4 | 1/4, но manual review | 2/4 при сумме критериев 1 | Балл скрыт, manual review |
| Ошибка на границе нуля | 3/4 | 2/4 | Балл скрыт, manual review | 3/4 | 3/4, partially checked |

По **сырым числовым ответам на этих четырёх известных development/regression cases** совпадение итогового балла: AI-only 1/4, Hybrid 3/4. Баллы по отдельным критериям в фиксированном порядке: AI-only 13/16, Hybrid 16/16. Это техническое сравнение с заранее записанным эталоном, а не независимая оценка качества педагогических объяснений. Guard принял без ручной эскалации 0/4 AI-only и 3/4 Hybrid. Code Judge получил 4/4 ожидаемых распределений. В четвёртом Hybrid модель противоречила собственной сумме критериев; guard верно остановил публикацию оценки. Итог 3/4 Hybrid частично обязан авторитету Judge и **не** доказывает, что модель сама научилась оценивать лучше.

## D. AI Course, AI Lesson и последующие сигналы

Course v5 уточнил, что структурная ошибка порядка тем не должна попадать в `material_proposals`. Из двух новых реальных ответов оба прошли прежнюю структурную проверку, но ответ о порядке тем снова содержал две текстовые «правки», фактически предлагавшие перестановку структуры. Это подтверждённая слабость: существующая проверка source ref удостоверяла наличие фрагмента, но не смысловую связь предложения с ним. После сохранения исходного ответа добавлена узкая серверная защита: если при обнаруженном нарушении порядка модель предлагает переставить темы через правку материала, ответ отклоняется с понятной причиной и требует ручной проверки. Регрессионный тест использует неизменённый реальный ответ; дополнительный запрос к модели не выполнялся. Обычное предложение о содержании материала по другому case остаётся допустимым. Общая достоверность текстовых предложений всё ещё требует человека.

Lesson: два вызова структурно валидны. В случае позднее исправленной ошибки итоговый `observed_difficulties` пуст; текущая проблема не была создана. Явное затруднение сохраняется как AI inference до ручного подтверждения. Числовые оценки из транскрипта не выставляются. Длинные chunks, восстановление после сбоя, source refs, отсутствие вымышленных speaker/timestamp и дедупликация событий покрыты регрессией Sprint 4/6; новая независимая содержательная экспертиза двух ответов ещё ожидается. Analytics и Practice продолжают принимать подтверждённые сигналы отдельно от неподтверждённых выводов и не назначают практику по одному вопросу.

## E. Каталог GigaChat

Ошибка браузера была `response_timeout`, но сетевой стек показывал таймаут во время TLS handshake к Windows system proxy `127.0.0.1:2080` (локальный ThroneCore). Он происходил примерно через 20 секунд connect timeout; API не успевал получить запрос. Прямое соединение с тем же CA bundle устанавливало проверенный TLS за доли секунды. Исправление относится только к GigaChat: `_send` по умолчанию обходится без системного proxy, передаёт существующий CA bundle в `verify`; при явном `GIGACHAT_USE_SYSTEM_PROXY=true` системный proxy возвращается. Глобальные сертификаты и другие интеграции не менялись.

После перезапуска локального backend в браузере нажата «Загрузить модели»: зафиксированы статус «GigaChat: Подключено», шесть моделей, включая GigaChat-3-Pro, и «TLS проверен». До фактической проверки Studio показывает «Не проверено». Отдельный тест проверяет параметры `verify`, proxy и timeout без отключения TLS.

## I. Долг и решение о готовности

- **P0:** Независимых экспертных оценок нет. Без них нельзя объявлять педагогическое качество или production readiness.
- **P1:** AI-only ошибся в 3/4 сырых баллов; Hybrid противоречил собственной сумме в 1/4. Нужна новая серия на нераскрытом контрольном наборе после отдельного утверждения протокола и бюджета.
- **P1:** Course v5 не удержал модель от структурной правки; серверный guard закрывает подтверждённый шаблон, но не все возможные необоснованные содержательные утверждения.
- **P2:** Quality Review длинный на мобильном экране; возможно добавить компактное сворачивание технических секций после реальной работы эксперта.

Sprint 7 улучшил воспроизводимость и защиту, но не доказал педагогическую надёжность модели. Следующий шаг — человеческая разметка сохранённых 22 ответов, без новых генераций и без изменения контрольных записей.
