# BooStudy AI Lab — Sprint 8.0: отчёт

Дата: 20 октября 2026. Область: локальная AI Lab и синтетические/regression данные. Реальные ученики, домашние работы, production, GigaChat credentials и профиль Docker Runner не менялись. Сохранённые ответы Sprint 6–7 и их fixtures не исправлялись задним числом; новые запросы к модели не выполнялись.

## Результат

Спринт укрепляет разделение между детерминированным баллом, педагогическим комментарием модели и подтверждениями, которые действительно даёт Code Judge. Решение по баллам Code Judge остаётся источником фактов; GigaChat формирует объяснение и не может незаметно изменить результаты исполнения. Несогласованный комментарий блокируется отдельно от корректного балла и требует ручной проверки.

### Проверенные направления

| Направление | Статус и границы |
|---|---|
| Homework | Добавлена проверка согласованности комментария с критериями и публичными подтверждениями. Отдельно обрабатываются регрессии для альтернативы `n & 1` в Python и условия `n > 0`/`n >= 0`. Балл Code Judge сохраняется при конфликте текста; комментарий получает `conflict_blocked`. |
| Код-коррекция | Один полный предложенный фрагмент Python можно проверить только при наличии связанного, принадлежащего тому же автору завершённого запуска и неизменённого снимка задания. Исполнение идёт через существующий изолированный Runner. В отчёт возвращается только агрегат pass/total и хеш кода; детали скрытых тестов не раскрываются. Проверка конечным набором тестов подтверждает только эти тесты, не универсальную корректность. |
| Course | В Quality Review добавлен просмотр исходного материала, предложения, ссылок и основания. Наличие ссылки не считается доказательством смысловой корректности предложения; содержательная проверка остаётся за преподавателем. |
| Lesson | Экспертный просмотр показывает реплики и соответствующие выводы. Регрессии проверяют, что вопрос сам по себе не считается доказанным затруднением, а позднее устранение сохраняется при объединении фрагментов. |
| Quality Review | Результаты Homework/Course/Lesson представлены в читаемом виде; сравнение критериев и конфликтов вынесено вперёд, исходный JSON свёрнут. Разметка остаётся явным действием эксперта и не заполняется автоматически. |

## Защитное поведение Homework

В структурированных ошибках поддерживаются необязательные `criterion_id` и `evidence_refs`. Проверка связывает ссылки с доступными подтверждениями, проверяет соответствие статуса критерию и выявляет неподтверждённые обобщения вроде «все тесты прошли». Это многосигнальная проверка: используются структурированные критерии, отчёт Code Judge и текстовые утверждения; она не полагается только на фильтр ключевых слов.

При обнаружении конфликта допускается один контролируемый повтор в пределах существующего лимита попыток с описанием проблемы. Если конфликт остался, оценка Code Judge не подменяется, конфликтный комментарий не выдаётся как проверенный и требуется ручное решение. Статусы балла и комментария хранятся и показываются отдельно.

## Испытания и метрики

Команда регрессионной проверки: Sprint 3, 4, 6, 7 и 8 unit suites. Результат: **65 passed, 37 warnings** за 68,86 секунды. Дополнительно прошли `py_compile` для изменённых Python-модулей и `git diff --check` для изменённых файлов.

Новые regression cases используют только сохранённые данные Sprint 7 и контролируемые заглушки Runner; живой генерации GigaChat и исполнения произвольного кода вне Runner не было. Браузерная визуальная проверка не завершена: инструмент браузера отказал в доступе к вкладке по политике URL, и это ограничение не обходилось альтернативным браузерным каналом. Поэтому корректность шаблонов подтверждена тестами, но геометрия desktop/mobile в живом браузере в этом спринте не утверждается.

Человеческие экспертные метки не добавлялись. На основании этих автоматических регрессий нельзя заявлять процент педагогической точности, улучшение качества рекомендаций или готовность к production. Число независимых человеческих оценок для каждого аспекта остаётся **n=0**; это «не измерено», а не нулевое качество.

## Остаточные ограничения

- Смысловую правдивость объяснения, релевантность темы для повторения и педагогическую уместность всё ещё должен оценить человек.
- Строковая проверка выявляет ограниченный набор явных конфликтов и не является полной моделью естественного языка.
- Конечный набор запусков Code Judge не доказывает корректность для всех входов.
- Кандидат-код можно проверить только для связанного доступного снимка тестов; иначе результат должен оставаться неподтверждённым.
- Визуальная проверка страницы в браузере не состоялась по причине блокировки доступа.
