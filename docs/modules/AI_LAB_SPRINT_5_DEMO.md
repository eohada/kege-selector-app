# BooStudy AI Lab Sprint 5 — локальная демонстрация

Демонстрация использует отдельный локальный SQLite файл в `%TEMP%` и синтетическую учётную запись администратора. Она не подключает production, реальные домашние работы, данные учеников, Docker Runner, LiveKit или Telegram.

## Запуск

В PowerShell из корня репозитория:

```powershell
$env:PYTHONPATH = (Get-Location).Path
$env:AI_LAB_SPRINT5_PREVIEW_DB = Join-Path $env:TEMP 'boostudy-ai-lab-sprint5-preview.sqlite'
$env:SECRET_KEY = 'sprint5-isolated-preview-session-key'
python scripts/run_ai_lab_sprint5_preview.py
```

По умолчанию preview использует локальный синтетический provider. Он не выполняет платных или внешних model-запросов. Для явно разрешённого R&D с настроенными GigaChat credentials процесс можно запустить с `$env:AI_LAB_SPRINT5_LIVE_GIGACHAT = '1'`; сначала проверьте, что выбран только синтетический sample. Ключи остаются на backend и не включаются в UI или payload эксперимента.

Локальный адрес: `http://localhost:5058`. Вход синтетического preview: `sprint5-preview-admin` / `preview-only`.

## Сценарии

### AI Course

1. Откройте `/admin/ai-lab/course`.
2. Выберите «Python: курс с проверяемыми структурными пробелами».
3. Запустите анализ. Структурные находки рассчитываются детерминированно; AI-предложения сохраняются как черновики с точными ссылками на версии и фрагменты.
4. Ручное принятие предложения меняет только локальную историю AI Lab и не редактирует исходный master-course.

Изменённый материал требует новой `course_version`. Каждая часть курса ограничена конфигурацией chunk-размера и максимального количества chunks.

### AI Lesson

1. Откройте `/admin/ai-lab/lesson-intelligence`.
2. Выберите «Явное затруднение с условием» и оставьте отметку, что текст синтетический.
3. Запустите анализ. Предварительное наблюдение должно ссылаться на сегмент транскрипта.
4. Подтвердите, отклоните или отметьте исправленным выбранные наблюдения. Ручное решение применяется только к локальной синтетической истории.

Повтор одинакового `lesson_id` и версии не запускает генерацию повторно. Изменение содержимого требует новой `lesson_version`.

## Хранение и конфигурация

Укажите другой `AI_LAB_SPRINT5_PREVIEW_DB`, чтобы создать отдельную базу для каждого набора экспериментов. Файл намеренно не удаляется по завершении процесса: это позволяет проверить историю после обычного перезапуска preview backend.

Размер Course/Lesson chunks, максимальное число частей, очередь GigaChat, таймаут, лимит попыток и lease настраиваются через AI Lab env-настройки в `app/ai_lab/config.py` и `app/ai_lab/provider.py`. Исполнение остаётся последовательным через общий процессный GigaChat queue. Все тестовые программы Code Judge по-прежнему исполняются только действующим sandbox runner.

## Что считать результатом

- Fake-provider preview подтверждает интеграцию страниц и сохранение истории, но не качество реальной модели.
- Live GigaChat результат помечен используемой версией prompt, моделью, usage, параметрами и payload hash.
- Ошибка источника сохраняется как `invalid_response` и не превращается в успешное предложение.
- Любое Lesson-наблюдение требует ручного подтверждения и не является самостоятельной оценкой ученика.
