# Доступ к диагностике

## URL для диагностики

После авторизации в системе откройте:

- **Production**: `https://boostudy.ru/admin/diagnostics`
- **Sandbox**: `https://boostudy.ru/admin/diagnostics`

## Требования

- ✅ Требуется авторизация (любой авторизованный пользователь)
- ❌ Не требуется роль "Создатель" (доступно всем)

## Альтернативный доступ

### Через админ-панель

1. Войдите в систему
2. Откройте админ-панель (только для создателей): `/admin`
3. В разделе "Быстрые действия" нажмите "🔍 Диагностика окружения"

### Прямая ссылка

Если вы авторизованы, просто откройте:
```
/admin/diagnostics
```

### JSON API

Для программного доступа:
```
/admin/diagnostics/api
```

Возвращает JSON с диагностической информацией.

## Если страница не открывается

### Проблема: 404 Not Found

**Причина**: Endpoint не зарегистрирован или неправильный URL

**Решение**:
1. Проверьте, что вы авторизованы
2. Убедитесь, что используете правильный URL: `/admin/diagnostics`
3. Проверьте логи Railway на наличие ошибок

### Проблема: 403 Forbidden или редирект на логин

**Причина**: Не авторизованы

**Решение**:
1. Войдите в систему через `/login`
2. После входа откройте `/admin/diagnostics`

### Проблема: 500 Internal Server Error

**Причина**: Ошибка в коде диагностики

**Решение**:
1. Проверьте логи Railway
2. Убедитесь, что база данных доступна
3. Проверьте переменные окружения

## Проверка доступности

Чтобы проверить, что диагностика работает:

1. Войдите в систему
2. Откройте консоль браузера (F12)
3. Перейдите на `/admin/diagnostics`
4. Если есть ошибки - они будут в консоли

## Отладка

Если диагностика не работает, проверьте:

1. **Логи Railway**:
   - Откройте проект в Railway
   - Deployments → последний деплой
   - Просмотрите логи запуска

2. **Проверка endpoint**:
   ```bash
   # Через Railway CLI
   railway run python -c "from app import create_app; app = create_app(); print([r.rule for r in app.url_map.iter_rules() if 'diagnostics' in r.rule])"
   ```

3. **Проверка импортов**:
   ```bash
   railway run python -c "from app.admin import diagnostics; print('OK')"
   ```
