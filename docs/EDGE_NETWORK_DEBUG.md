# Как проверить API в Microsoft Edge

## Открыть вкладку Network (Сеть)

1. Нажмите **F12** (или правый клик → «Проверить элемент»)
2. Перейдите на вкладку **Сеть** (или **Network**)
3. Обновите страницу (**Ctrl+Shift+R** — жёсткое обновление)

## Посмотреть ответ API

1. Откройте страницу «Решения заданий»
2. Нажмите на любое задание в списке
3. Во вкладке «Сеть» найдите запрос `task-solutions` и число (например `task-solutions/1`)
4. Кликните по нему
5. Справа откроется панель — нажмите **«Ответ»** (Payload)
6. В ответе должно быть поле `_api_version`: `"2025-02-rev2"` — если новая версия
7. Если поля нет — на сервере всё ещё старый код

## Индикатор на странице

Если видите надпись **«API: старая версия — обновите сервер с данными»** — это значит, что сервер, на который указывает окружение (PRODUCTION_URL), возвращает ответ без `_api_version`. Нужно обновить и перезапустить именно тот сервер.
