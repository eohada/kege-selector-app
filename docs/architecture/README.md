# Архитектура

Этот раздел описывает текущее устройство системы на уровне подсистем и связей между ними.

## Файлы раздела

- [system-overview.md](system-overview.md) — основной архитектурный обзор проекта.

## Когда использовать этот раздел

- при онбординге нового разработчика;
- перед изменениями в `app/__init__.py`, `core/db_models.py` и крупных blueprint-модулях;
- при планировании декомпозиции монолита или отделения подсистем;
- когда нужно понять, что является канонической архитектурой, а что legacy/side-service.
