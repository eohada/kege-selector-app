# Теория ЕГЭ по информатике: локальная проверка и перенос

Пакет курса находится в `data/theory/ege_informatics_curriculum.json`. Это не шаблон страницы и не набор случайных демонстрационных записей: в нём две группы — «Введение в программирование» (8 блоков) и «Теория по заданиям ЕГЭ №1–27» (27 блоков). Каждый блок содержит цель, подробное объяснение, алгоритм, практику, типовые ошибки и серверные `CHECKPOINT`-проверки. При загрузке пакет дополняется предметной лабораторией каждой темы: примером, действием ученика, критерием результата и тематическим checkpoint-вопросом.

## Проверка пакета без изменения БД

```powershell
venv\Scripts\python.exe scripts/import_theory_curriculum.py --course-id 1 --validate-only
```

Команда проверяет схему JSON, наличие обеих групп, все номера 1–27 и минимальный объём каждого блока.

## Импорт в локальный курс

Сначала найдите ID курса в BooStudy или в таблице `ExamCourses`, затем выполните:

```powershell
venv\Scripts\python.exe scripts/import_theory_curriculum.py --course-id <ID> --author-username creator --publish
```

Без `--publish` блоки импортируются как черновики. Повторный импорт безопасен: группы и блоки обновляются по курсу и номеру задания, а ID уже существующих блоков и ученические состояния сохраняются.

## Проверка в браузере

1. Откройте `/theory` под преподавателем и убедитесь, что видны две группы и темы 1–27.
2. Откройте любую тему через `/theory/topic/<block_id>` под учеником.
3. Пройдите checkpoint: неверный ответ показывает объяснение и разрешает повтор, верный сохраняет попытку.
4. Прокрутите материал, обновите страницу и проверьте процент и последнюю позицию.
5. Поставьте закладку, сохраните заметку, оценку и комментарий обратной связи.
6. Нажмите «Отметить изученной» и проверьте, что тема закрыта в каталоге и видна преподавателю в статистике.

## Экспорт для сервера

```powershell
venv\Scripts\python.exe scripts/export_theory_curriculum.py --course-id <ID> --output .\ege_informatics_export.json
```

Полученный JSON переносится на сервер вместе с релизом. На сервере выполняется та же команда импорта с `--file`:

```bash
python scripts/import_theory_curriculum.py --course-id <ID> --file /opt/boostudy/ege_informatics_export.json --author-username creator --publish
```

Импорт не требует ручного редактирования HTML или legacy-маршрутов. Перед публикацией на production сначала выполняется `--validate-only`, затем импорт в нужный `ExamCourses.id`.
