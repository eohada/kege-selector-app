# План: выдача и сдача заданий (релизная версия)

## Текущее состояние

- **Комната урока** (`lesson_homework.html`): переключатель форматов «ДЗ» / «КР» / «Провер.» в шапке и вкладка «Домашнее задание / Классная работа / Проверочная» с задачами из `LessonTask` (привязка к уроку, без единого дедлайна/попыток по работе).
- **Раздел «Задания»** (`assignments`): модель `Assignment` (дедлайн, тип, урок опционально), `Submission`, `Answer`; страницы списка сдач, выполнения работы, проверки, комментарии. Частично используется параллельно с «ДЗ/КР» в уроке.

## Цель

1. Убрать вкладки ДЗ/КР из комнаты урока — все задания на дом выдавать и сдавать через **«Задания»**.
2. В «Задания»: дедлайн, попытки, комментарии, итоговая оценка — довести до удобного релизного вида.
3. Для ученика: **редактор кода** в задании (писать код, запускать, сохранять; учитель видит после сдачи).
4. Для ученика: **рисование поверх экрана/задания** (вкл/выкл), сохранение и доступ к своим рисункам.

---

## Фаза 1: Убрать ДЗ/КР из комнаты урока

- Удалить из шапки урока переключатель форматов (кнопки «ДЗ», «КР», «Провер.»).
- Убрать вкладку «Домашнее задание / Классная работа / Проверочная» из комнаты урока (или заменить на одну кнопку «Перейти к заданиям»).
- Оставить в комнате урока: Конспект, Материалы, Заметки, Диалог, Доска, Звонок.
- Маршруты `lesson_homework_view`, `lesson_classwork_view`, `lesson_exam_view`: оставить один общий вход в комнату урока (например только `lesson_view`) или редирект на него; ссылки «на ДЗ этого урока» вести в раздел «Задания» (фильтр по уроку) или на создание/просмотр работы.

**Решено:** Да — кнопка «Создать домашнее задание» из карточки урока / при добавлении урока (переход в Задания с `lesson_id`).

**Важно:** Из комнаты урока **убираем только ДЗ и Проверочную**. **Классная работа (КР) остаётся** — вкладка с заданиями в уроке только для совместной работы в классе. В шапке оставляем одну вкладку «Классная работа» (без переключателя ДЗ | КР | Провер.).

## Фаза 2: Задания — дедлайн, попытки, комментарии, оценка

- **Дедлайн:** уже есть в `Assignment.deadline`, `hard_deadline`. Проверить отображение и редактирование в формах создания/редактирования работы и на странице сдачи.
- **Попытки:** та же система, что в уроке (Lesson): по умолчанию 1 попытка; настраивается **на всю работу** (`Assignment.max_attempts_default`) и **по заданиям** (`AssignmentTask.max_attempts`). Добавить поля в модель, миграцию, UI редактирования и проверку при сдаче.
- **Комментарии:** уже есть `SubmissionComment`. Убедиться, что учитель и ученик могут оставлять комментарии к сдаче и видеть их в одном месте.
- **Итоговая оценка:** выставить и сохранить в `Submission` (total_score, max_score, teacher_feedback), отобразить ученику и в журнале.

Довести сценарии «создать работу → назначить → ученик сдаёт → учитель проверяет, ставит оценку, пишет комментарий» до стабильного релизного вида.

## Фаза 3: Редактор кода в задании

- В интерфейсе выполнения задания (submission_view): для заданий, где нужен код (например по номерам КЕГЭ с программой), показывать **редактор кода** (Monaco/CodeMirror или простой textarea с подсветкой).
- Ученик: пишет код, нажимает **«Запустить»** — выполнение на бэкенде (песочница/ограниченный runner) или только сохранение без запуска в MVP.
- **Сохранять** код в ответе (в `Answer.value` или отдельное поле/вложение), чтобы после сдачи учитель видел сохранённый код.

**Решено:** Запуск обязателен (песочница на бэкенде). Редактор показывать **везде**, но по умолчанию **аккуратно скрыт** — ученик может открыть по желанию (раскрывающийся блок).

---

## Фаза 4: Рисование поверх задания

- Режим **«Рисовать»**: ученик может включить/выключить overlay с холстом поверх страницы/задания.
- Рисование: перо/карандаш, цвет, ластик (при необходимости), очистка.
- **Сохранение:** отправить рисунок(и) на сервер и привязать к сдаче (например к `Submission` или к конкретному `Answer` — один общий холст на работу или по одному на задание).
- После сдачи ученик и учитель могут **просматривать** сохранённые рисунки.

**Решено:** Один общий холст на всю работу. Хранение: файл PNG в хранилище, путь в БД (к сдаче).

## Порядок работ и коммиты

1. **Фаза 1** — правки в шаблонах и маршрутах урока, редиректы/ссылки на «Задания». Коммит: `refactor(lessons): remove ДЗ/КР tabs from lesson room, homework via Assignments`.
2. **Фаза 2** — доработка UI/API заданий (дедлайн, попытки, комментарии, оценка). Коммит: `feat(assignments): deadline, attempts, comments, grading release-ready`.
3. **Фаза 3** — редактор кода в задании, сохранение (и при необходимости запуск). Коммит: `feat(assignments): code editor and run/save per task`.
4. **Фаза 4** — рисование поверх задания, сохранение и просмотр. Коммит: `feat(assignments): drawing overlay, save and view`.
5. После каждой фазы — пуш в репозиторий.
