# Audit

Этот раздел фиксирует результаты аудита документации и структуры репозитория без агрессивной очистки и удаления файлов.

## Что уже сделано

- выстроена новая каноническая навигация по docs;
- обновлены верхнеуровневые structural документы;
- вынесены отдельные разделы по архитектуре, setup, operations и modules;
- зафиксированы противоречия и cleanup-кандидаты.

## Файлы раздела

- [docs-health.md](docs-health.md) — где документация устарела, противоречит коду или требует осторожности.
- [cleanup-register.md](cleanup-register.md) — безопасный реестр кандидатов на перенос, архивирование и возможную очистку.

## Принцип этого аудита

- ничего не удалять без отдельного подтверждения;
- сначала обозначить канонические документы;
- затем инвентаризировать шум, legacy и дубли;
- только после этого принимать решения о переносе или удалении.
