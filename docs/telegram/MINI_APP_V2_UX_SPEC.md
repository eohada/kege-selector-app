# BooStudy Telegram Mini App V2 — UX & UI Спецификация

**Версия документа:** 2.0.0  
**Статус:** Утверждено  
**Основа:** BooStudy UI Canon, Telegram WebApp Guidelines  

---

## 1. Концепция и визуальный язык

Telegram Mini App V2 спроектирован в строгом соответствии с **BooStudy UI Canon**:
- **Тактильные карточки (Tactile 3D Cards):** поверхности с мягкими скруглениями (`border-radius: 18px`), выраженным объёмным разделением, деликатной границей (`border: 1px solid var(--c-border)`) и многослойными тенями (`box-shadow: 0 4px 16px rgba(0,0,0,0.06), 0 1px 2px rgba(0,0,0,0.04)`).
- **Выразительные кнопки:** активный отклик при нажатии (`transform: scale(0.98)`), скругления `border-radius: 14px`, достаточная высота для удобного нажатия пальцем (минимум 44px).
- **Таблеточные переключатели (Pill Tabs):** фильтры и чипы с округлыми краями (`border-radius: 9999px`) и контрастным состоянием активного элемента.
- **Мобильный фокус (Mobile-First):** приложение оптимизировано для управления одной рукой. Основная навигация вынесена в нижний бар (Bottom Navigation Bar), второстепенные действия — в карточки и контекстные модальные листы (BottomSheet / Drawer).

## 2. Адаптивность и темизация (Dark / Light Theme)

Приложение динамически адаптируется к цветовой теме клиента Telegram через CSS Custom Properties и слушатель `tg.onEvent('themeChanged')`:

```css
:root {
  /* Dynamic Telegram Theme Variables with BooStudy Fallbacks */
  --c-bg: var(--tg-theme-bg-color, #0f172a);
  --c-surface: var(--tg-theme-secondary-bg-color, #1e293b);
  --c-surface-card: #243046;
  --c-text: var(--tg-theme-text-color, #f8fafc);
  --c-hint: var(--tg-theme-hint-color, #94a3b8);
  --c-accent: var(--tg-theme-button-color, #6366f1);
  --c-accent-hover: #4f46e5;
  --c-accent-text: var(--tg-theme-button-text-color, #ffffff);
  --c-link: var(--tg-theme-link-color, #818cf8);
  --c-border: rgba(255, 255, 255, 0.08);
  --c-success: #10b981;
  --c-warning: #f59e0b;
  --c-danger: #ef4444;

  /* Safe Area Insets for iOS & Android Notches / Gestures */
  --safe-top: env(safe-area-inset-top, 0px);
  --safe-bottom: env(safe-area-inset-bottom, 0px);
}
```

### Поддержка Telegram WebApp API:
- **`tg.expand()`:** Приложение сразу разворачивается на полную высоту экрана при запуске.
- **`tg.BackButton`:** Автоматически синхронизируется со стеком переходов. При переходе в модальное окно или подэкран появляется нативная кнопка «Назад» Telegram, нажатие на которую плавно возвращает пользователя на предыдущий экран.
- **`tg.HapticFeedback`:**
  - `impactOccurred('light')` — при переключении табов нижней навигации и фильтров.
  - `impactOccurred('medium')` — при нажатии основных действий (переход к уроку, отправка формы).
  - `notificationOccurred('success')` — при успешном сохранении настроек, ответе на баг-репорт или запуске рассылки.
- **`tg.setHeaderColor` / `tg.setBackgroundColor`:** Окрашивание системного хедера Telegram в тон фона страницы для бесшовного нативного ощущения.

## 3. Информационная архитектура по ролям

### 3.1. Ученик (Student)
- **Главная (Action Center):**
  - Баннер ближайшего урока с кнопкой входа в класс.
  - Сводка дедлайнов (срочные, на проверке, просроченные).
  - Карточки внимания (Action Items).
- **Уроки (Расписание):**
  - Интерактивный календарь с переключением недель.
  - Карточки уроков: статус («Идёт», «Запланирован», «Завершён»), время, длительность, преподаватель, тема, кнопка входа.
- **Задания (Домашние задания):**
  - Пилюльные фильтры: `Все`, `К сдаче` (Assigned/Returned), `На проверке` (Submitted), `Проверено` (Graded).
  - Карточки сдачи с дедлайном, набранным баллом и процентом.
  - Модальный лист с подробным описанием задания.
- **Прогресс (Успеваемость):**
  - Общий процент успешности, количество выполненных работ.
  - Визуальные индикаторы последних оценок.
- **Профиль:**
  - Имя, статус подписки, переключатели категорий Telegram-уведомлений, ссылка на веб-платформу.

### 3.2. Преподаватель (Teacher / Tutor)
- **Главная:**
  - Уроки на сегодня.
  - Число ожидающих проверки работ.
  - Быстрый доступ к неотложным задачам.
- **Очередь проверки (Review Queue):**
  - Список сданных работ с фильтрацией и временем ожидания.
  - Карточка сдачи: имя ученика, название задания, ссылка на проверку.
- **Ученики (Students):**
  - Список прикреплённых учеников с живым поиском.
  - Число активных и сданных заданий по каждому ученику.
- **Уроки (Расписание):**
  - График предстоящих занятий с именами учеников и временем.
- **Профиль:**
  - Настройки уведомлений и служебная информация.

### 3.3. Родитель (Parent)
- **Главная:**
  - Селектор ребёнка (если детей несколько).
  - Сводка успеваемости выбранного ребёнка.
  - Ближайшее занятие.
- **Дети:**
  - Индивидуальные карточки детей с недельным дайджестом: количество сданных работ, процент выполнения, просрочки.
- **Расписание:**
  - График уроков ребёнка с преподавателями и темами.
- **Профиль:**
  - Настройки уведомлений об оценках и расписании.

### 3.4. Администратор / Создатель (Admin & Creator)
- **Главная:**
  - Сводка ключевых метрик платформы (активные ученики, преподаватели, уроки сегодня, работы в очереди, состояние очереди Outbox).
  - Быстрый переключатель контекста «Создатель <-> Учитель».
- **Операции / Баг-репорты:**
  - Список входящих сообщений об ошибках с фильтрацией `Новые` / `Отвеченные` / `Все`.
  - Модальное окно быстрого ответа с автоматической отправкой в Telegram ученика.
- **Ученики:**
  - Поиск по всем активным ученикам платформы с отметкой привязки к боту (`📱 В боте` / `Не привязан`).
- **Рассылка (Broadcast):**
  - Форма отправки сообщения всем ученикам платформы с предпросмотром.
  - История прошедших рассылок со статусами доставки.
- **Профиль:**
  - Системный статус, служебные настройки.

## 4. Состояния экранов (UX States)

1. **Loading State:** Скелетонные карточки и плавный спиннер бренда BooStudy, отсутствие «дёргания» лейаута.
2. **Empty State:** Дружелюбные иллюстрации/эмодзи с понятным текстом (например, «🎉 На сегодня уроков нет», «✅ Все работы проверены»).
3. **Error State:** Экран с возможностью повторной попытки («Повторить попытку») без падения приложения.
4. **Offline / Network Reconnect:** Сохранение локального состояния и мягкое оповещение всплывающим тостом (`Toast`).
