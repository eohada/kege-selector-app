# BooStudy Telegram Next — Продуктовая спецификация и Conversational UI Kit

**Версия:** 2.0 (Telegram Next)  
**Статус:** Утверждено  
**Целевая аудитория:** Преподаватели, Ученики, Родители, Администраторы платформы BooStudy

---

## 1. Продуктовая концепция

**BooStudy Telegram Next** — это персональный мобильный ассистент образовательной платформы BooStudy, встроенный непосредственно в мессенджер Telegram.

В отличие от разрозненных ботов-оповещателей, Telegram Next представляет собой **полнофункциональный диалоговый кабинет (Conversational Hub)**:
- Не требует постоянного перехода в браузер для типовых действий (просмотр расписания, статуса заданий, оценок, очереди проверки).
- Доставляет интерактивные уведомления с возможностью выполнить действие в один тап прямо внутри чата с ботом.
- Предоставляет ролевую персонализацию: один и тот же Telegram-аккаунт может иметь несколько ролей (например, Преподаватель + Создатель или Родитель + Ученик) и бесшовно переключаться между ними.

---

## 2. Conversational UI Kit и правила оформления

### 2.1. Анатомия сообщения-карточки

Каждый экран бота оформлен в виде визуальной карточки с четкой иерархией:

```
[Эмодзи-бейдж] <b>[Заголовок экрана / События]</b>
[Контекстный статус или подзаголовок]

──────────────
• <b>[Параметр 1]:</b> [Значение 1]
• <b>[Параметр 2]:</b> [Значение 2]
• <b>[Параметр 3]:</b> [Значение 3]

[Цитата, комментарий преподавателя или примечание в <blockquote>]

──────────────
<i>[Компактный контекстный футер: дата/время в Europe/Moscow]</i>
```

### 2.2. Семантика эмодзи

Использование эмодзи строго стандартизировано для исключения визуального шума:

| Эмодзи | Значение в интерфейсе |
| :---: | :--- |
| 🎓 | Пространство преподавателя (уроки, проверка, ученики) |
| 📚 | Домашние задания, учебные материалы, тесты |
| 👨‍🎓 | Пространство ученика, индивидуальные успехи |
| 👨‍👩‍👧 | Пространство родителя, дети, баланс семьи |
| ⚙️ | Настройки профиля, уведомления, привязка |
| 🛡️ | Панель администратора, безопасность, системные метрики |
| 👑 | Режим Создателя платформы (Creator) |
| 🗓️ | Календарь, дата, расписание уроков |
| ⏰ | Время, дедлайны, таймеры, тихие часы |
| ⏳ | Ожидание (на проверке, в обработке) |
| ✅ | Успешно проверено, сдано, подтверждено |
| ⚠️ | Предупреждение, горящий дедлайн, отмена |
| 💬 | Комментарий преподавателя, обратная связь |
| 🔄 | Обновление экрана, переключение роли |

### 2.3. Tone of Voice (Тональность общения)

- **Грамотный академический русский язык:** уважительное, дружелюбное и лаконичное общение без бюрократизма, сленга и роботизированных фраз.
- **Информативность первого экрана:** пользователь должен за 2 секунды понять, что произошло и требуется ли от него действие.
- **Бережное отношение к вниманию:** отсутствие спама, возможность настройки категорий уведомлений и тихих часов.

### 2.4. Локализация даты и времени

- Все временные метки отображаются в часовом поясе пользователя (по умолчанию `Europe/Moscow`, МСК).
- Формат: `ДД месяца (день недели) в ЧЧ:ММ МСК`, например:  
  *«24 октября (сб) в 18:00 МСК»*.

## 3. Спецификация ролевых пространств

### 3.1. Преподаватель (Tutor / Teacher)

**Главный экран (`/menu` в роли преподавателя):**
- Расписание занятий на сегодня с указанием времени, темы и имени ученика.
- Количество сданных работ в очереди проверки (`Ожидают проверки: N`).
- Интерактивные кнопки:
  - `📋 Очередь проверки (N)` → переход к `v3:tch:queue`
  - `👥 Мои ученики` → переход к `v3:tch:students`
  - `🗓️ Расписание` → переход к `v3:tch:lessons`
  - `🔄 Сменить роль` (при наличии других ролей)

**Очередь проверки (`v3:tch:queue`):**
- Список домашних заданий, сданных учениками преподавателя.
- Реализована строгая фильтрация по авторству/назначению работы (Zero-IDOR): преподаватель видит только свои работы.

**Карточка работы на проверку (`v3:tch:q:<id>`):**
- Название задания, имя ученика, точное время сдачи.
- Наличие прикрепленных решений/файлов.
- Кнопка перехода к проверке в веб-студии BooStudy (`🌐 Проверить на платформе`).
- Кнопка возврата в очередь (`⬅️ В очередь`).

**Список учеников (`v3:tch:students`):**
- Полная агрегация через `app.utils.relationship_scope`:
  - Ученики с активным статусом в таблице `TeacherStudent`.
  - Ученики, закрепленные за преподавателем как за куратором (`Student.mentor_id == teacher.id`).
  - Ученики групповых и индивидуальных курсов преподавателя.
- Отображение категории экзамена (ЕГЭ / ОГЭ / Программирование) и остатка оплаченных уроков.

---

### 3.2. Ученик (Student)

**Главный экран (`/menu` в роли ученика):**
- Ближайшее занятие (тема, преподаватель, время до начала).
- Статистика по домашним заданиям:
  - ⏳ На проверке: N
  - 📝 Требуют выполнения: M
  - ⚠️ Горящие дедлайны: K
- Интерактивные кнопки:
  - `📚 Мои домашние задания` → переход к `v3:stu:hw`
  - `🗓️ Моё расписание` → переход к `v3:stu:schedule`
  - `⚙️ Настройки уведомлений` → переход к `v3:set:home`

**Список домашних заданий (`v3:stu:hw`):**
- Разделение на вкладки/блоки:
  1. Активные задания с дедлайном.
  2. Просроченные задания (выделены предупреждением ⚠️).
  3. Работы на проверке у преподавателя (⏳).
  4. Проверенные работы (✅) с итоговым баллом.

**Карточка домашнего задания (`v3:stu:hw_view:<id>`):**
- Название темы, подробное описание задачи.
- Дедлайн с обратным отсчетом.
- Для проверенных работ:
  - Итоговый балл: например, `24 / 25 (96%)`.
  - Комментарий преподавателя в блоке `<blockquote>`.
- Кнопка перехода к решению на платформе (`🌐 Открыть задание`).

---

### 3.3. Родитель (Parent)

**Главный экран (`/menu` в роли родителя):**
- Список прикрепленных детей (связи `FamilyTie` с `is_confirmed == True`).
- Для каждого ребенка:
  - Ближайший запланированный урок.
  - Академический прогресс за текущую неделю.
  - Баланс оплаченных занятий.
- Интерактивные кнопки:
  - `👶 [Имя ребенка 1]` → детальный отчет
  - `👶 [Имя ребенка 2]` → детальный отчет
  - `➕ Привязать ребенка` → инструкция по привязке

**Карточка ребенка (`v3:par:child:<id>`):**
- Полный дайджест: посещаемость занятий, средний балл по сданным домашним работам, комментарии преподавателей.
- Кнопка просмотра расписания ребенка (`🗓️ Расписание занятий`).

---

### 3.4. Администратор (Admin)

**Главный экран (`/menu` в роли администратора):**
- Оперативный пульс платформы BooStudy:
  - Активные пользователи за последние 24 часа.
  - Запланированные уроки сегодня.
  - Количество открытых баг-репортов.
- Интерактивные кнопки:
  - `🐛 Баг-репорты (N)` → переход к `v3:adm:bugs`
  - `📊 Системные метрики` → переход к `v3:adm:ops`
  - `🔍 Поиск пользователя` → поиск по логину или ID

---

### 3.5. Создатель платформы (Creator)

- Полный суперпользовательский доступ ко всем ролям.
- Встроенный селектор ролей с возможностью мгновенного переключения в любой ролевой контекст (`teacher`, `student`, `parent`, `admin`).
- Тумблер `Режим по умолчанию: Преподаватель / Администратор`.

---

### 3.6. Непривязанный пользователь (Unlinked / Guest)

Если пользователь запустил бота без авторизации на платформе BooStudy:
- Приветственное сообщение с описанием возможностей платформы.
- Четкая инструкция по привязке:
  - Либо переход по персональной ссылке из веб-кабинета BooStudy.
  - Либо отправка 6-значного кода привязки прямо в чат с ботом.
- Кнопка `❓ Помощь и поддержка`.
