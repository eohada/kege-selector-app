## 1. С чего начать

1. Откройте Telegram на компьютере или телефоне и найдите бота: **`@BooStudy_local_bot`**.
2. Отправьте боту команду:
   ```text
   /start
   ```
   или
   ```text
   /menu
   ```
3. Бот поприветствует вас и отобразит главное меню активного кабинета.

## 2. Переключение ролей (мульти-ролевой режим)

## 3. Сценарии проверки по кабинетам

### Сценарий А. 👨‍🏫 Кабинет Преподавателя
1. Переключитесь на роль **Преподаватель** (`/role` → Преподаватель).
2. Нажмите кнопку **📅 Расписание**:
   - Вы увидите список уроков на сегодня (урок по Графам в 17:00 и урок по ОГЭ в 20:00).
   - Нажмите на любой урок, чтобы открыть детальную карточку (время, ученик, длительность, статус).
3. Нажмите кнопку **❌ Отменённые занятия**:
   - Отобразится индивидуальная консультация со статусом отмены.
4. Нажмите кнопку **👥 Мои ученики**:
   - Отобразится список учеников, прикрепленных к вам.

### Сценарий Б. 🎓 Кабинет Ученика
1. Переключитесь на роль **Ученик** (`/role` → Ученик).
2. Нажмите кнопку **📚 Домашние задания**:
   - **Активные:** *Лабораторная работа: Бинарные деревья поиска* (дедлайн через 3 дня).
   - **Просроченные:** *Практикум №14: Позиционные системы счисления*.
   - **На проверке:** *Решение варианта №102 КЕГЭ 2026*.
   - **Проверенные:** *Контрольная работа №2: Динамическое программирование*.
3. Откройте проверенное задание:
   - Проверьте отображение оценки: **96% (24/25 баллов)**.
   - Проверьте отображение отзыва учителя: *"Отличная оптимизация памяти в задаче №3! В коде учтены все крайние случаи."*
4. Нажмите кнопку **📅 Мои уроки**:
   - Отобразятся запланированные занятия с указанием времени по Москве.

### Сценарий В. 👨‍👩‍👦 Кабинет Родителя
1. Переключитесь на роль **Родитель** (`/role` → Родитель).
2. Нажмите кнопку **👶 Мои дети**:
   - Отобразятся два прикрепленных ребёнка: *Алексей Смирнов* и *Ученик Room QA*.
3. Выберите любого ребёнка:
   - Откроется сводка по успеваемости ребёнка, статус последних заданий и баланс занятий.

### Сценарий Г. 🛠️ Кабинет Администратора / Создателя
1. Переключитесь на роль **Администратор** или **Создатель**.
2. Нажмите **📊 Метрики платформы**:
   - Отобразится статистика: количество пользователей (718), состояние очередей и активность.
3. Нажмите **🐞 Баг-репорты / Инциденты**:
   - Отобразится карточка открытого тестового инцидента по рендерингу формул со статусом `IN_PROGRESS`.

## 4. Как протестировать живое уведомление

Первое тестовое уведомление (`lesson_scheduled`) **уже отправлено и доставлено** вам в `@BooStudy_local_bot`! Проверьте историю чата с ботом.

Чтобы отправить **ещё одно реальное уведомление** в любой момент:
1. Откройте терминал в папке проекта.
2. Выполните команду:
   ```bash
   ./venv/bin/python scripts/trigger_test_notification.py
   ```
3. В течение 2–5 секунд диспетчер захватит задачу из базы и пришлет вам в Telegram push-уведомление с карточкой урока.

## 6. Что делать, если бот не отвечает

Если бот был случайно остановлен или соединение разорвалось:
1. Проверьте статус:
   ```bash
   ./venv/bin/python scripts/check_telegram_status.py
   ```
2. Перезапустите бота при необходимости:
   ```bash
   ./venv/bin/python run_bot.py
   ```
