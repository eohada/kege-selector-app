# BooStudy Telegram Next — Регламент ручной приёмки

**Назначение:** Пошаговый сценарий ручной верификации возможностей Telegram Next для Создателя / Владельца платформы.  
**Целевой бот:** `@BooStudy_local_bot` (локальный dev-бот)  
**Аккаунт Создателя:** User ID `4`, Chat ID `854161398`, username `@eohada`  
**Время прохождения сценария:** 5–7 минут  

---

## Подготовительный этап

### Шаг 0.1. Убедитесь, что сервер и бот запущены
В процессах должны быть активны:
1. Flask сервер на `http://127.0.0.1:5000`.
2. Локальный Telegram бот (`./venv/bin/python run_bot.py`).

### Шаг 0.2. Загрузка демонстрационных данных приёмки
В терминале выполните команду для генерации реалистичных связей и расписания:

```bash
./venv/bin/python scripts/seed_telegram_v3_acceptance_data.py
```

*Результат:* скрипт создаст уроки на сегодня, домашние задания разных статусов (новое, просроченное, на проверке, проверенное с оценкой), семейные связи и сохранит манифест в `instance/telegram_acceptance_seed_manifest.json`.

## Сценарии приёмки

### Сценарий 1. Преподаватель: уроки на сегодня и очередь проверки

1. Откройте диалог с `@BooStudy_local_bot` в Telegram.
2. Отправьте команду `/role` и выберите **«🎓 Преподаватель»** (или отправьте `/menu`, если роль уже активна).
3. **Что проверить на главном экране:**
   - [ ] Заголовок: `🎓 Кабинет преподавателя`.
   - [ ] В блоке «Занятия на сегодня» видны 2 запланированных урока (например, *«ЕГЭ Информатика: Графы и поиск в глубину»*).
   - [ ] В блоке «Проверка заданий» указано количество работ, ожидающих проверки.
4. Нажмите inline-кнопку **«📋 Очередь проверки»**:
   - [ ] Открывается список сданных работ.
   - [ ] Нажмите на работу *«Решение варианта №102 КЕГЭ 2026»*.
   - [ ] Открывается карточка работы: указан ученик, дата и время сдачи, ссылка на веб-студию проверки и кнопка «⬅️ В очередь».
5. Нажмите **«👥 Мои ученики»**:
   - [ ] Отображается список прикрепленных учеников (включая учеников по `TeacherStudent` и кураторству).

---

### Сценарий 2. Ученик: домашние задания, дедлайны и проверенная работа с баллом

1. Отправьте команду `/role` и переключитесь на роль **«👨‍🎓 Ученик»**.
2. **Что проверить на главном экране:**
   - [ ] Заголовок: `👨‍🎓 Кабинет ученика`.
   - [ ] Отображается ближайшее занятие сегодня с отсчетом времени.
   - [ ] Отображается статус домашних заданий (активные, на проверке).
3. Нажмите кнопку **«📚 Мои домашние задания»**:
   - [ ] Отображаются списки: активные, просроченные, на проверке и проверенные.
4. В блоке проверенных заданий выберите **«Контрольная работа №2: Динамическое программирование»**:
   - [ ] Открывается карточка сданной работы.
   - [ ] Отображается итоговый балл: **`24 / 25 (96%)`**.
   - [ ] В цитате (`<blockquote>`) отображается комментарий преподавателя: *«Отличная оптимизация памяти в задаче №3!...»*.

---

### Сценарий 3. Родитель: академический дайджест детей и баланс уроков

1. Отправьте команду `/role` и выберите **«👨‍👩‍👧 Родитель»**.
2. **Что проверить на главном экране:**
   - [ ] Заголовок: `👨‍👩‍👧 Кабинет родителя`.
   - [ ] Отображается список подтвержденных детей (например, *«Алексей Смирнов (Демо)»*).
3. Нажмите на карточку ребенка:
   - [ ] Отображается статус успеваемости, последнее занятие и баланс уроков.
   - [ ] Доступна кнопка просмотра расписания ребенка.

---

### Сценарий 4. Администратор / Создатель: оперативный мониторинг

1. Отправьте команду `/role` и выберите **«🛡️ Администратор»** (или `/menu`).
2. Нажмите кнопку **«🐛 Баг-репорты»**:
   - [ ] Отображается список открытых инцидентов (включая тестовый инцидент по KaTeX).
3. Нажмите кнопку **«📊 Системные метрики»**:
   - [ ] Отображаются счетчики активности платформы.

---

### Сценарий 5. Интерактивные Push-уведомления с переходом в бот

1. В терминале запустите разовую безопасную доставку реального уведомления Создателю:

```bash
./venv/bin/python scripts/trigger_test_notification.py --live --kind submission_submitted
```

2. **Что проверить в Telegram:**
   - [ ] В чат с ботом мгновенно приходит форматированное сообщение:
     *«📬 Новая работа на проверку»*.
   - [ ] Указано название работы и ученик.
   - [ ] В сообщении присутствует кнопка: **`📋 Проверить в боте`**.
3. **Нажмите на кнопку `📋 Проверить в боте`:**
   - [ ] Бот прямо в диалоге открывает карточку сданной работы без необходимости перехода в сторонний браузер!

4. (Опционально) Проверьте уведомление о проверенной работе:
```bash
./venv/bin/python scripts/trigger_test_notification.py --live --kind submission_checked
```
   - [ ] Приходит карточка с оценкой `24/25 (96%)` и кнопкой `📊 Результат ДЗ`.
   - [ ] Нажатие открывает карточку выполненного задания.

---

### Сценарий 6. Чистый откат демонстрационных данных (Unseed)

После завершения приёмки база данных возвращается в исходное состояние одной командой:

```bash
./venv/bin/python scripts/unseed_telegram_v3_acceptance_data.py
```

**Что проверить:**
- [ ] Консоль сообщает об успешном удалении добавленных тестовых уроков, заданий, сдач и связей.
- [ ] Файл манифеста `instance/telegram_acceptance_seed_manifest.json` удален.
- [ ] Никакие существующие пользователи или боевые данные не затронуты.

Если все 6 сценариев успешно пройдены — Telegram-экосистема **BooStudy Telegram Next** полностью готова к штатной эксплуатации.
