# Аудит платформы: ученик и родитель (UI/UX и функциональность)

**Дата:** 03.02.2025  
**Фокус:** степень «сырости», недоработки, потенциальные ошибки и неудобства по разделам для учеников и родителей.

---

## Резюме исправлений в этой сессии

- **Контекст навигации:** для учеников, созданных через «Create Pack» (связь по `user_id` без email), в шапке не отображались пункты «Комната ученика» и «Статистика». В `inject_user_data()` добавлен приоритетный поиск Student по `user_id`, затем по email.
- **Дашборд ученика:** поиск Student для дашборда приведён к той же логике (user_id → email → legacy), чтобы «Create Pack» ученики видели контент.
- **Дашборд родителя:** для детей и выбранного ребёнка поиск Student выполняется по `user_id`, затем по email, чтобы у родителя отображались статистика и задания для учеников без email.
- **Профиль ученика:** добавлен редирект «свой профиль» по `user_id` и явная выдача доступа к своему профилю по `student.user_id == current_user.id`, чтобы ученики без email не получали 403.

| Критерий | Оценка | Комментарий |
|----------|--------|-------------|
| Сырость | Низкая | Есть логин/логаут, роли (creator, admin, tutor, student, parent), RBAC и data scoping. |

**Рекомендации:** Добавить сброс пароля по ссылке (email/бот) и опцию «Запомнить меня».

| Критерий | Оценка | Комментарий |
|----------|--------|-------------|
| Сырость | Низкая | Карточки: план, активные работы, слабые темы, последние оценки. Единый стиль (glass-panel, neo-button). |
| Недоработки | Средние | Нет явной ссылки «Дашборд» в навбаре — ученик попадает сюда после логина, но из навбара ведёт только «Комната ученика» (профиль). Пустая «траектория»/«слабые темы» выглядят нейтрально (есть empty-state). |

## 5. Работы и отправки (Assignments / Submissions)

| Критерий | Оценка | Комментарий |
|----------|--------|-------------|
| Сырость | Низкая | Список работ, карточки KPI, просмотр отправки, ввод ответов, дедлайны, автосохранение. |
| Недоработки | Средние | Для ученика/родителя список заданий может быть неочевиден (нужно заходить в «Комната ученика» или дашборд). Нет фильтра «только мои» на общем списке для тьютора. |

| Неудобства | Средние | Длинные работы с большим числом задач требуют прокрутки; фиксированный хедер/прогресс по задачам улучшили бы UX. |

**Рекомендации:** Явная ссылка «Мои работы» в навбаре ученика; индикатор «Сохранено»/«Ошибка сохранения» при автосохранении.

## Приоритетные действия

1. **Высокий (сделано в этой сессии):** унификация поиска Student по `user_id` и email в контексте, дашборде ученика, дашборде родителя и профиле ученика.
2. **Средний:** кнопка «Пополнить баланс» у родителя — либо экран/редирект, либо временное отключение с подсказкой.
3. **Средний:** публичная страница тарифов — единый навбар и CTA «Выбрать»/«Купить».
4. **Низкий:** сброс пароля через UI или бота; «Запомнить меня»; индикатор автосохранения в формах отправки.

Аудит выполнен по коду и шаблонам; рекомендуется дополнительно прогнать сценарии вручную (ученик с email, ученик только user_id, родитель с несколькими детьми, мобильный вид).
