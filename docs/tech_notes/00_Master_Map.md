## 🏗️ Очередь Интеграции (Принцип "Снизу-Вверх")

### 🟢 Уровень 1: Фундамент (Только чтение / GET)
*Начальный этап. Безопасное подключение отображения статичных данных, справочников и профилей без мутаций в БД.*

#### 1.1 Авторизация и Профиль
- [[Авторизация_и_Вход]] — Базовый рендер форм входа и регистрации.
- [[Профиль_Пользователя]] — Просмотр данных авторизованного пользователя.

#### 1.2 Базовые Справочники и Каталоги
- [[Каталог_и_Фильтр_Задач]] — Справочник и фильтр задач КЕГЭ/ЕГЭ.
- [[Каталог_Теории_и_Тем]] — Каталог теоретических материалов и разделов.
- [[Критерии_и_Рубрики_Оценивания]] — Справочник критериев проверки ДЗ.

#### 1.3 Списки и Дашборды
- [[Дашборд_Ученика]] — Главная страница ученика со списками задач и уроков.
- [[Кабинет_Родителя]] — Просмотр прогресса ребенка родителями.
- [[Школьные_Группы]] — Просмотр состава учебных групп.
- [[Расписание_Уроков]] — Календарный виджет вебинаров.
- [[Список_Домашних_Заданий]] — Карточки и списки выданых ДЗ.
- [[Управление_Тарифами_и_Подписками]] — Витрина тарифных планов.
- [[Центр_Уведомлений]] — Просмотр списка системных алертов.
- [[Telegram_Mini_App]] — Рендер Mini App страниц внутри Telegram.
- [[RAG_Контекст_и_LLM_Логирование]] — Мониторинг логов AI-ассистента.

---

### 🟡 Уровень 2: Простые Действия (Изолированные POST / PUT)
*Второй этап. Привязка изолированных форм, кнопок отправки и пользовательских мутаций.*

#### 2.1 Интерактивный Workspace и Код-раннер
- [[Песочница_Python_Runner]] — Выполнение Python кода во встроенном runner.
- [[Код_Плейбек_и_История_Версий]] — Просмотр историй версий и плеер кода.
- [[Интерактивный_Холст_Рисования]] — Сохранение и загрузка черновиков на canvas.

#### 2.2 Прочие Изолированные Действия
- [[Достижения_и_Стрейки]] — Начисление XP и ежедневного стрейка.
- [[Управление_Семейными_Привязками]] — Ввод инвайт-кодов для связи аккаунтов.
- [[Заметки_Преподавателя]] — Сохранение приватных заметок к урокам.
- [[Интеграция_Miro_и_Доски]] — Синхронизация токенов и холста Miro.
- [[Отправка_Решения_ДЗ]] — Отправка ответов на домашние задания.
- [[Редактор_и_Модерация_Задач]] — Создание и редактирование условий задач.
- [[Интерактивные_Теоретические_Блоки]] — Оценка понятности конспектов и прогресс.
- [[Напоминания_о_Дедлайнах]] — Персональная настройка напоминаний.
- [[Промокоды_и_Реферальная_Система]] — Активация промокодов и рефералок.
- [[Telegram_Уведомления_и_Бот]] — Настройка TG вебхуков и связок.
- [[QA_Тестирование_и_Баг_Репорты]] — Логирование багов платформы.
- [[Режим_Имперсонации]] — Переключение админа в контекст ученика.
- [[Загрузка_Файлов_и_S3]] — Загрузка ассетов и файлов в S3.

---

### 🔴 Уровень 3: Сложные Сквозные Цепочки (Workflows)
*Финальный этап. Интеграция высокосвязанной бизнес-логики, сокетов и генераторов.*

- [[Онбординг_Ученика]] — Полный цикл онбординга: регистрация -> стартовая диагностика -> генерация траектории.
- [[Статистика_и_MMR]] — Динамический расчет MMR на основе решенных задач и истории попыток.
- [[Программы_Обучения_и_Курсы]] — Дерево курса с ограничением доступа по подписке и прогрессу.
- [[Комната_Урока]] — Онлайн-вебинар: Socket.IO чат + синхронизация кода + Miro + задачи урока.
- [[Проверка_Работы_Преподавателем]] — Полный цикл проверки ДЗ: код ученика -> критерии -> диффы -> оценки -> уведомления.
- [[Генератор_Вариантов_КЕГЭ]] — Автоматическая сборка варианта КЕГЭ по спецификации -> прохождение -> автопроверка.
- [[Граф_Знаний_и_Мастери]] — Вычисление степени освоения тем по графу знаний (Knowledge Graph).
- [[Сессия_AI_Тренажера]] — Диалоговая сессия с AI-репетитором: RAG поиск -> генерация -> автоподсказки.
- [[Админ_Панель_и_Пользователи]] — Сквозное администрирование: роли -> блокировки -> биллинг -> логи аудита.
