## 📐 Формула Расчета XP и Уровней
1. **Кумулятивный XP уровня $L$:**
   $$\text{XP}(L) = \lfloor 100 \times (L - 1) \times (L - 1)^{0.5} \rfloor$$
   - *Уровень 1:* 0 XP
   - *Уровень 2:* 100 XP (`Инициализатор переменных / x = 5`)
   - *Уровень 3:* 282 XP (`Разветвитель условий / if-else`)
   - *Уровень 4:* 519 XP (`Повелитель циклов / while True`)
   - *Уровень 10:* 2700 XP (`Определитель функций / def f()`)
   - *Уровень 50:* `Создатель ИИ / Bug Exterminator`

2. **Динамический прогресс и звание:**
   - Каждому уровню соответствует тематическое звание по Информатике из словаря `INFORMATICS_RANKS`.
   - Прогресс-бар вычисляет процент внутри текущего уровня:
     $$\text{Progress \%} = \frac{\text{XP} - \text{XP}(L)}{\text{XP}(L+1) - \text{XP}(L)} \times 100\%$$

3. **Инструменты Разработчика (QA):**
   - Для быстрой проверки переходов рангов в Dev Role Switcher и в профиле выведена кнопка `⚡ +500 XP` (вызывающая роут `/sandbox/api/dev/add_xp`).
