## 🏆 Система Ачивок и Условий
1. **Ударный режим (Streak):**
   - Выводится реальное количество дней подряд из `Student.streak_days`.
   - `streak_5`: "Ударник 5 дней" (Заниматься 5 дней подряд).
   - `streak_14`: "Огненный марафон" (14 дней непрерывного обучения).

2. **Рубежи XP и Уроков:**
   - `first_lesson`: "Первый шаг" (1+ пройденный урок).
   - `xp_1000`: "Первый рубеж" (1000+ XP).
   - `xp_5000`: "Опытный алгоритмист" (5000+ XP).
   - `python_pro`: "Взломщик КЕГЭ" (50 решенных задач Python).
   - `secret_master`: "Секретный код" (Особая награда основателя).

3. **Интерактивный Bento 3D UI:**
   - Кликом по карточкам достижений открывается модалка «Все достижения» с 3 вкладками фильтров: `[Все]`, `[Полученные]`, `[В процессе]`.
   - Каждая ачивка выводит иконку, название, описание, дату получения и условия разблокировки.
