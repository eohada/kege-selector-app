## 📝 План интеграции (9 Модулей Бизнес-Логики)
- [x] **Рейтинг (Номер в классе):** Динамический расчет ранга среди одноклассников (`#1 в классе`).
- [x] **Стрик (Ударный режим):** Вывод дней непрерывного обучения из `Student.streak_days`.
- [x] **Посещено уроков:** Метрика переименована в «Посещено уроков» и привязана к `Lesson.status == 'completed'`.
- [x] **Система XP и Уровни:** Поддержка рангов `Ученик I-VI ранга`, прогресс-бара XP и остатка очков до следующего уровня.
- [x] **Цели на неделю:** Вывод целей из `StudentLearningPlanItem` с интерактивными кликабельными чекбоксами (AJAX `/sandbox/api/profile/goal/toggle/<id>`) и формой добавления.
- [x] **Достижения (Ачивки):** Автоматическая и ручная разблокировка ачивок (`streak_5`, `xp_1000`, `first_lesson`, `secret_master`).
- [x] **Bento 3D Редактирование:** Стилизованная модалка редактирования (Аватар, Баннер/Обложка, О себе, Учебная цель, Часовой пояс, Пароль) через AJAX `/sandbox/api/profile/edit`.
- [x] **Реферальная программа:** Генерация кода `BOOSTUDY-<USERNAME>-2026` и копирование в буфер обмена.
- [x] **Статус онлайна:** Проверка активности пользователя (`presence_last_seen_at`) с индикатором `ONLINE` / `OFFLINE`.
