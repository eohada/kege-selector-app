# Режим Имперсонации (Dev Role Switcher)

**Статус интеграции:** #status/stable (Зелёный - полностью интегрировано, оживлено и протестировано)

## 🔗 Зависимости
- [[Дашборд_Ученика]]
- [[Профиль_Пользователя]]
- [[Админ_Панель_и_Пользователи]]

## 💻 Текущий бэкенд
- **Роуты:** `/sandbox/impersonate/<int:user_id>`, `/sandbox/impersonate/revert`, `/sandbox/api/impersonate/users`, `/sandbox/api/dev/set_mentor` (`app/main/routes.py`)
- **Таблицы БД:** `Users`, `Students`, `UserRoles`
- **Связанные макеты:** `templates/sandbox/_dev_role_switcher.html`

## 🛠️ Функционал Dev Role Switcher (`Alt + I`)
1. **Быстрое переключение ролей:** Мгновенный переход между профилями ученика, преподавателя, админа, родителя и создателя без необходимости повторного ввода паролей.
2. **Управление связями (Выбор Наставника):**
   - В плашку виджета добавлено меню быстрого назначения/сброса наставника текущего ученика (`/sandbox/api/dev/set_mentor`).
   - Изменение мгновенно обновляет `student.mentor_id` в БД и динамически перерисовывает карточку на [[Дашборд_Ученика]].
3. **Безопасный сброс (Revert):** Кнопка «Выйти из имперсонации» для быстрого возврата в профиль разработчика.
