## 🚀 6 Модулей Бизнес-Логики Дашборда
1. **Текущий / Ближайший урок (Hero Hub):**
   - Проверка активного вебинара (`start_time <= now <= end_time` & `status == 'active'`).
   - Если урок идет — индицируется `ИДЕТ СЕЙЧАС` с кнопкой «В КОМНАТУ» (`/sandbox/lesson_room/<lesson_id>`).
   - Если урока сейчас нет — вывод ближайшего запланированного урока или переход в тренажер.

2. **Статистика курса:**
   - Вычисление процента завершения траектории `(completed_lessons / total_lessons) * 100%`.
   - Динамический ID ученика `#{{ current_user.id }}` и реальные баллы XP `student.xp`.
   - Просроченные долги по заданиям из БД (`StudentLearningPlanItem.status != 'done'`).

3. **Быстрый переход в Тренажёр:**
   - Интерактивный ввод номера задачи ЕГЭ (например, №15).
   - Мгновенный переход на `/sandbox/trainer?task=<number>`.

4. **Кликабельная Лента недавних уроков:**
   - Кликабельные названия последних 3 уроков с переходом на `/sandbox/lesson_room/<lesson_id>` и статусами `ИЗУЧЕНО`, `ПРОПУЩЕНО`, `НА ПРОВЕРКЕ`.

5. **Статус интеграции Telegram:**
   - Проверка наличия `user.tg_id` или `user.telegram_link`.
   - Зеленая плашка при подключенном боте, либо кнопка быстрого перехода в `@boostudy_bot`.

6. **Назначенный наставник (Управление через [[Режим_Имперсонации]]):**
   - Если `student.mentor_id` равен `None` — нейтральная плашка *«Наставник не назначен. Ждем распределения группы»*.
   - Если наставник назначен — карточка преподавателя с аватаром и кнопкой прямой связи.
   - Изменяется на лету через Dev Switcher (`Alt + I`) роутом `/sandbox/api/dev/set_mentor`.
