## 🚀 4 Модуля Интерактивной Бизнес-Логики Заданий
1. **Жесткая Фильтрация по Выписанным Работам:**
   - Выборка `Assignment` в роуте `/sandbox/tasks` осуществляется строго по `Submission.student_id == student.student_id`. Неназначенные ученику работы не выводятся.
   - 100% 1-в-1 совпадение со списком работ у наставника на `/sandbox/assignments`.

2. **Динамические Вкладки и Клиентская Фильтрация:**
   - Счетчики по категориям работ ученика:
     - **В работе (`in_progress`):** Задания со статусом `assigned` / `in_progress`.
     - **На проверке (`under_review`):** Задания со статусом `submitted` / `under_review`.
     - **Завершенные (`completed`):** Задания со статусом `completed` / `graded`.
   - Мгновенная клиентская переключка вкладок по атрибутам `data-status` без перезагрузки страницы.

3. **Двухколоночная Асимметричная Сетка:**
   - **Левая колонка (2/3): «Работы с дедлайном»** (Домашние задания с установленным дедлайном).
   - **Правая колонка (1/3): «По занятиям»** (Практические и классные работы, привязанные к урокам).
   - **Empty State:** Если в колонке нет задач для выбранной вкладки, отображается плашка с призраком 👻 (*«Абсолютно чисто! Вы великолепны.»*).

4. **Логика Карточки Задания:**
   - **Индикация Дедлайна:** Розово-красный бейдж при времени до дедлайна < 24 часов / просрочке (`<i class="ph-bold ph-fire"></i>`), либо мягкий зеленый при достаточном запасе.
   - **Прогресс-бар:** Динамический счетчик `X / Y задач` и процент закрашивания полосы.
   - **Кнопка Действия:** Текст **«Открыть работу»** при 0 выполненных задач, либо **«Продолжить»** при частичном выполнении с ведением на `/sandbox/task_detail/<assignment_id>`.
