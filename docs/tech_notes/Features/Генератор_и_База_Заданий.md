## 💻 Бэкенд и Эндпоинты API (`app/main/routes.py`)
- **Страница:** `GET /sandbox/task_generator`
- **Поток (Tinder):**
  - `GET /sandbox/api/task_generator/tinder_next?task_number=X&difficulty=Y` — следующая доступная задача без попавших в блэклист.
  - `POST /sandbox/api/task_generator/tinder_action` — обработка действий `{ task_id, action: 'accept'|'skip'|'blacklist' }`.
- **Ручное Добавление:**
  - `POST /sandbox/api/task_generator/create_task` — ручное создание с физическим сохранением файлов в `app/static/sandbox_files/`.
- **Центральный Банк:**
  - `GET /sandbox/api/task_generator/bank_list?task_number=X&difficulty=Y&search_query=S&only_my=true|false` — список всех активных задач с флагами `can_manage`.
  - `POST /sandbox/api/task_generator/edit_task/<id>` — редактирование с проверкой прав.
  - `POST /sandbox/api/task_generator/delete_task/<id>` — физическое удаление с проверкой прав.

## 🛠️ 3 Интерактивные Вкладки UI

1. **Вкладка 1: Поток (Tinder Generator) & Контекстная Блокировка:**
   - Переключение карточек заданий с фильтрацией по номеру КЕГЭ (1–27) и сложности `[Базовый] [Средний] [Хард]`.
   - **Контекстный режим (Lock / Unlock):**
     - При отсутствии `assignment_id` / `context_id` в URL: кнопки `[В blacklist]`, `[Пропустить]`, `[Принять в работу]` блокируются (`disabled`, `opacity-50 cursor-not-allowed pointer-events-none`), и отображается баннер *«ℹ️ Режим обзора: Откройте генератор из конкретной работы или шаблона, чтобы добавлять задачи в один клик.»*
     - При наличии `assignment_id` в URL: кнопки активны, а «Принять в работу» связывает `task_id` с `assignment_id` в таблице `AssignmentTasks`.
   - **Анимации Tinder Slide / Fade:** При перелистывании карт карточка уходит с анимированным `opacity-0 translate-x-4`, а следующая плавно въезжает `duration-300`.

2. **Вкладка 2: Ручное Добавление & Bento Live-Preview (Debounce 300ms):**
   - Форма ввода параметров задачи (номер, сложность, тема, балл, источник, LaTeX-текст условия, ответ, Python-код).
   - **Debounce 300ms & Smooth Fade:** Ввод текста приглушает предпросмотр (`opacity-70`), а спустя 300 мс после паузы в печати реактивно обновляет DOM и перезапускает KaTeX.
   - Загрузка файлов и сохранение на диске в `app/static/sandbox_files/`.

3. **Вкладка 3: Центральный Банк Заданий:**
   - Поиск по условию/теме/источнику и фильтрация «Все задачи / Только мои».
   - Инлайн/модальное редактирование и физическое удаление.
   - **Разграничение прав (RBAC):** Удаление и редактирование системных задач разрешено только создателю или администраторам (`ADMIN`).
