## 🎯 Мгновенный Переход из Дашборда
- На главном экране [[Дашборд_Ученика]] расположен интерактивный виджет быстрого перехода в тренажёр по номеру задачи КЕГЭ.
- При вводе номера задачи (например, `№15`) происходит мгновенный редирект на `/sandbox/trainer?task=15`.
- Чат с AI-репетитором подбирает задачи соответствующего номера и ведет диалог без прямой выдачи готового ответа.
