## 🚀 8 Усовершенствований и Интерактивных Фичей

1. **Встроенный поиск по названию:**
   - Поисковая строка перенесена в верхнюю панель фильтрации рядом с вкладками и кнопкой «+ Создать работу».

2. **JS-Click Выпадающее Меню Трех Точек:**
   - Ликвидирован нестабильный CSS `:hover`. Меню фиксируется по `toggleMenu` и закрывается при клике снаружи.

3. **Вкладка «Архив» и Архивация:**
   - Пункт **«В архив»** переводит работу в статус `status = 'archived'`. Добавлена вкладка **«Архив»**.

4. **Функция «Сделать копию»:**
   - Пункт **«Сделать копию»** клонирует `Assignment` и `AssignmentTask` с заголовком `"<Название> (Копия)"`.

5. **Исправление аномалии счетчика (`0/1 сдано`):**
   - Устранены хардкод-значения `or 12` / `or 7`. Знаменатель и числитель рассчитываются строго по записям `Submission` в БД.

6. **100% Синхронизация с Учеником:**
   - Запрос на `/sandbox/assignments` подтягивает работы преподавателя и его подопечных (`student.mentor_id == current_user.id`), гарантируя полное 1-в-1 совпадение с `/sandbox/tasks`.

7. **🔥 Строгая Изоляция Данных Преподавателей:**
   - Преподаватели (например, `Teacher_1` и `Teacher_2`) при переключении через `Alt + I` видят строго свои пулы работ.

8. **Obsidian Интеграция:**
   - Статус функции зафиксирован как `#status/stable` со связями `[[Страница_Заданий]]`, `[[Режим_Имперсонации]]` и `[[Дашборд_Ученика]]`.
