## 🛡️ 1. Правило "Schema Only" (Изоляция Песочницы)
- **Чистая структура без старых дампов:** Песочница заимствует **ТОЛЬКО структуру и схему данных (SQLAlchemy Models)**. Категорически запрещено импортировать или копировать старые дамп-записи (198 старых уроков).
- **Изолированная БД (`sandbox_clean.db`):** Песочница работает с отдельным SQLite файлом `data/sandbox_clean.db`.

## 🔄 2. Реляционные Связи и Сквозная Синхронизация (Assignment <-> Submission <-> Student)

### Схема связей (ER-Logic):
```
[User (Teacher)] -- (created_by_id) --> [Assignment] <-- (assignment_id) -- [Submission] -- (student_id) --> [Student] -- (mentor_id) --> [User (Mentor)]
```

- **Роут ученика (`/sandbox/tasks`):**
  - Выборка `Assignment` производится строго через `Submission.query.filter_by(student_id=student.student_id)`.
  - Ученик видит **только те работы**, которые были выписаны непосредственно ему.

- **Роут преподавателя (`/sandbox/assignments`):**
  - Выборка `Assignment` объединяет работы, где `created_by_id == current_user.id` **ИЛИ** где `Submission.student.mentor_id == current_user.id`.
  - Обеспечена **100% 1-в-1 синхронизация** списка работ у ученика `Student_1` и его наставника `Teacher_1`.

- **Исправление счетчиков сдачи:**
  - Знаменатель `total_assigned` рассчитывается честно по кол-ву `Submission` карточки (без оверхеда и захардкоженных fallback `or 12` / `or 7`).
  - Отображается корректный статус сдачи (например, `0/1 сдано` или `1/1 сдано`).
