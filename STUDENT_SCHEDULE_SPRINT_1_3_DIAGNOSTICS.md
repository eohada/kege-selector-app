## 3. Диагностика синхронизации локального сервера (Dev Server Sync)

### 3.1. Причина рассинхронизации

При разработке возникал эффект «код изменён, но в браузере ничего не поменялось».  
Исследование файла запуска `scripts/run_local.py`:

```python
# scripts/run_local.py:46
socketio.run(
    app,
    host=args.host,
    port=args.port,
    debug=True,
    use_reloader=False,  # <--- АВТОРЕЛОАДЕР ОТКЛЮЧЕН!
    log_output=True,
)
```

Автоперезагрузка (`use_reloader=False`) была выключена намеренно из-за конфликтов авторелоадера Werkzeug с фоновыми потоками Socket.IO / eventlet.  
В результате фоновый процесс `python scripts/run_local.py` (например, PID 1502456), запущенный в начале дня, продолжал удерживать в памяти старые версии Python-файлов и скомпилированных шаблонов Jinja2.

### 3.2. Регламент перезапуска для разработчиков

Перед проверкой любых правок:
```bash
# 1. Завершить зависшие экземпляры сервера
pkill -f "scripts/run_local.py" || true

# 2. Запустить сервер с контролем вывода
python scripts/run_local.py --port 5000
```

## 4. Архитектурное ограничение: Multi-Teacher Schema Constraint

### 4.1. Диагностика модели данных

При проектировании сценария с несколькими преподавателями у одного ученика в течение недели было выявлено критическое ограничение реляционной схемы:

В файле `core/db_models.py`:
- Модель `Lesson` содержит поле `student_id = db.Column(db.Integer, db.ForeignKey('students.id'))`.
- Модель `Lesson` **НЕ содержит** поля `teacher_id`!
- Резолвинг преподавателя в `app/schedule/routes.py` (строки 80–108) выполняется косвенно:
  ```python
  # Попытка получить куратора студента
  mentor = student.mentor
  # Или через Enrollment курса
  enrollment = Enrollment.query.filter_by(student_id=student.id).first()
  tutor = enrollment.tutor if enrollment else None
  ```

### 4.2. Статус: BLOCKED (Архитектурное ограничение)

Невозможно назначить разных преподавателей на разные индивидуальные уроки одного студента в рамках текущей схемы БД.  
**Для разблокировки в будущих релизах требуется миграция:**
Добавление `teacher_id = db.Column(db.Integer, db.ForeignKey('teachers.id'), nullable=True)` в таблицу `lessons`.

## 5. Валидация доменной логики календаря

Создан набор тестов `tests/v2/test_schedule_diagnostics_sprint1_3.py` (10 тестов), покрывающий краевые случаи доменной модели:

```
tests/v2/test_schedule_diagnostics_sprint1_3.py .......... [100%]
10 passed in 9.71s
```

### Результаты проверки доменных правил:

1. **`day.is_completed` (Статус дня):**
   День считается завершённым только тогда, когда все события этого дня завершены (`status == 'completed'`) и находятся в прошлом. Если в дне есть хотя бы одно незавершённое занятие или активный дедлайн — день не маркируется как `is_completed`.
2. **`free` (Дни отдыха):**
   При отсутствии назначенных уроков и дедлайнов день корректно помечается типом `free`, генерируется вдохновляющее описание («Свободный день — время повторить теорию») и нейтральный бейдж.
3. **Жизненный цикл домашних заданий:**
   Дедлайны ДЗ корректно отображаются в карточках дней и Hero-карточке со специфическими иконками (`ph-clock`, `ph-check-circle`), статусами `pending` / `submitted` / `graded` и ссылками в `/task_workspace/...`.
4. **Формула прогресса недели:**
   $$\text{Progress} = \text{round}\left(\frac{\text{Completed Lessons}}{\text{Completed} + \text{Scheduled Lessons}} \times 100\right)$$
   При 0 уроков прогресс равен 0% (деление на ноль защищено).
5. **Временные зоны и границы полуночи:**
   Проверено корректное соотнесение уроков в 23:30 и 00:30 UTC при конвертации в MSK и Tomsk (UTC+7).

## 9. Каталог реальных дефектов (Unvarnished Defect Catalog)

В отличие от предыдущих спринтов, здесь честно зафиксированы все визуальные и геометрические проблемы, выявленные при инспекции полученных скриншотов:

### ДЕФЕКТ 1 (Критический, High Severity): Наложение свернутого сайдбара на контент на планшетах (768×1024)
- **Скриншот:** `schedule_tablet_768x1024.png`
- **Суть проблемы:** На ширине 768px боковое меню переходит в свернутый режим (`w-16` / `w-20`), однако выпадающие или фиксированные подписи пунктов («Программа Мои курсы и уроки») вылезают вправо за пределы сайдбара с `z-index`, перекрывая левый край основной рабочей области: карточку понедельника, заголовок «Моё расписание» и стартовую станцию SVG-дороги.
- **Корневая причина:** В `layout_dashboard.html` контейнер сайдбара на брейкпоинте `md` не скрывает переполняющийся текст (`overflow-hidden` отсутствует на текстовых лейблах при свернутом состоянии).

### ДЕФЕКТ 2 (Высокий, High Severity): Сжатие 7-колоночной сетки на планшете (768×1024)
- **Скриншот:** `schedule_tablet_768x1024.png`
- **Суть проблемы:** Сетка `grid-cols-7` на ширине 768px оставляет на каждую карточку дня всего ~82–86px ширины.
- **Проявления:** 
  - Текст заголовков не помещается даже на двух строках и обрезается на полуслове («Рекурс алгор...», «Самост закрепл...»);
  - Блоки времени превращаются в «17:0...»;
  - Слово «Отдых» сжимается до «Отд...».
- **Корневая причина:** Дизайн-система переключает сетку в мобильный свайп-трек только на `sm` (< 640px), а на `md` (768px) сразу включает 7 колонок, для которых экран 768px физически слишком узок.
- **Решение для Sprint 1.4:** Продлить режим горизонтального свайп-трека или сделать адаптивную сетку 3+4 карточки для брейкпоинта `md` (до 1024px).

### ДЕФЕКТ 3 (Средний, Medium Severity): Обрезание правой части SVG-трассы на мобильных устройствах (360–430px)
- **Скриншоты:** `schedule_mobile_360x780.png`, `schedule_mobile_390x844.png`, `schedule_mobile_430x932.png`
- **Суть проблемы:** Исходный векторный ландшафт и трасса имеют координатную сетку шириной `1000px`. На экране смартфона 360–390px видна только левая треть трассы (станции Пн, Вт, Ср). Станции Пт, Сб, Вс и финишный флаг находятся далеко за правым краем экрана.
- **Проявления:** Пользователь на мобильном устройстве не видит конца недели и не понимает, что трассу можно скроллить, так как отсутствует визуальный градиентный хинт свайпа или мини-пагинатор.

### ДЕФЕКТ 4 (Средний, Medium Severity): Неудачный перенос длинных русских слов без дефисов
- **Скриншот:** `scenario_state_d_long_strings.png`
- **Суть проблемы:** Длинные термины ЕГЭ («Программирование», «Последовательности», «Рекурсивные») при адаптивном сужении карточек ломаются по случайным буквам («Программ-», «ирование») без использования мягких переносов.
- **Решение для Sprint 1.4:** Добавить CSS-свойство `hyphens: auto; -webkit-hyphens: auto;` и `overflow-wrap: break-word` в класс карточек `.day-card-tactile`.

### ДЕФЕКТ 5 (Низкий, Low Severity): Обрезание правого края подзаголовка страницы на смартфонах
- **Скриншот:** `schedule_mobile_360x780.png`
- **Суть проблемы:** Текст описания под заголовком «Моё расписание» («Ваш персональный учебный трек: онлайн-занятия, дедлайны п...») обрезается правым паддингом контейнера без многоточия.
- **Решение для Sprint 1.4:** Уменьшить размер шрифта на мобильных до `text-xs` и разрешить перенос на 2 строки.

### ДЕФЕКТ 6 (Низкий, Low Severity): Скрытый текст кнопки «Сегодня» на мобильных
- **Скриншоты:** мобильные разрешения
- **Суть проблемы:** На смартфонах кнопка «Сегодня» скрывает текст `<span>Сегодня</span>` (`hidden sm:inline`), оставляя только иконку прицела `ph-crosshair`. Для неопытных учеников значение этой пиктограммы неочевидно.
- **Решение для Sprint 1.4:** Использовать сокращенный текст «Сейч.» или оставить компактную текстовую пилюлю.
