Решение задания №3 ЕГЭ по информатике: Базы данных в Excel

Описание задания и теория баз данных

Задание №3 из ЕГЭ по информатике проверяет умение работать с реляционными базами данных в Excel. Требуется находить и анализировать информацию с помощью встроенных функций и формул. На его выполнение отводится примерно 3 минуты.

Основные понятия:

  • База данных (БД) — организованное хранилище данных, позволяющее эффективно их сохранять, управлять и извлекать.
  • Первичный ключ — уникальный идентификатор записи (однозначно определяет строку в таблице).
  • Внешний ключ — связывает записи разных таблиц, указывая на первичный ключ другой таблицы.

Типы связей между таблицами:

  • Один к одному (1:1): Каждая запись в одной таблице может быть связана только с одной записью в другой.
  • Один ко многим (1:N): Одна запись в первой таблице может быть связана с несколькими записями во второй таблице, но каждая запись во второй таблице связана только с одной записью в первой. (Именно этот тип чаще всего встречается в задании 3).
  • Многие ко многим (M:N): Записи в обеих таблицах могут быть связаны с несколькими записями в другой таблице.

Функция ВПР (VLOOKUP)

Функция ВПР (вертикальный поиск) находит заданное значение в первом столбце диапазона данных и возвращает соответствующее значение из другого столбца той же строки.

Синтаксис функции: =ВПР(Искомое_значение; Диапазон_таблицы; Номер_столбца; [Тип_совпадения])

  • Искомое_значение — значение, которое нужно найти.
  • Диапазон_таблицы — область данных, в которой выполняется поиск (включая первый столбец с искомыми значениями).
  • Номер_столбца — номер столбца диапазона, из которого возвращается результат.
  • Тип_совпадения — всегда используйте ЛОЖЬ для точного совпадения.

Разбор реального задания из демоверсии ФИПИ

Задание: Используя данные из базы в Excel, определите общую массу (в кг) всех видов зефира, поступившего в магазины, расположенные на проспекте Мира, за период с 5 по 19 июня 2023 года включительно. В ответе укажите только число (массу в килограммах).

Шаг 1 Сбор данных в одну таблицу

Оптимально собрать все нужные данные в главной таблице — «Движение товаров». Для этого используем функцию ВПР.

  • В столбец G добавляем Адрес магазина:
    =ВПР(C2; Магазин!A:C; 3; ЛОЖЬ)
    Где C2 — ID магазина, 3 — номер столбца с адресом в таблице «Магазин».
  • В столбец H добавляем Наименование товара:
    =ВПР(D2; Товар!A:F; 3; ЛОЖЬ)
  • В столбец I добавляем Единицу измерения:
    =ВПР(D2; Товар!A:F; 4; ЛОЖЬ)
  • В столбец J добавляем Количество в упаковке:
    =ВПР(D2; Товар!A:F; 5; ЛОЖЬ)

Шаг 2 Расчёт массы упаковок

Рассчитаем массу зефира. Если единица измерения указана в граммах, умножаем количество упаковок на массу одной упаковки и переводим в килограммы (разделив на 1000). В столбец K пишем формулу:

=ЕСЛИ(I2="грамм"; J2/1000*E2; 0)

Шаг 3 Фильтрация данных

Выделим заголовки таблицы и включим «Фильтр» (Главная → Сортировка и фильтр). Настроим условия:

  • Дата: оставляем только с 5 по 19 июня 2023 года.
  • Тип операции: оставляем «Поступление».
  • Адрес магазина: выбираем магазины на проспекте Мира.
  • Наименование товара: отмечаем все виды зефира (в шоколаде, ванильный, воздушный, лимонный).

Шаг 4 Подсчёт общей массы

После применения фильтров останутся только нужные строки. Кликните по заголовку столбца K (Масса), чтобы выделить его целиком. Внизу окна Excel, в строке состояния, автоматически отобразится Сумма.
