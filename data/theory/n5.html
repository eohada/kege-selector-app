Задание 5: Анализ и построение алгоритмов

Задание 5 проверяет умение формально исполнять алгоритмы, описанные на естественном языке, и анализировать их результаты. Чаще всего алгоритм связан с преобразованием чисел из десятичной системы в двоичную и выполнением действий над строками.

1. Основы работы с системами счисления в Python

Для решения задания программным методом необходимо быстро переводить числа между системами счисления.

Встроенные функции перевода (10 → n):

  • bin(n) — перевод в двоичную (возвращает строку вида '0b1010').
  • oct(n) — перевод в восьмеричную (возвращает строку вида '0o12').
  • hex(n) — перевод в шестнадцатеричную (возвращает строку вида '0xa').
Важно: Все эти функции добавляют технический префикс (0b, 0o, 0x). Чтобы получить чистое значение, используйте срез [2:]:
s = bin(n)[2:]

Обратный перевод (n → 10):

Используется функция int(string, base), где string — число в виде строки, а base — основание системы.

n = int('1010', 2)  # Результат: 10
n = int('AF1', 16)   # Результат: 2801

2. Методы строк для алгоритмов

Алгоритмы в задании 5 часто требуют манипуляций с "цифрами" записи числа:

  • Подсчет единиц: s.count('1') — критически важно для условий четности суммы цифр в двоичной записи.
  • Добавление в конец: s += '10' или s = s + '0'.
  • Замена: s.replace('1', '0') (заменяет все единицы на нули).

3. Типовой алгоритм решения

Обычно решение сводится к перебору чисел N в цикле for:

for n in range(1, 1000):
    s = bin(n)[2:] # Шаг 1: перевод в 2-ичную
    
    # Шаг 2: модификация по условию (например, сумма цифр)
    if s.count('1') % 2 == 0:
        s = s + '0'
    else:
        s = s + '1'
        
    r = int(s, 2) # Шаг 3: перевод обратно в 10-ичную
    
    if r > 43: # Шаг 4: проверка условия
        print(n)
        break

4. Продвинутые техники: Произвольные системы счисления

Если в задании требуется перевести число в систему счисления, отличную от 2, 8 или 16 (например, в 3-ичную или 7-ичную), встроенных функций не хватит. В этом случае необходимо написать собственную функцию на основе алгоритма деления с остатком.

Собственная функция перевода (на примере 7-ичной системы):

Алгоритм последовательно берет остатки от деления и записывает их в строку, после чего разворачивает её.

def perevod(n):
    t = ''
    while n > 0:
        t += str(n % 7) # Добавляем остаток
        n //= 7          # Целочисленное деление
    return t[::-1]      # Разворачиваем строку

Работа со срезами для разворота строки:

В Python строки являются неизменяемыми последовательностями, и для их инверсии (разворота) удобнее всего использовать срез с отрицательным шагом.

  • Синтаксис среза: [start:stop:step]
  • t[::-1] — это сокращенная запись, которая означает: "взять всю строку от начала до конца с шагом -1".
При делении "в столбик" мы получаем цифры числа в обратном порядке (от младших к старшим). Именно поэтому использование [::-1] в функции перевода является обязательным для получения корректного результата.
