## Easy

*Тема: Параллельные вычисления*

### Условие

В файле содержится информация о совокупности вычислительных процессов, которые могут выполняться параллельно или последовательно. Формат файла: ID процесса, Время выполнения (мс), ID процессов-предков (разделитель — точка с запятой). Если процесс независимый, указан 0.  Определите минимальное время (в мс), через которое завершатся  все  процессы.

### Решение

### Шаг 1

Считаем данные. Структура файла: `ID; Time; Deps`. Разделитель в Deps — точка с запятой.

```python
data = {}
with open('22_easy.csv') as f:
    for line in f:
        # Удаляем лишние пробелы и разбиваем
        parts = line.strip().split(';')
        pid = int(parts[0])
        time = int(parts[1])
        # Предки могут быть '0' или '1;2'
        if parts[2] == '0':
            deps = []
        else:
            # Обработка '1; 2' -> [1, 2]
            deps = [int(x) for x in parts[2].split(';') if x.strip().isdigit()]
        
        data[pid] = {'time': time, 'deps': deps, 'end': 0}
```

### Шаг 2

Для вычисления времени завершения процесса нужно знать время завершения всех его предков. 
$End(P) = Time(P) + \max(End(Dep_1), End(Dep_2), \dots)$. 
Используем рекурсию с мемоизацией (или просто словарь, так как ID идут обычно по порядку, но рекурсия надежнее).

```python
def get_end_time(pid):
    if data[pid]['end'] > 0:
        return data[pid]['end']
    
    # Время старта = макс время завершения предков
    start_time = 0
    if data[pid]['deps']:
        start_time = max(get_end_time(dep) for dep in data[pid]['deps'])
    
    data[pid]['end'] = start_time + data[pid]['time']
    return data[pid]['end']

# Вычисляем для всех процессов
max_total = 0
for pid in data:
    max_total = max(max_total, get_end_time(pid))

print(max_total)
```

### Альтернативные решения

**Решение программой (Python):**

1. Полный код решения.

**Решение в Excel:**

1. Открываем файл. Столбцы: A (ID), B (Время), C (Предки).

2. Если предков несколько (через точку с запятой), Excel не поймет это как числа. В Easy задачах обычно 1 предок или 0. 
Пусть в столбце D будет время окончания. 
D2: `=B2 + ВПР(C2; A:D; 4; 0)`. 
Если C2=0, то просто `=B2` (используйте ЕСЛИ).

3. Ответ = МАКС(столбец D).

**Ответ:** `805`

## Medium

*Тема: Параллельные вычисления*

### Условие

Файл содержит информацию о процессах. В столбце 'Предки' могут быть перечислены несколько ID через точку с запятой. Пример:  3;4 .  Определите минимальное время завершения всех процессов.

### Решение

### Шаг 1

Парсинг файла усложняется наличием `;` в поле зависимостей.

```python
data = {}
with open('22_medium.csv') as f:
    for line in f:
        parts = line.strip().split(';')
        pid = int(parts[0])
        time = int(parts[1])
        # Все оставшиеся части строки — это предки (если формат ID;Time;Dep1;Dep2...)
        # Или если формат ID;Time;"Dep1;Dep2"
        # Предположим формат CSV, где предки в одной ячейке или в нескольких.
        # Обычно в ЕГЭ: ID <tab> Time <tab> Dep1;Dep2
        # Реализуем универсально:
        deps_str = parts[2] if len(parts) > 2 else "0"
        deps = [int(x) for x in deps_str.replace('"','').split(';') if x.isdigit()] if deps_str != "0" else []
        data[pid] = {'t': time, 'd': deps, 'end': None}
```

### Шаг 2

Рекурсивная функция.

```python
def solve(pid):
    if data[pid]['end'] is not None: return data[pid]['end']
    
    start = 0
    if data[pid]['d']:
        start = max(solve(dep) for dep in data[pid]['d'])
    
    data[pid]['end'] = start + data[pid]['t']
    return data[pid]['end']

print(max(solve(pid) for pid in data))
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Код выше.

**Решение в Excel:**

1. Если предки в одной ячейке ('3;4'), Excel не сможет их сразу обработать. Нужно использовать 'Данные -> Текст по столбцам', чтобы разбить предков на отдельные колонки (C, D, E...).

2. Формула времени завершения (в столбце Z, например): `=B2 + МАКС(ВПР(C2...); ВПР(D2...); ВПР(E2...))`.
Чтобы ВПР не ломался на пустых ячейках, используйте `ЕСЛИОШИБКА(ВПР(...); 0)`.

**Ответ:** `1254`

## Hard

*Тема: Параллельные вычисления*

### Условие

Дана таблица процессов. Определите  максимальное количество процессов , которые могут выполняться  параллельно  (одновременно) при условии, что каждый процесс начинается  как можно раньше  (сразу после завершения всех его предков).

### Решение

### Шаг 1

Сначала вычислим время начала и окончания для каждого процесса (как в Easy/Medium).

```python
# ... (чтение и расчет data[pid]['start'] и data[pid]['end']) ...
# Допустим, мы вычислили start и end для каждого pid.
# data[pid] = {'start': 10, 'end': 15, ...}
```

### Шаг 2

Теперь нужно пройти по временной шкале и посчитать пересечения. Создадим массив (таймлайн) или словарь событий.

```python
events = []
for pid in data:
    # Процесс начинается в start (включая эту мс) и заканчивается в end (включая или нет?)
    # Обычно процесс длится [start, end). То есть в момент end он уже не активен.
    # Добавим +1 к счетчику в start, -1 в end.
    events.append((data[pid]['start'], 1))
    events.append((data[pid]['end'], -1))

events.sort() # Сортируем по времени

max_parallel = 0
current_parallel = 0

for time, change in events:
    current_parallel += change
    max_parallel = max(max_parallel, current_parallel)

print(max_parallel)
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Код с событиями (scanline).

**Решение в Excel:**

1. Рассчитайте Start и End для каждого процесса (два столбца).

2. Сложный способ: создать диаграмму Ганта (условное форматирование). По горизонтали время (1, 2, 3...), по вертикали процессы. Закрасить ячейки, где процесс идет. 
Внизу просуммировать столбцы. Найти макс сумму.

**Ответ:** `1953`
