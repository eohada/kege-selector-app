# Задание 8

## Easy

*Тема: Комбинаторика*

### Условие

Все 4-буквенные слова, составленные из букв  К, Л, Р, Т , записаны в алфавитном порядке и пронумерованы, начиная с 1.  Вот начало списка:   КККК  КККЛ  КККР  КККТ  ККЛК  ...   Под каким номером в списке идёт слово  ТРКЛ ?

### Решение

### Шаг 1

Задачу можно решить перебором с помощью Python. Нам нужно сгенерировать все слова в том же порядке (алфавитном), считать их и остановиться, когда встретим 'ТРКЛ'.

```python
from itertools import product

# Буквы в алфавитном порядке: К, Л, Р, Т
alphabet = 'КЛРТ'

count = 0
for word_tuple in product(alphabet, repeat=4):
    count += 1
    word = ''.join(word_tuple)
    if word == 'ТРКЛ':
        print(count)
        break
```

### Шаг 2

Важно: буквы в `product` или в строке `alphabet` должны быть строго отсортированы по алфавиту, как в условии (К, Л, Р, Т).

---

### Альтернативные решения

**Ручной способ (Системы счисления):**

1. Закодируем буквы цифрами от 0 по порядку алфавита:
К -> 0
Л -> 1
Р -> 2
Т -> 3

2. Слово 'ТРКЛ' превращается в число в четверичной системе счисления (так как 4 буквы): 3201₄.

3. Переведем в десятичную: $3 \cdot 4^3 + 2 \cdot 4^2 + 0 \cdot 4^1 + 1 \cdot 4^0 = 3 \cdot 64 + 2 \cdot 16 + 0 + 1 = 192 + 32 + 1 = 225$.

4. Так как нумерация в списке начинается с 1 (а в системе счисления с 0), к полученному числу нужно добавить 1. Ответ: 225 + 1 = 226.

**Ответ:** `226`

## Medium

*Тема: Комбинаторика*

### Условие

Определите количество 5-буквенных слов, записанных в алфавитном порядке и составленных из букв  Л, Е, Т, О , в которых буква  Е  встречается ровно 2 раза, а буква  Т  не встречается ни разу.

### Решение

### Шаг 1

Используем `itertools.product` для перебора всех вариантов. Буквы берем отсортированные: 'Е', 'Л', 'О', 'Т'.

```python
from itertools import product

# Алфавит: ЕЛОТ (сортировка важна, если бы мы искали номер, тут просто количество, но лучше привыкать сортировать)
alphabet = sorted('ЛЕТО') 
count = 0

for word_tuple in product(alphabet, repeat=5):
    word = ''.join(word_tuple)
    
    # Условие 1: Е встречается ровно 2 раза
    cond1 = word.count('Е') == 2
    # Условие 2: Т не встречается
    cond2 = 'Т' not in word
    
    if cond1 and cond2:
        count += 1
        
print(count)
```

### Шаг 2

Запускаем код и получаем ответ.

---

### Альтернативные решения

**Ручной способ (Комбинаторика):**

1. Слово длины 5. Букв в алфавите 4: Л, Е, Т, О. 
Условие: Т нет. Значит, алфавит сократился до 3 букв: Л, Е, О.

2. Условие: Е ровно 2 раза. Остальные 3 позиции заняты буквами Л или О (2 варианта).

3. Выберем места для двух букв Е. Это число сочетаний из 5 по 2: $C_5^2 = \frac{5 \cdot 4}{2} = 10$ способов.

4. На оставшихся 3 позициях могут стоять любые буквы из {Л, О}. Всего $2^3 = 8$ вариантов расстановки.

5. Итого: $10 \cdot 8 = 80$ слов.

**Ответ:** `80`

## Hard

*Тема: Комбинаторика*

### Условие

Все 5-буквенные слова, составленные из букв  П, А, Р, У, С , записаны в алфавитном порядке и пронумерованы, начиная с 1. Начало списка:   ААААА  ААААП  ААААР  ...   Под каким номером в списке идёт  последнее  слово, которое содержит  не более одной  буквы У и  не содержит  двух букв А, стоящих рядом?

### Решение

### Шаг 1

Для поиска *последнего* слова удобно перебирать список, обновляя переменную с номером при каждом совпадении, или собрать все номера и взять max().

```python
from itertools import product

# 1. Алфавит. В условии сказано 'записаны в алфавитном порядке'.
# Буквы П, А, Р, У, С. Сортируем их: А, П, Р, С, У.
alphabet = sorted('ПАРУС') 

count = 0
last_number = 0

for word_tuple in product(alphabet, repeat=5):
    count += 1
    word = ''.join(word_tuple)
    
    # Условие 1: не более одной 'У' (<= 1)
    cond1 = word.count('У') <= 1
    
    # Условие 2: нет 'АА'
    cond2 = 'АА' not in word
    
    if cond1 and cond2:
        last_number = count
        # Мы не делаем break, так как нам нужно ПОСЛЕДНЕЕ слово
        
print(last_number)
```

### Шаг 2

Важный момент: так как мы идем по возрастанию номеров, последнее найденное подходящее слово и будет иметь максимальный номер. Можно просто перезаписывать `last_number`.

---

### Альтернативные решения

**Ручной способ (Анализ с конца):**

1. Чтобы найти последнее слово, можно перебирать слова с конца списка (от 'УУУУУ' вниз). Первое подошедшее будет ответом.

2. Но ручной перебор сложен из-за условия 'АА'. Проще написать код.

**Ответ:** `2969`
