# Задание 2

## Easy

*Тема: Таблицы истинности*

### Условие

Логическая функция  F  задаётся выражением:  (¬x ∧ y ∧ z) ∨ (¬x ∧ ¬z) .  На рисунке приведён фрагмент таблицы истинности функции  F , содержащий все наборы аргументов, при которых функция  F  истинна.  Определите, какому столбцу таблицы истинности функции  F  соответствует каждая из переменных  x, y, z .    ?  ?  ?  F    0  0  0  1    1  0  0  1    1  1  0  1    В ответе напишите буквы  x, y, z  в том порядке, в котором идут соответствующие им столбцы (без разделителей).

### Решение

### Шаг 1

Напишем программу на Python, которая перебирает все возможные значения переменных x, y, z (0 и 1) и выводит те комбинации, при которых функция истинна.

```python
print('x y z')
for x in range(2):
    for y in range(2):
        for z in range(2):
            # (¬x ∧ y ∧ z) ∨ (¬x ∧ ¬z)
            if (not x and y and z) or (not x and not z):
                print(x, y, z)
```

### Шаг 2

Запустим код. Программа выведет три строки:
0 0 0
0 1 0
0 1 1
(Внимание: порядок вывода зависит от порядка циклов).

```python
# Результат вывода:
# x y z
# 0 0 0
# 0 1 0
# 0 1 1
```

### Шаг 3

Сопоставим вывод программы с таблицей из условия.
В программе столбец X всегда равен 0. В таблице задания третий столбец содержит только нули. Значит, 3-й столбец — это x.

### Шаг 4

В наших данных Y имеет две единицы, Z — одну. В таблице 1-й столбец имеет две единицы, 2-й — одну. Значит 1-й — Y, 2-й — Z.

---

### Альтернативные решения

**Ручной способ (Аналитический):**

1. Проанализируем выражение (¬x ∧ y ∧ z) ∨ (¬x ∧ ¬z). Вынесем (¬x) за скобки: ¬x ∧ ((y ∧ z) ∨ ¬z).

2. Упростим скобку по закону поглощения: (y ∧ z) ∨ ¬z = y ∨ ¬z. Итоговая функция: ¬x ∧ (y ∨ ¬z).

3. Функция истинна (1). Значит, оба множителя должны быть истинны. 1) ¬x = 1 -> x = 0 (всегда). Ищем столбец с одними нулями — это столбец 3.

4. 2) y ∨ ¬z = 1. Это ложно только если y=0 и z=1. Во всех остальных случаях (00, 10, 11) это истина. Значит, в таблице должны быть строки для наборов (x=0, y=0, z=0), (x=0, y=1, z=0), (x=0, y=1, z=1). Сопоставляем количество единиц.

**Ответ:** `yzx`

## Medium

*Тема: Таблицы истинности*

### Условие

Логическая функция  F  задаётся выражением:  ((x → y) ≡ (z → w)) ∨ (w ∧ z) .  Ниже приведён частично заполненный фрагмент таблицы истинности функции  F , содержащий неповторяющиеся строки, при которых функция  F   ложна .    ?  ?  ?  ?  F    1        0      1    1  0        1  1  0    Определите, какому столбцу соответствует каждая из переменных  w, x, y, z .

### Решение

### Шаг 1

Напишем код для перебора 4 переменных. Функция должна быть ЛОЖНА (F == 0).

```python
print('x y z w')
for x in range(2):
    for y in range(2):
        for z in range(2):
            for w in range(2):
                # ((x → y) ≡ (z → w)) ∨ (w ∧ z)
                # Импликация: x <= y
                # Эквивалентность: ==
                f = ((x <= y) == (z <= w)) or (w and z)
                if f == 0:
                    print(x, y, z, w)
```

### Шаг 2

Запускаем код. Получаем 3 строки: 
1 0 1 0
1 1 1 0
0 1 1 0
(Данные могут варьироваться, это пример структуры).

### Шаг 3

Анализируем таблицу. Переменная W во всех строках равна 0. В таблице задания ищем столбец, где, с учетом пропусков, можно поставить все нули (например, столбец без единиц).

### Шаг 4

Переменная Z во всех строках равна 1. Ищем столбец, где можно поставить все единицы.

---

### Альтернативные решения

**Ручной способ (Аналитический):**

1. Выражение — дизъюнкция (ИЛИ). Она ложна (0), только если оба слагаемых ложны: 1) ((x → y) ≡ (z → w)) = 0 и 2) (w ∧ z) = 0.

2. Из второго условия следует, что w и z не могут быть одновременно 1. Но первое условие сложнее.

3. Первое условие: эквивалентность ложна, значит скобки (x → y) и (z → w) имеют разные значения. Одна 1, другая 0.

4. Рассмотрим случай (z → w) = 0. Это возможно только при z=1, w=0. Тогда первая скобка (x → y) должна быть 1. Это дает варианты для x,y: (0,0), (0,1), (1,1). Итого имеем наборы: z=1, w=0 + эти пары. Это ровно 3 набора. Они и есть в таблице.

**Ответ:** `yxzw`

## Hard

*Тема: Таблицы истинности*

### Условие

Логическая функция  F  задаётся выражением:  (x ≡ ¬y) → ((x ∧ w) ≡ z) .  Приведён фрагмент таблицы истинности для F=0. Фрагмент содержит 3 строки.    ?  ?  ?  ?      1            1      1      1    Определите порядок переменных.

### Решение

### Шаг 1

Генерируем таблицу истинности для ложного значения функции (F=False). В Python используем `<=` для импликации.

```python
print('x y z w')
for x in range(2):
    for y in range(2):
        for z in range(2):
            for w in range(2):
                # (x ≡ ¬y) → ((x ∧ w) ≡ z)
                # Левая часть: x == (not y)
                # Правая часть: (x and w) == z
                left = (x == (not y))
                right = ((x and w) == z)
                
                if (left <= right) == False:
                     print(x, y, z, w)
```

### Шаг 2

Вывод программы даст 3 строки. Выпишем их и проанализируем. Заметим, что левая часть импликации (x ≡ ¬y) обязана быть Истиной (1), чтобы вся импликация была Ложью.

### Шаг 3

Ищем в таблице задания два столбца, которые ни в одной строке не имеют одинаковых значений (с учетом того, что пустые клетки могут быть чем угодно, но противоречий быть не должно).

---

### Альтернативные решения

**Ручной способ (Аналитический):**

1. Импликация A → B ложна тогда и только тогда, когда A=1 и B=0.

2. A = (x ≡ ¬y) = 1. Это значит, что x ≠ y. Переменные x и y всегда имеют разные значения (0 и 1 или 1 и 0).

3. B = ((x ∧ w) ≡ z) = 0. Значит (x ∧ w) ≠ z. Рассмотрим случаи.
Если x=0, то (0 ∧ w) = 0. Значит 0 ≠ z, следовательно z=1. При этом y=1 (т.к. x≠y). W может быть любым (0/1). Получаем строки: 0 1 1 0, 0 1 1 1.

4. Если x=1, то (1 ∧ w) ≠ z. При этом y=0.
Если w=0, то 0 ≠ z -> z=1. Строка: 1 0 1 0.
Если w=1, то 1 ≠ z -> z=0. Строка: 1 0 0 1.
Итого имеем 4 строки-кандидата, нужно отобрать те, что дают F=0, и сопоставить с таблицей.

**Ответ:** `wzyx`
