## Easy

*Тема: Кодирование графической информации*

### Условие

Какой минимальный объём памяти (в Кбайт) нужно зарезервировать, чтобы можно было сохранить любое растровое изображение размером  320×240  пикселей при условии, что в изображении могут использоваться  256  различных цветов? В ответе запишите только целое число.

### Решение

### Шаг 1

Сначала определим глубину цвета (i). По формуле Хартли: $N = 2^i$. У нас N = 256 цветов. 256 = 2^8, значит i = 8 бит на пиксель.

```python
import math
N = 256
i = int(math.log2(N))
print(f"Глубина цвета: {i} бит")
```

### Шаг 2

Вычислим общий объем в битах: $V = x \cdot y \cdot i$. Размеры 320x240.

```python
x = 320
y = 240
V_bits = x * y * i
print(f"Объем в битах: {V_bits}")
```

### Шаг 3

Переведем биты в Кбайты. 
1 байт = 8 бит.
1 Кбайт = 1024 байта.
Сначала делим на 8, потом на 1024.

```python
V_bytes = V_bits / 8
V_kb = V_bytes / 1024
print(f"Объем в Кбайт: {V_kb}")
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Простой скрипт для расчета.

**Ручной способ:**

1. i = log2(256) = 8 бит = 1 байт.

2. Объем V = 320 * 240 * 1 байт. 
Для перевода в Кбайт делим на 1024. 
320 * 240 / 1024.
Сократим: 320 = 10 * 32, 240 = 240.
Или просто: 76800 байт / 1024 = 75 Кбайт.

**Ответ:** `75`

## Medium

*Тема: Кодирование звуковой информации*

### Условие

Производится двухканальная (стерео) звукозапись с частотой дискретизации 48 кГц и 24-битным разрешением. Запись длится 2 минуты. Сжатие данных не производится.  Определите приблизительный размер полученного файла в  Мбайтах . В качестве ответа укажите ближайшее к полученному значению целое число.

### Решение

### Шаг 1

Выпишем параметры:
k = 2 (стерео)
f = 48 кГц = 48000 Гц
i = 24 бит
t = 2 мин = 120 сек

### Шаг 2

Формула объема: $V = k \cdot f \cdot i \cdot t$. Подставим значения.

```python
k = 2
f = 48000
i = 24
t = 120
V_bits = k * f * i * t
print(f"Биты: {V_bits}")
```

### Шаг 3

Переведем в Мбайты. 
Биты -> Байты (/8) -> Кбайты (/1024) -> Мбайты (/1024).

```python
V_mbytes = V_bits / 8 / 1024 / 1024
print(f"Мбайты: {V_mbytes}")
print(f"Округленно: {round(V_mbytes)}")
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Скрипт для расчета.

**Ручной способ:**

1. V = 2 * 48000 * 24 * 120 бит.

2. Делим на 8: 2 * 48000 * 3 * 120 байт (так как 24/8=3).
Делим на 1024*1024 (1 048 576). 
Числитель: 2 * 48000 * 360 = 34 560 000.
34 560 000 / 1 048 576 ≈ 32.95.
Ближайшее целое: 33.

**Ответ:** `33`

## Hard

*Тема: Передача информации*

### Условие

Прибор автоматической фиксации нарушений делает цветные фотографии размером  1024×960  пикселей, используя палитру из  8192  цветов. Снимки группируются в пакеты по  160  штук и передаются в центр со скоростью  14 680 064  бит/с.  Сколько  секунд  потребуется для передачи одного пакета фотографий? В ответе укажите только целую часть полученного значения.

### Решение

### Шаг 1

Найдем вес одной фотографии. 
Размер: 1024x960.
Палитра 8192 цвета. i = log2(8192) = 13 бит.

```python
import math
x = 1024
y = 960
N = 8192
i = int(math.log2(N)) # 13
size_one = x * y * i # бит
```

### Шаг 2

Найдем вес пакета. В пакете 160 фото.

```python
count = 160
total_size = size_one * count
```

### Шаг 3

Найдем время передачи. t = Q / v.
Скорость v = 14 680 064 бит/с.

```python
v = 14680064
t = total_size / v
print(int(t)) # Целая часть
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Скрипт полностью повторяет логику ручного решения, но исключает арифметические ошибки.

**Ручной способ:**

1. i = 13 бит.
Объем 1 фото = 1024 * 960 * 13 = 12 779 520 бит.

2. Пакет = 12 779 520 * 160 = 2 044 723 200 бит.

3. Время = 2 044 723 200 / 14 680 064 ≈ 139.28.
Целая часть: 139.

**Ответ:** `139`
