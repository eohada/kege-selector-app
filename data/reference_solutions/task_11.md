# Задание 11

## Easy

*Тема: Вычисление количества информации*

### Условие

При регистрации в компьютерной системе каждому пользователю выдаётся пароль, состоящий из  15  символов и содержащий только символы из  8 -символьного набора: А, В, C, D, E, F, G, H.  В базе данных для хранения сведений о каждом пользователе отведено одинаковое и минимально возможное целое число  байт . При этом используют посимвольное кодирование паролей, все символы кодируют одинаковым и минимально возможным количеством бит.  Кроме собственно пароля, для каждого пользователя в системе хранятся дополнительные сведения, для чего отведено  12  байт на одного пользователя.  Определите объём памяти (в байтах), необходимый для хранения сведений о  50  пользователях. В ответе запишите только целое число.

### Решение

### Шаг 1

Сначала найдем глубину кодирования одного символа (i). Мощность алфавита N = 8. Формула Хартли: $N = 2^i$. $8 = 2^3$, значит i = 3 бита на символ.

```python
import math
N = 8
i = math.ceil(math.log2(N)) # i = 3
print(f"Бит на символ: {i}")
```

### Шаг 2

Найдем объем пароля в битах. Длина пароля L = 15 символов. $V_{bits} = L \cdot i = 15 \cdot 3 = 45$ бит.

```python
L = 15
v_pass_bits = L * i # 45
print(f"Объем пароля (бит): {v_pass_bits}")
```

### Шаг 3

Переведем объем пароля в байты (по условию: целое число байт на пароль). 1 байт = 8 бит. Делим 45 на 8 и округляем ВВЕРХ (так как нужно уместить все биты). $45 / 8 = 5.625 \to 6$ байт.

```python
v_pass_bytes = math.ceil(v_pass_bits / 8) # 6
print(f"Объем пароля (байт): {v_pass_bytes}")
```

### Шаг 4

Добавим доп. сведения (12 байт). Общий объем на одного пользователя: $V_{user} = 6 + 12 = 18$ байт.

```python
v_extra = 12
v_user = v_pass_bytes + v_extra # 18
```

### Шаг 5

Умножим на количество пользователей (50). $V_{total} = 18 \cdot 50 = 900$ байт.

```python
users = 50
v_total = v_user * users
print(v_total)
```

---

### Альтернативные решения

**Ручной способ:**

1. 1. i = log2(8) = 3 бита.

2. 2. Пароль = 15 * 3 = 45 бит.

3. 3. Байты = 45 / 8 -> 6 байт (округляем вверх).

4. 4. Один юзер = 6 + 12 = 18 байт.

5. 5. Всего = 18 * 50 = 900.

**Ответ:** `900`

## Medium

*Тема: Вычисление количества информации*

### Условие

Каждый объект, зарегистрированный в информационной системе, получает уникальный код из  11  символов, содержащий только заглавные латинские буквы (всего 26) и десятичные цифры (всего 10).  В базе данных для хранения каждого кода отведено минимально возможное целое число  байт . При этом используется посимвольное кодирование, все символы кодируются одинаковым минимально возможным количеством бит.  Кроме кода, для каждого объекта в системе хранятся дополнительные сведения, занимающие  24  байта.  Определите объём памяти (в байтах), необходимый для хранения сведений о  40  объектах.

### Решение

### Шаг 1

Мощность алфавита N = 26 (буквы) + 10 (цифры) = 36 символов. Находим i: $2^i \ge 36$. Ближайшая степень двойки — 64 ($2^6$). Значит i = 6 бит.

```python
import math
N = 26 + 10 # 36
i = math.ceil(math.log2(N)) # 6
```

### Шаг 2

Объем кода в битах: $11 \cdot 6 = 66$ бит.

```python
L = 11
v_code_bits = L * i # 66
```

### Шаг 3

Перевод в байты: $66 / 8 = 8.25 \to 9$ байт.

```python
v_code_bytes = math.ceil(v_code_bits / 8) # 9
```

### Шаг 4

Один объект: $9 + 24 = 33$ байта. Всего 40 объектов: $33 \cdot 40 = 1320$ байт.

```python
v_extra = 24
v_obj = v_code_bytes + v_extra
total = v_obj * 40
print(total)
```

---

### Альтернативные решения

**Ручной способ:**

1. Алфавит: 26+10=36. i=6 бит (т.к. 2^5=32 мало, 2^6=64 норм).

2. Код: 11 * 6 = 66 бит.

3. Байты: 66/8 = 8 с остатком -> 9 байт.

4. Всего: (9 + 24) * 40 = 33 * 40 = 1320.

**Ответ:** `1320`

## Hard

*Тема: Вычисление количества информации*

### Условие

При регистрации в компьютерной системе каждому объекту присваивается идентификатор, состоящий из  317  символов. Для его формирования используются:   десятичные цифры (10 символов);  специальный алфавит из  4090  символов.   В базе данных для хранения каждого идентификатора отводится одинаковое и минимально возможное целое число  байт . Используется посимвольное кодирование.  Определите объём памяти (в  Мбайтах ), необходимый для хранения  262 144  таких идентификаторов. В ответе запишите только целое число.

### Решение

### Шаг 1

Мощность алфавита $N = 10 + 4090 = 4100$. Найдем i: $2^i \ge 4100$. $2^{12} = 4096$ (мало), $2^{13} = 8192$ (хватает). i = 13 бит.

```python
import math
N = 10 + 4090
i = math.ceil(math.log2(N)) # 13
```

### Шаг 2

Объем одного ID в битах: $317 \cdot 13 = 4121$ бит.

```python
L = 317
v_bits = L * i # 4121
```

### Шаг 3

Перевод в байты: $4121 / 8 = 515.125 \to 516$ байт.

```python
v_bytes = math.ceil(v_bits / 8) # 516
```

### Шаг 4

Общий объем: $516 \cdot 262144$ байт. Переводим в Мбайты: делим на $1024^2$. $262144 = 2^{18}$, $1024^2 = 2^{20}$. $516 \cdot 2^{18} / 2^{20} = 516 / 4 = 129$.

```python
count = 262144
total_bytes = v_bytes * count
total_mb = total_bytes / (1024 * 1024)
print(int(total_mb))
```

---

### Альтернативные решения

**Ручной способ (Степени двойки):**

1. N=4100 -> i=13 бит.

2. ID = 317 * 13 = 4121 бит. В байтах: 4121/8 = 515.125 -> 516 байт.

3. Всего = 516 * 262144. Заметим, что 262144 = 2^18 (так как 1024=2^10, 262тыс это 2^18). 1 Мбайт = 2^20 байт.

4. Мбайты = (516 * 2^18) / 2^20 = 516 / 2^2 = 516 / 4 = 129.

**Ответ:** `129`
