## Easy

*Тема: Алгоритмы для исполнителей*

### Условие

На вход алгоритма подаётся натуральное число  N . Алгоритм строит по нему новое число  R  следующим образом:   Строится двоичная запись числа  N .  К этой записи дописываются разряды по следующему правилу:  если число  N   чётное , то к двоичной записи слева дописывается '10';  если число  N   нечётное , то к двоичной записи слева дописывается '1', а справа '01'.    Полученная таким образом запись (в ней на 2 или 3 разряда больше, чем в записи исходного числа  N ) является двоичной записью искомого числа  R .   Укажите  минимальное  число  N , после обработки которого с помощью этого алгоритма получается число  R , большее 516. В ответе запишите это число в десятичной системе счисления.

### Решение

### Шаг 1

Алгоритм поиска минимального N. Переберем числа, начиная с 1, выполним условия задачи для каждого и проверим результат.

```python
for N in range(1, 1000):
    # 1. Двоичная запись (срез [2:] убирает префикс '0b')
    bin_n = bin(N)[2:]
    
    # 2. Обработка по условию
    if N % 2 == 0:
        r_bin = '10' + bin_n
    else:
        r_bin = '1' + bin_n + '01'
        
    # 3. Перевод обратно в десятичную
    R = int(r_bin, 2)
    
    # 4. Проверка условия
    if R > 516:
        print(N)
        break
```

### Шаг 2

Запускаем код. Цикл остановится на первом подходящем N, так как мы идем по возрастанию (range(1, 1000)). Выведенное число и есть минимальное.

---

### Альтернативные решения

**Решение программой (Python):**

1. Используем цикл for для перебора N. Внутри цикла реализуем логику автомата строковыми методами.

**Ручной способ (Анализ битов):**

1. Число 516 переведем в двоичную систему. 512 = 2^9 (1000000000). 516 = 512 + 4 = 1000000100.

2. Нам нужно R > 1000000100. Ищем минимальное такое R, которое могло получиться из какого-то N.
Рассмотрим длину. Исходное R имеет 10 бит. 
Если N четное, добавляется '10' слева (2 бита). Значит N было 8 бит.
Если N нечетное, добавляется '1' слева и '01' справа (3 бита). Значит N было 7 бит.

3. Попробуем найти N среди 7-битных (нечетных). Результат начинается на '1...'. 516 тоже начинается на '1...'.
Попробуем найти N среди 8-битных (четных). Результат начинается на '10...'.
Наше число 516 = 1000000100 начинается на '10'. Это похоже на случай четного N.
Если N четное, R = '10' + bin(N). 
То есть R должно выглядеть как 10xxxxxxx. 
Сравним: 1000000100 (это 516). 
Если мы возьмем 1000000101 (517), это подходит под маску '10...'? Да. 
Отбрасываем '10' слева. Остается 00000101. Это 5.
Проверяем N=5. Оно нечетное! А мы предполагали четное. Противоречие.
Ищем дальше.

**Ответ:** `33`

## Medium

*Тема: Алгоритмы для исполнителей*

### Условие

Автомат обрабатывает натуральное число  N  по следующему алгоритму:   Строится двоичная запись числа  N .  Далее эта запись обрабатывается по следующему правилу:  если сумма цифр в двоичной записи числа  чётная , то к этой записи справа дописывается '0', а затем два левых разряда заменяются на '10';  если сумма цифр в двоичной записи числа  нечётная , то к этой записи справа дописывается '1', а затем два левых разряда заменяются на '11'.    Полученная таким образом запись является двоичной записью искомого числа  R .   Укажите  максимальное  число  N , для которого результат работы алгоритма  R  меньше 100.

### Решение

### Шаг 1

Поскольку нам нужно найти МАКСИМАЛЬНОЕ N, а результат R ведет себя нелинейно (из-за замены разрядов), надежнее всего собрать все подходящие N в список и выбрать максимум.

```python
results = []
for N in range(1, 1000):
    # 1. Двоичная запись
    bn = bin(N)[2:]
    
    # 2. Сумма цифр (в двоичной записи это просто количество единиц)
    summ = bn.count('1')
    
    if summ % 2 == 0:
        # Четная сумма: справа '0', слева замена на '10'
        # Срез [2:] убирает два первых символа, потом клеим '10'
        if len(bn) < 2: continue # Защита от коротких чисел
        temp = bn + '0'
        r_bin = '10' + temp[2:]
    else:
        # Нечетная сумма: справа '1', слева замена на '11'
        if len(bn) < 2: continue
        temp = bn + '1'
        r_bin = '11' + temp[2:]
        
    R = int(r_bin, 2)
    
    # 3. Условие R < 100
    if R < 100:
        results.append(N)

print(max(results))
```

### Шаг 2

Запускаем программу. Функция max(results) выведет искомое N.

---

### Альтернативные решения

**Решение программой (Python):**

1. Перебор range(1, 100). Анализ суммы цифр через .count('1'). Использование срезов для замены первых двух символов.

**Ручной способ:**

1. R < 100. Максимальное R = 99 (1100011 в двоичной). Длина числа R ограничена 7 битами (127) или 6 битами (63).

2. Алгоритм: N -> дописывает 1 бит справа, меняет 2 слева. Длина R = Длина N + 1 (если замена 2->2 не меняет длину, а она не меняет). Значит если R < 100 (6-7 бит), то N должно быть 5-6 бит.

3. Ищем макс N. Начнем с 6-битных чисел (от 32 до 63). Проверяем вручную числа ближе к верхней границе.

**Ответ:** `45`

## Hard

*Тема: Алгоритмы для исполнителей*

### Условие

На вход алгоритма подаётся натуральное число  N . Алгоритм строит по нему новое число  R  следующим образом:   Строится запись числа  N  в  шестеричной  системе счисления.  Далее эта запись обрабатывается по следующему правилу:  если число  N  делится на 3, то к этой записи дописываются две последние шестеричные цифры;  если число  N  на 3 не делится, то остаток от деления на 3 умножается на 5, переводится в шестеричную запись и дописывается в конец числа.    Полученная таким образом запись является шестеричной записью искомого числа  R .   Укажите  минимальное  число  R , большее 400, которое может являться результатом работы данного алгоритма. В ответе запишите это число в десятичной системе.

### Решение

### Шаг 1

В Python нет встроенной функции для перевода в 6-ричную систему. Напишем свою функцию `perevod(n, base)`.

```python
def perevod(n, base):
    t = ''
    while n > 0:
        t = str(n % base) + t
        n //= base
    return t
```

### Шаг 2

Напишем перебор N. Поскольку R должно быть > 400, а алгоритм увеличивает число (приписывает цифры), N должно быть небольшим. Начнем с 1.

```python
min_r = 10**10  # Инициализируем очень большим числом

for N in range(1, 1000):
    # 1. Шестеричная запись
    s = perevod(N, 6)
    
    # 2. Обработка
    if N % 3 == 0:
        s = s + s[-2:] # Дописываем две последние
    else:
        rem = (N % 3) * 5
        s = s + perevod(rem, 6)
        
    # 3. Перевод R обратно в десятичную (int умеет из любой базы до 36)
    R = int(s, 6)
    
    # 4. Поиск минимума > 400
    if R > 400:
        min_r = min(min_r, R)

print(min_r)
```

### Шаг 3

Запускаем. Важно не использовать break сразу, если мы не уверены, что функция R(N) монотонна (она не монотонна). Лучше собрать минимум через min().

### Альтернативные решения

**Решение программой (Python):**

1. Реализация функции перевода (через остатки) и основного цикла.

**Ручной способ:**

1. R > 400 (в десятичной). Переведем 400 в шестеричную. 
400 / 6 = 66 (ост 4)
66 / 6 = 11 (ост 0)
11 / 6 = 1 (ост 5)
1 / 6 = 0 (ост 1)
400(10) = 1504(6).

2. Ищем R(6) > 1504(6). Алгоритм приписывает цифры.
Если N делится на 3, приписываются 2 цифры. 
Если N не делится, приписывается результат (N%3)*5. Если ост=1 -> 5(6). Если ост=2 -> 10(10)=14(6) (две цифры).
Скорее всего N было двузначным или однозначным в 6-ричной.

3. Подбор N около границы.

**Ответ:** `428`
