# Задание 3

## Easy

*Тема: Базы данных (Excel/SQL)*

### Условие

В файле приведён фрагмент базы данных «Продукты» (3 таблицы: Движение товаров, Товар, Магазин).  Используя информацию из приведённой базы данных, определите, на какую общую  сумму  (в рублях) было  продано  товара  «Крупа Гречневая»  во всех магазинах сети за период с 1 по 10 июня включительно.  В ответе запишите только число.

### Решение

### Шаг 1

Задача решается в два простых шага. Сначала найдем Артикул товара 'Крупа Гречневая'.

### Шаг 2

Переходим на лист 'Товар'. Используем поиск (Ctrl+F) или фильтр по названию. Находим, что у Гречки артикул, например, '42'.

### Шаг 3

Переходим на лист 'Движение товаров'. Включаем фильтр.
1. Артикул: выбираем '42'.
2. Тип операции: 'Продажа'.
(Магазины фильтровать не нужно, так как в условии сказано 'во всех магазинах').

### Шаг 4

Выделяем столбец с суммой (Количество * Цена) или перемножаем и суммируем. Записываем ответ.

---

### Альтернативные решения

**ВПР (VLOOKUP):**

1. Можно подтянуть название товара прямо в таблицу движений.
Формула: `=ВПР(D2; Товар!$A:$C; 3; 0)`.

2. Фильтруем по столбцу с названием ('Крупа Гречневая') и типом операции ('Продажа').

**Ответ:** `465549`

## Medium

*Тема: Базы данных (Excel/SQL)*

### Условие

В файле приведён фрагмент базы данных «Продукты» о поставках товаров в магазины районов города. База данных состоит из трёх таблиц.   Таблица «Движение товаров»  содержит записи о поставках товаров в магазины в течение первой декады июня 2023 г., а также информацию о проданных товарах. Поля:  ID операции, Дата, ID магазина, Артикул, Количество, Тип операции, Цена .   Таблица «Товар»  содержит информацию о товарах. Поля:  Артикул, Отдел, Наименование, Единица измерения, Количество в упаковке .   Таблица «Магазин»  содержит информацию о магазинах. Поля:  ID магазина, Район, Адрес .  Используя информацию из приведённой базы данных, определите общую  выручку  от продажи всех видов  «Зефира»  в магазинах  Заречного  района за период с 4 по 8 июня включительно.  В ответе запишите только число.

### Решение

### Шаг 1

Этот способ (ВПР) наиболее эффективен. Откроем файл Excel. Перейдем на лист 'Движение товаров'. Нам нужно подтянуть сюда информацию о Районе (из листа Магазин) и Названии товара (из листа Товар).

### Шаг 2

Добавим вспомогательный столбец 'Район'. Используем функцию ВПР (VLOOKUP).
Формула: `=ВПР(C2; Магазин!$A:$B; 2; 0)`, где C2 — ID магазина.

*Формула:* =ВПР(C2; Магазин!$A:$B; 2; 0)

### Шаг 3

Добавим вспомогательный столбец 'Товар'.
Формула: `=ВПР(D2; Товар!$A:$C; 3; 0)`, где D2 — Артикул.

*Формула:* =ВПР(D2; Товар!$A:$C; 3; 0)

### Шаг 4

Включим фильтры (Данные -> Фильтр). Настроим условия:
1. Тип операции: 'Продажа'.
2. Район: 'Заречный'.
3. Товар: содержит 'Зефир' (текстовый фильтр -> содержит).
4. Дата: снимаем галочки, оставляем с 4 по 8 июня.

### Шаг 5

Отфильтровав таблицу, выделим столбец 'Сумма' (или перемножим Количество * Цена в новом столбце, если готовой суммы нет). Смотрим сумму в строке состояния Excel внизу.

---

### Альтернативные решения

**Ручное сопоставление (Фильтры):**

1. Способ без формул. Сначала найдем ID магазинов Заречного района.
1. Идем на лист 'Магазин'.
2. Фильтр по столбцу 'Район' -> 'Заречный'.
3. Выписываем или запоминаем ID магазинов (например: M3, M9, M11, M14).

2. Найдем Артикулы Зефира.
1. Идем на лист 'Товар'.
2. Фильтр по 'Наименование' -> содержит 'Зефир'.
3. Выписываем Артикулы (например: 34, 35, 36).

3. Переходим на лист 'Движение товаров'. Включаем фильтры и аккуратно проставляем галочки:
1. ID магазина: выбираем только M3, M9, M11, M14.
2. Артикул: выбираем только 34, 35, 36.
3. Тип операции: 'Продажа'.
4. Дата: 4.06 - 8.06.

4. После фильтрации выделяем столбец с деньгами (Количество * Цена) и смотрим сумму.

**Ответ:** `703384`

## Hard

*Тема: Базы данных (Excel/SQL)*

### Условие

В файле приведён фрагмент базы данных «Продукты».  Используя информацию из приведённой базы данных, определите  ID магазина  в  Первомайском  районе, который получил  наибольшую выручку  от продажи товаров отдела  «Бакалея»  за весь период.  В ответе запишите только ID магазина (число).

### Решение

### Шаг 1

Задача на поиск максимума среди групп. Эффективнее всего использовать Сводную таблицу (Pivot Table).

### Шаг 2

Подготовка данных (ВПР):
1. В таблицу 'Движение товаров' подтягиваем Район магазина (`=ВПР(...)` из табл. Магазин).
2. Подтягиваем Отдел товара (`=ВПР(...)` из табл. Товар).
3. Считаем Выручку в отдельном столбце (`=Количество*Цена`).

### Шаг 3

Создание Сводной таблицы:
Вставка -> Сводная таблица. Диапазон: вся таблица движений.

### Шаг 4

Настройка Сводной таблицы:
- Фильтры: Район ('Первомайский'), Отдел ('Бакалея'), Тип операции ('Продажа').
- Строки: ID магазина.
- Значения: Сумма по полю Выручка.

### Шаг 5

Сортировка:
В полученной сводной таблице сортируем выручку по убыванию. Верхний магазин — наш ответ.

---

### Альтернативные решения

**Ручной способ (без Сводной):**

1. Сделайте ВПР для Района и Отдела. Отфильтруйте таблицу: Район='Первомайский', Отдел='Бакалея', Тип='Продажа'.

2. Скопируйте отфильтрованные строки на новый лист.

3. Используйте функцию 'Промежуточные итоги' (Данные -> Структура) или просто отсортируйте по ID магазина и вручную посчитайте суммы для каждого магазина (или используйте СУММЕСЛИ).

4. Сравните суммы и выберите ID магазина с максимальной.

**Ответ:** `820815`
