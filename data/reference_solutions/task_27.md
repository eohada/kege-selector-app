## Easy

*Тема: Эффективные алгоритмы*

### Условие

Дана последовательность чисел. Найдите количество пар элементов $(a_i, a_j)$, таких что $|i - j| \ge 5$ (расстояние между элементами не менее 5) и их сумма кратна 3.  Для файла А (маленький) и Б (большой).

### Решение

### Шаг 1

Эффективный алгоритм ($O(N)$). Используем буфер и счетчики остатков. 
Мы идем по последовательности с индексом `i`. В пару к `x = nums[i]` может попасть любое число `y = nums[j]`, где `j <= i - 5`. 
Все такие числа `y` уже прошли через 'карантин' (буфер длиной 5). 
Мы будем хранить количество чисел, которые уже вышли из карантина, разбитое по остаткам от деления на 3 (rems[0], rems[1], rems[2]).

```python
with open('27_B.txt') as f:
    n = int(f.readline())
    nums = [int(line) for line in f]

rems = [0] * 3 # Счетчик остатков для доступных чисел (левее i-5)
queue = [] # Буфер (очередь) последних 5 чисел
count = 0
K = 5

for x in nums:
    # Если очередь заполнена (в ней K элементов), значит самый старый элемент (x_old) уже 'созрел'
    if len(queue) == K:
        x_old = queue.pop(0)
        rems[x_old % 3] += 1
    
    # Теперь ищем пару для текущего x из тех, кто уже в rems
    # Сумма кратна 3:
    # x%3==0 -> пара 0
    # x%3==1 -> пара 2
    # x%3==2 -> пара 1
    target_rem = (3 - (x % 3)) % 3
    count += rems[target_rem]
    
    # Добавляем текущий x в очередь (он станет доступен через K шагов)
    queue.append(x)

print(count)
```

## Medium

*Тема: Эффективные алгоритмы*

### Условие

Дана последовательность. Найдите непрерывную подпоследовательность с максимальной суммой, кратной  89 .

### Решение

### Шаг 1

Используем префиксные суммы. `S[i]` — сумма первых `i` элементов. 
Сумма подстроки `[j..i]` равна `S[i] - S[j-1]`. 
Чтобы разность делилась на 89, `S[i]` и `S[j-1]` должны иметь **одинаковый остаток** от деления на 89.

```python
with open('27_pref.txt') as f:
    n = int(f.readline())
    nums = [int(line) for line in f]

# min_prefix[rem] хранит МИНИМАЛЬНУЮ префиксную сумму с остатком rem.
# Инициализируем бесконечностью, кроме остатка 0.
min_prefix = {r: float('inf') for r in range(89)}
min_prefix[0] = 0 # Сумма пустого префикса = 0, остаток 0

max_sum = 0
current_sum = 0

for x in nums:
    current_sum += x
    rem = current_sum % 89
    
    # Если такой остаток уже встречался, значит разность (current_sum - min_prefix[rem]) кратна 89.
    # И так как мы вычитаем МИНИМАЛЬНУЮ сумму, результат будет МАКСИМАЛЬНЫМ.
    if min_prefix[rem] != float('inf'):
        max_sum = max(max_sum, current_sum - min_prefix[rem])
    
    # Обновляем минимум для этого остатка
    min_prefix[rem] = min(min_prefix[rem], current_sum)

print(max_sum)
```

## Hard

*Тема: Эффективные алгоритмы*

### Условие

Дана последовательность точек на прямой (координаты). Нужно выбрать  три точки  так, чтобы расстояние между любыми двумя было не менее K, а сумма их координат была максимальной.  (Или вариация: выбрать Центр так, чтобы сумма расстояний до него была минимальной - 'Пункт сбора').

### Решение

### Шаг 1

Задача на выбор 3 точек с условием расстояния. Это динамика. 
Пусть `dp[i][cnt]` — макс сумма `cnt` точек, выбранных из первых `i`, где последняя точка — это `nums[i]`. 
Это сложно. Проще так: 
Идем по массиву `x`. 
Поддерживаем `max_1` — макс точка левее `i-K`. 
Поддерживаем `max_2` — макс пара (точка + точка левее неё на К), левее `i-K`. 
Тогда для текущей `x`: ответ обновляется как `x + max_2`. 
`max_1` обновляется значением `nums[i-K]`. 
`max_2` обновляется значением `nums[i-K] + max_1 (старое)`.

```python
with open('27_hard.txt') as f:
    K = int(f.readline()) # Расстояние
    N = int(f.readline())
    nums = [int(line) for line in f]

# Максимумы на расстоянии
max_1 = -float('inf')
max_2 = -float('inf')
ans = -float('inf')

# Индекс j отстает от i на K (или на 2K для тройки? Нет, просто поток)
# Нам нужны точки i, j, m: m > j+K, j > i+K.
# Когда мы стоим на m (текущий элемент), нам нужна лучшая пара (i, j) где j <= m-K.
# Для элемента nums[idx] лучшая пара готова из элементов до idx-K.

for i in range(2 * K, N):
    # Кандидат на первую точку (самая левая): nums[i - 2*K]
    # Мы можем обновить max_1, используя nums[i - 2*K]
    x_prev = nums[i - 2 * K]
    if x_prev > max_1: max_1 = x_prev
    
    # Кандидат на вторую точку: nums[i - K]. 
    # Мы можем составить пару из (лучшего max_1) + nums[i - K]
    pair = max_1 + nums[i - K]
    if pair > max_2: max_2 = pair
    
    # Текущая точка (третья): nums[i]
    # Тройка = max_2 + nums[i]
    current_triple = max_2 + nums[i]
    if current_triple > ans: ans = current_triple

print(ans)
```
