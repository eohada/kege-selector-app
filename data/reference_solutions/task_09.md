## Easy

*Тема: Электронные таблицы*

### Условие

Откройте файл электронной таблицы, содержащей в каждой строке 3 натуральных числа.  Определите количество строк таблицы, содержащих числа, которые могут быть длинами сторон  прямоугольного треугольника .  В ответе запишите только число.

### Решение

### Шаг 1

Считываем файл построчно. Преобразуем строку в список чисел и сортируем их по возрастанию.

```python
count = 0
with open('9_easy.csv') as f:
    for line in f:
        # Разбиваем строку по точке с запятой (для CSV) или пробелу
        # sorted() поставит гипотенузу (максимум) в конец
        nums = sorted(list(map(int, line.replace(';', ' ').split())))
        
        # Проверяем теорему Пифагора: a^2 + b^2 == c^2
        if nums[0]**2 + nums[1]**2 == nums[2]**2:
            count += 1
print(count)
```

---

### Альтернативные решения

**Решение в Excel:**

1. Чтобы проверить условие Пифагора, нужно знать, какое число максимальное (гипотенуза). Отсортируем числа в столбцах D, E, F.
D1: `=НАИМЕНЬШИЙ($A1:$C1; 1)` (самое маленькое)
E1: `=НАИМЕНЬШИЙ($A1:$C1; 2)` (среднее)
F1: `=НАИМЕНЬШИЙ($A1:$C1; 3)` (самое большое, гипотенуза)

2. В ячейке G1 напишем проверку: `=ЕСЛИ(D1^2 + E1^2 = F1^2; 1; 0)`.

3. Скопируем формулы вниз на все строки. Сумма столбца G даст ответ.

**Ответ:** `239`

## Medium

*Тема: Электронные таблицы*

### Условие

В файле электронной таблицы в каждой строке содержатся 4 натуральных числа. Определите количество строк, для которых выполнены оба условия:   Наибольшее из четырёх чисел  меньше  суммы трёх остальных.  Четыре числа можно разбить на две пары так, чтобы  суммы чисел в этих парах были равны .

### Решение

### Шаг 1

Решаем на Python. Считываем файл, сортируем числа в каждой строке.

```python
count = 0
with open('9.txt') as f:
    for line in f:
        nums = sorted(map(int, line.split()))
        # Теперь nums[0] - мин, nums[3] - макс
        
        # Условие 1: Макс < Сумма остальных
        if nums[3] < sum(nums[:3]):
            # Условие 2: Равные суммы пар
            # Единственный вариант для отсортированного списка: (мин + макс) == (сред1 + сред2)
            if nums[0] + nums[3] == nums[1] + nums[2]:
                count += 1
print(count)
```

---

### Альтернативные решения

**Решение в Excel:**

1. E1 (Условие 1): `=МАКС(A1:D1) < (СУММ(A1:D1) - МАКС(A1:D1))`.

2. F1 (Условие 2): Нужно проверить все комбинации пар. Их три: (A+B и C+D), (A+C и B+D), (A+D и B+C).
Формула: `=ИЛИ(A1+B1=C1+D1; A1+C1=B1+D1; A1+D1=B1+C1)`.

3. G1 (Итог): `=И(E1; F1)`. Если ИСТИНА, ставим 1, иначе 0 (или просто считаем количество ИСТИНА через СЧЁТЕСЛИ).

**Ответ:** `451`

## Hard

*Тема: Электронные таблицы*

### Условие

В файле в каждой строке 6 натуральных чисел. Определите количество строк, где:   В строке есть  только одно  число, которое повторяется  дважды  (остальные 4 числа различны и не совпадают с повторяющимся).  Среднее арифметическое неповторяющихся чисел не больше суммы повторяющихся чисел.

### Решение

### Шаг 1

Решаем на Python. Используем метод `count` для анализа повторов.

```python
count = 0
with open('9_hard.txt') as f:
    for line in f:
        nums = list(map(int, line.split()))
        
        # Списки для повторяющихся и уникальных
        # Если число встречается 2 раза, оно пойдет в rep (дважды!)
        rep = [x for x in nums if nums.count(x) == 2]
        uniq = [x for x in nums if nums.count(x) == 1]
        
        # Условие 1: одно число повторяется дважды (значит в rep должно быть 2 элемента)
        # И 4 числа уникальны (в uniq 4 элемента)
        # Это исключает случаи 3-х повторов или двух пар по 2.
        if len(rep) == 2 and len(uniq) == 4:
            # Условие 2: Ср. арифм. неповторяющихся <= Сумма повторяющихся
            avg_uniq = sum(uniq) / 4
            sum_rep = sum(rep) # Это x + x
            
            if avg_uniq <= sum_rep:
                count += 1
print(count)
```

---

### Альтернативные решения

**Решение в Excel:**

1. В Excel нужно создать 6 вспомогательных столбцов (G-L), где для каждого числа посчитать, сколько раз оно встречается: `=СЧЁТЕСЛИ($A1:$F1; A1)`.

2. Проверка условия 1: Сумма этих счетчиков должна быть равна 8 (4 числа по 1 разу + 2 числа по 2 раза = 4 + 4 = 8). Если сумма 8, значит структура верная. Или используйте `СЧЁТЕСЛИ` по диапазону счетчиков.

3. Сложнее посчитать суммы. Используем `СУММЕСЛИ`. 
Сумма повторяющихся: `СУММЕСЛИ(G1:L1; 2; A1:F1)`.
Сумма неповторяющихся: `СУММЕСЛИ(G1:L1; 1; A1:F1)`.

4. Финальная проверка: `(СуммаНеповт / 4) <= СуммаПовт`.

**Ответ:** `726`
