## Easy

*Тема: Обработка символьных строк*

### Условие

Текстовый файл состоит не более чем из $10^6$ символов A, B, C. Определите максимальное количество идущих подряд символов  C .

### Решение

### Шаг 1

Считываем содержимое файла в строку.

```python
with open('24_easy.txt') as f:
    s = f.readline().strip()
```

### Шаг 2

Самый простой способ: использовать метод `split`. Если разбить строку по всем символам, кроме 'C' (заменив их на пробелы), то останутся только цепочки из 'C'. Но проще заменить все, что НЕ 'C', на пробел.

```python
# Способ 1: Линейный проход (универсальный)
max_len = 0
cur_len = 0
for char in s:
    if char == 'C':
        cur_len += 1
        max_len = max(max_len, cur_len)
    else:
        cur_len = 0
print(max_len)
```

### Шаг 3

Способ 'Pythonic' (через replace и split).

```python
# Заменяем A и B на пробел
s_clean = s.replace('A', ' ').replace('B', ' ')
# Разбиваем по пробелам, получаем список строк из 'C'
chains = s_clean.split()
# Находим макс длину
print(max(len(c) for c in chains))
```

---

### Альтернативные решения

**Решение программой (Python Loop):**

1. Линейный алгоритм: идем по строке, считаем подряд идущие 'C', сбрасываем счетчик, если встретили не 'C'.

**Ответ:** `190`

## Medium

*Тема: Обработка символьных строк*

### Условие

Текстовый файл содержит строку из символов A, B, C, D, E. Определите максимальную длину подстроки, в которой  никакие два соседних символа не равны  (то есть нет пар AA, BB и т.д.).

### Решение

### Шаг 1

Нужно найти самую длинную цепочку, где `s[i] != s[i+1]`.

```python
with open('24_medium.txt') as f:
    s = f.readline().strip()
```

### Шаг 2

Используем линейный проход. Начинаем с 1 символа (k=1). Сравниваем текущий с предыдущим.

```python
mx = 1
k = 1
for i in range(1, len(s)):
    if s[i] != s[i-1]:
        k += 1
        mx = max(mx, k)
    else:
        k = 1 # Сброс в 1, так как текущий символ начинает новую цепочку
print(mx)
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Код решения.

**Ответ:** `380`

## Hard

*Тема: Обработка символьных строк*

### Условие

Текстовый файл содержит строку из букв Q, R, W и цифр 1, 2, 4. Определите максимальную длину подстроки, которая состоит из чередующихся групп:  буква + цифра  (например, Q1R2W4...).  Подстрока может начинаться как с буквы, так и с цифры, и заканчиваться чем угодно, главное соблюдать чередование видов символов.

### Решение

### Шаг 1

Заменим все буквы на 'L' (Letter), а все цифры на 'D' (Digit). Это упростит задачу до поиска чередования L и D.

```python
with open('24_hard.txt') as f:
    s = f.readline().strip()

# Нормализация
for c in 'QRW': s = s.replace(c, 'L')
for c in '124': s = s.replace(c, 'D')

# Теперь ищем макс цепочку типа LDLDLD... или DLDLDL...
mx = 1
k = 1
for i in range(1, len(s)):
    if s[i] != s[i-1]: # L!=D или D!=L
        k += 1
        mx = max(mx, k)
    else:
        k = 1
print(mx)
```

### Шаг 2

Вариант через Regex (как в PDF). Это мощнее, если условия сложнее (например, пары буква+цифра строго).

```python
import re
# Ищем пары (БукваЦифра) или (ЦифраБуква). 
# Но задача просит просто чередование. Regex: (?:[QRW][124])+
# В PDF решение: re.findall(r'(?:[QRW][124])+', s)
# Это найдет цепочки четной длины (пары). А если цепочка нечетная? 
# Универсальнее метод замены (Шаг 1).
```

### Альтернативные решения

**Решение программой (Replace):**

1. Заменяем все допустимые буквы на один символ (например, '*') и цифры на другой ('#').

**Решение через Regex (из PDF):**

1. Используем `re.findall`. Паттерн ищет повторы групп.
