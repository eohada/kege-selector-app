## Easy

*Тема: Истинность логического выражения*

### Условие

Обозначим через $ДЕЛ(n, m)$ утверждение «натуральное число $n$ делится без остатка на натуральное число $m$».  Для какого  наибольшего  натурального числа $A$ формула  $$(\neg ДЕЛ(x, A) \to (ДЕЛ(x, 6) \to \neg ДЕЛ(x, 9)))$$  тождественно истинна (то есть принимает значение 1 при любом натуральном значении переменной $x$)?

### Решение

### Шаг 1

Запишем логическое выражение на Python. Импликация `a -> b` это `a <= b`.

```python
def D(n, m): return n % m == 0

for A in range(1000, 0, -1):
    flag = True
    for x in range(1, 1000):
        if not ((not D(x, A)) <= (D(x, 6) <= (not D(x, 9)))):
            flag = False
            break
    if flag:
        print(A)
        break
```

## Medium

*Тема: Истинность логического выражения*

### Условие

На числовой прямой даны два отрезка: $P = [10, 29]$ и $Q = [13, 18]$.  Какова  наибольшая  возможная длина отрезка $A$, при котором формула  $$((x \in A) \to (x \in P)) \lor (x \in Q)$$  тождественно истинна?

### Решение

### Шаг 1

Используем множества точек (с шагом 0.5 или 1, если границы целые и нет строгих неравенств, но надежнее аналитика или мелкий шаг). В данном случае для ЕГЭ достаточно перебора целых чисел, но нужно помнить про длину.

```python
P = {x for x in range(10, 30)} # [10, 29]
Q = {x for x in range(13, 19)} # [13, 18]
A = set()

for x in range(0, 100):
    # ((x in A) <= (x in P)) or (x in Q)
    # Преобразуем: A -> (P + Q)
    if (x in P) or (x in Q):
        A.add(x)

print(len(A)) # Нет, длина отрезка это max - min. Для [10, 29] это 29-10=19. Кол-во точек 20.
if A:
    print(max(A) - min(A))
```

## Hard

*Тема: Истинность логического выражения*

### Условие

Обозначим через $m \& n$ поразрядную конъюнкцию неотрицательных целых чисел $m$ и $n$.  Для какого  наименьшего  неотрицательного целого числа $A$ формула  $$(x \& 29 \neq 0) \to ((x \& 17 = 0) \to (x \& A \neq 0))$$  тождественно истинна?

### Решение

### Шаг 1

Запишем выражение на Python. Операция `&` — это `&`.

```python
def f(x, A):
    return (x & 29 != 0) <= ((x & 17 == 0) <= (x & A != 0))
```

### Шаг 2

Перебираем A. Так как ищем наименьшее, идем от 0 вверх.

```python
for A in range(0, 1000):
    if all(f(x, A) for x in range(0, 1000)):
        print(A)
        break
```
