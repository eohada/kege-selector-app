# Задание 23

## Easy

*Тема: Динамическое программирование (кол-во путей)*

### Условие

Исполнитель Калькулятор преобразует число на экране. У исполнителя есть две команды, которым присвоены номера:    Прибавить 1    Умножить на 2    Сколько существует программ, для которых при исходном числе  2  результатом является число  16 ?

### Решение

### Шаг 1

Решим задачу с помощью рекурсивной функции на Python. Функция `f(curr, end)` будет возвращать количество путей из `curr` в `end`.

```python
def f(curr, end):
    if curr > end:
        return 0
    if curr == end:
        return 1
    # Команды: +1, *2
    return f(curr + 1, end) + f(curr * 2, end)
```

### Шаг 2

Вызовем функцию для диапазона 2 -> 16.

```python
print(f(2, 16))
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Полный код.

**Ручной способ (Таблица DP):**

1. Составим таблицу значений от 2 до 16. 
K[i] — количество программ для получения числа i.
База: K[2] = 1.

2. Рекуррентная формула: K[i] = K[i-1] (приход командой +1) + K[i/2] (приход командой *2, если i делится на 2).

3. 3: K[2] = 1
4: K[3] + K[2] = 1 + 1 = 2
5: K[4] = 2
6: K[5] + K[3] = 2 + 1 = 3
...
16: K[15] + K[8] = ...

**Ответ:** `14`

## Medium

*Тема: Динамическое программирование (кол-во путей)*

### Условие

Исполнитель Калькулятор преобразует число на экране. Команды:    Прибавить 1    Умножить на 2    Сколько существует программ, для которых при исходном числе  1  результатом является число  20 , и при этом траектория вычислений содержит число  10 ?

### Решение

### Шаг 1

Чтобы траектория обязательно проходила через 10, нужно разбить путь на два этапа: 
1) 1 -> 10 
2) 10 -> 20. 
Итоговое количество путей — это произведение путей первого и второго этапа.

```python
def f(x, y):
    if x > y: return 0
    if x == y: return 1
    return f(x + 1, y) + f(x * 2, y)

# Путь 1 -> 10 -> 20
ans = f(1, 10) * f(10, 20)
print(ans)
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Используем стандартную функцию `f(x, y)` и умножаем результаты.

**Ответ:** `28`

## Hard

*Тема: Динамическое программирование (кол-во путей)*

### Условие

Исполнитель преобразует число:  +1 ,  +2 ,  *2 . 
Сколько существует программ, преобразующих число  3  в число  18 , при этом траектория вычислений  содержит  число  9  и  не содержит  числа  13 ?

### Решение

### Шаг 1

Модифицируем функцию `f`. Добавим проверку на запрещенное число (13). Если `x == 13`, возвращаем 0.

```python
def f(x, y):
    if x > y or x == 13:
        return 0
    if x == y:
        return 1
    return f(x + 1, y) + f(x + 2, y) + f(x * 2, y)
```

### Шаг 2

Разбиваем маршрут по обязательной вершине (9): 3 -> 9 и 9 -> 18.

```python
print(f(3, 9) * f(9, 18))
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Код с учетом обоих условий.

**Ответ:** `24`
