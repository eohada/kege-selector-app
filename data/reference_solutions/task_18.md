## Easy

*Тема: Динамическое программирование*

### Условие

Квадрат разлинован на $N \times N$ клеток ($1  вправо  или  вниз . По команде вправо Робот перемещается в соседнюю правую клетку, по команде вниз — в соседнюю нижнюю.  При попытке выхода за границу квадрата Робот разрушается. Перед каждым запуском Робота в каждой клетке квадрата лежит монета достоинством от 1 до 100.  Определите  максимальную  и  минимальную  денежную сумму, которую может собрать Робот, пройдя из  левой верхней  клетки в  правую нижнюю .  В ответе укажите два числа: сначала максимальную сумму, затем минимальную.

### Решение

### Шаг 1

Решим задачу методом динамического программирования. Создадим таблицу dp того же размера, что и исходное поле.

```python
import pandas as pd # Для удобства чтения Excel
# Или csv модуль

# Читаем данные (предположим из CSV для универсальности)
with open('18_easy.csv') as f:
    grid = [list(map(int, line.split(';'))) for line in f]

N = len(grid)
M = len(grid[0])

# DP для максимума
dp_max = [[0]*M for _ in range(N)]

# База: начальная клетка
dp_max[0][0] = grid[0][0]

# Заполняем первую строку (движение только вправо)
for j in range(1, M):
    dp_max[0][j] = dp_max[0][j-1] + grid[0][j]

# Заполняем первый столбец (движение только вниз)
for i in range(1, N):
    dp_max[i][0] = dp_max[i-1][0] + grid[i][0]

# Заполняем остальное
for i in range(1, N):
    for j in range(1, M):
        # Приходим либо сверху, либо слева. Выбираем лучшее.
        dp_max[i][j] = max(dp_max[i-1][j], dp_max[i][j-1]) + grid[i][j]

print(f"Max: {dp_max[N-1][M-1]}")
```

## Medium

*Тема: Динамическое программирование*

### Условие

Квадрат разлинован на $N \times N$ клеток. Внутри квадрата есть внутренние стены (обозначены жирными линиями). Робот не может проходить сквозь стены.  Определите максимальную сумму, которую может собрать Робот, двигаясь из левой верхней клетки в правую нижнюю.   Примечание:  В файле стены никак не обозначены программно, обычно дается картинка или Excel с границами. Для программного решения стены нужно кодировать вручную или использовать готовый CSV с маской стен.

### Решение

### Шаг 1

В Excel визуально видны стены. Если стена СВЕРХУ от клетки, мы не можем прийти в неё сверху (только слева). Если стена СЛЕВА, мы не можем прийти слева (только сверху).

### Шаг 2

Решение в Excel: 
1. Копируем формулу `=МАКС(...)` на всё поле.
2. В ячейках, где есть стена СЛЕВА, меняем формулу на `=Сверху + Текущая` (так как слева проход закрыт).
3. В ячейках, где есть стена СВЕРХУ, меняем формулу на `=Слева + Текущая`.

## Hard

*Тема: Динамическое программирование*

### Условие

Квадрат разлинован на $N \times N$. Робот движется вправо/вниз. При посещении клетки с неё забирается монета.  Дополнительное условие: Робот не может наступать на клетки, где количество монет  чётно  (такие клетки считаются стенами/ямами). Исключение: начальная и конечная клетки (в них заходить можно, даже если там чётное число).  Найдите максимальную сумму.

### Решение

### Шаг 1

Решаем на Python, так как условие 'четность' легко проверить кодом.

```python
data = [list(map(int, s.split(';'))) for s in open('18_hard.csv')]
N, M = len(data), len(data[0])

# Инициализируем DP очень маленькими числами (чтобы пометить недостижимость)
dp = [[-10**9]*M for _ in range(N)]

# Старт
dp[0][0] = data[0][0]

for i in range(N):
    for j in range(M):
        # Пропускаем старт
        if i == 0 and j == 0: continue
        
        # Проверка условия проходимости: клетка должна быть нечетной (или финишной)
        is_finish = (i == N-1 and j == M-1)
        if data[i][j] % 2 == 0 and not is_finish:
            continue # Это стена/яма, оставляем -10^9
            
        candidates = []
        # Приходим сверху
        if i > 0 and dp[i-1][j] != -10**9:
            candidates.append(dp[i-1][j])
        # Приходим слева
        if j > 0 and dp[i][j-1] != -10**9:
            candidates.append(dp[i][j-1])
            
        if candidates:
            dp[i][j] = max(candidates) + data[i][j]

if dp[-1][-1] == -10**9:
    print("Маршрут невозможен")
else:
    print(dp[-1][-1])
```

### Альтернативные решения

**Решение программой (Python):**

1. Код выше. Основная идея: клетки с четным значением игнорируются при расчете пути (кроме финиша).

**Решение в Excel:**

1. Можно использовать условное форматирование, чтобы подсветить 'плохие' клетки. Затем вручную или формулой `=ЕСЛИ(ЕЧЁТН(B1); -99999; ...)` исключать их.

2. Формула станет громоздкой: `=ЕСЛИ(И(НЕ(ЕЧЁТН(Текущая)); ИЛИ(ЭтоФиниш)); МАКС(...)+Текущая; -99999)`.

**Ответ:** `2724 1040`
