## Easy

*Тема: Машина Тьюринга*

### Условие

Исполнитель Машина Тьюринга (МТ) работает с лентой, на которой записано двоичное число. Остальные ячейки заполнены символом  λ  (пусто). Головка находится над первой цифрой числа (самой левой). Алфавит: {0, 1, λ}.  Программа МТ задана таблицей переходов:      0  1  λ    q0  1, R, q0  0, R, q0  λ, N, q1    Начальное состояние  q0 . Конечное состояние  q1  (стоп).  Какое число (в десятичной системе) окажется на ленте после остановки машины, если исходно было записано число  10  (десятичное)?

### Решение

### Шаг 1

Переведем число 10 в двоичную систему: $10_{10} = 1010_2$. Лента: `... λ 1 0 1 0 λ ...`.

```python
n = 10
tape_str = bin(n)[2:] # '1010'
print(f"Исходная лента: {tape_str}")
```

### Шаг 2

Используем универсальный класс TuringMachine для эмуляции.

```python
from collections import defaultdict

class TuringMachine:
    def __init__(self, rules, tape_str="", blank='λ', start_state='q0', accept_states=('q1',)):
        self.rules = rules
        self.blank = blank
        self.state = start_state
        self.accept = set(accept_states)
        self.tape = defaultdict(lambda: blank)
        for i, ch in enumerate(tape_str):
            self.tape[i] = ch
        self.head = 0

    def step(self):
        sym = self.tape[self.head]
        key = (self.state, sym)
        if key not in self.rules:
            return False
        write, move, next_state = self.rules[key]
        self.tape[self.head] = write
        if move == 'L': self.head -= 1
        elif move == 'R': self.head += 1
        self.state = next_state
        return self.state not in self.accept

    def run(self, max_steps=1000):
        steps = 0
        while steps < max_steps and self.state not in self.accept:
            if not self.step(): break
            steps += 1
    
    def get_tape_str(self):
        indexes = [i for i, sym in self.tape.items() if sym != self.blank]
        if not indexes: return ""
        return "".join(self.tape[i] for i in range(min(indexes), max(indexes)+1))

# Правила: q0,0->1,R,q0 | q0,1->0,R,q0 | q0,λ->λ,N,q1
rules = {
    ('q0', '0'): ('1', 'R', 'q0'),
    ('q0', '1'): ('0', 'R', 'q0'),
    ('q0', 'λ'): ('λ', 'N', 'q1')
}

tm = TuringMachine(rules, tape_str)
tm.run()
res_bin = tm.get_tape_str()
print(f"Результат (bin): {res_bin}")
print(f"Результат (dec): {int(res_bin, 2)}")
```

### Шаг 3

Анализ: q0 идет вправо, инвертируя биты (0->1, 1->0). 1010 -> 0101. 0101 в десятичной это 5.

---

### Альтернативные решения

**Ручная трассировка:**

1. Лента: 1 0 1 0. Головка на 1-м символе (1). Состояние q0.

2. q0, 1 -> пишем 0, сдвиг R, сост q0. Лента: 0 0 1 0. Головка на 2-м (0).

3. q0, 0 -> пишем 1, сдвиг R, сост q0. Лента: 0 1 1 0. Головка на 3-м (1).

4. q0, 1 -> пишем 0, сдвиг R, сост q0. Лента: 0 1 0 0. Головка на 4-м (0).

5. q0, 0 -> пишем 1, сдвиг R, сост q0. Лента: 0 1 0 1. Головка на λ.

6. q0, λ -> стоп (q1). Результат 0101 -> 5.

**Ответ:** `5`

## Medium

*Тема: Машина Тьюринга*

### Условие

На вход МТ подается двоичное число. Головка находится над  младшим  (самым правым) разрядом числа. Состояние  q1 . Алфавит: {0, 1, λ}.  Программа:  q1, 0 -> 1, N, q0
q1, 1 -> 0, L, q1
q1, λ -> 1, N, q0  Конечное состояние  q0 . Определите, какое число окажется на ленте, если исходное число было  11  (десятичное).

### Решение

### Шаг 1

11 -> 1011. Головка в конце (индекс 3, если считать 0,1,2,3). Настраиваем эмулятор.

```python
# Вставляем класс TuringMachine (см. Easy)
# ... (код класса) ...

rules = {
    ('q1', '0'): ('1', 'N', 'q0'),
    ('q1', '1'): ('0', 'L', 'q1'),
    ('q1', 'λ'): ('1', 'N', 'q0')
}

# Лента 1011. Головка на последнем символе.
tm = TuringMachine(rules, "1011", blank='λ', start_state='q1', accept_states=('q0',))
tm.head = 3 # Указываем на последнюю цифру (len - 1)
tm.run()
print(int(tm.get_tape_str(), 2))
```

---

### Альтернативные решения

**Ручная трассировка:**

1. 1011 (q1 на посл. 1) -> 1010 (q1 на пред. 1, сдвиг L).

2. 1010 (q1 на 1) -> 1000 (q1 на 0, сдвиг L).

3. 1000 (q1 на 0). Правило: q1,0 -> 1, N, q0. Пишем 1, стоп. Результат: 1100.

4. 1100 в двоичной = 12 в десятичной. (11 + 1 = 12).

**Ответ:** `12`

## Hard

*Тема: Машина Тьюринга*

### Условие

Дана программа. Начало q1, слева. Вход: число  205 . Машина стирает символы, заменяя их на λ (пусто), и движется вправо.  q1, 1 -> λ, R, q2
q1, 0 -> λ, R, q1
q1, λ -> 0, N, q0

q2, 1 -> λ, R, q1
q2, 0 -> λ, R, q2
q2, λ -> 1, N, q0  Какой результат (число 0 или 1) останется на ленте?

### Решение

### Шаг 1

205 -> 11001101. Эмулируем.

```python
# Вставляем класс TuringMachine
# ...

rules = {
    ('q1', '1'): ('λ', 'R', 'q2'),
    ('q1', '0'): ('λ', 'R', 'q1'),
    ('q1', 'λ'): ('0', 'N', 'q0'),
    ('q2', '1'): ('λ', 'R', 'q1'),
    ('q2', '0'): ('λ', 'R', 'q2'),
    ('q2', 'λ'): ('1', 'N', 'q0')
}

tm = TuringMachine(rules, bin(205)[2:], blank='λ', start_state='q1', accept_states=('q0',))
tm.run()
print(tm.get_tape_str())
```

---

### Альтернативные решения

**Ручная трассировка:**

1. Анализируем логику: q1 — состояние 'четное число единиц' (начало). q2 — 'нечетное'.

2. Если видим '1': q1->q2 или q2->q1 (состояние меняется). Если '0': состояние не меняется.

3. В конце (на λ): если q1 (четное) -> пишем 0. Если q2 (нечетное) -> пишем 1.

4. Число 205 (11001101) содержит 5 единиц. 5 — нечетное. Значит, остановимся в q2 и запишем 1.

**Ответ:** `1`
