## Easy

*Тема: Теория игр (1 куча)*

### Условие

Два игрока, Петя и Ваня, играют в игру. Перед игроками лежит куча камней. Игроки ходят по очереди, первый ход делает Петя.  За один ход игрок может добавить в кучу  один камень  или увеличить количество камней в куче  в два раза .  Игра завершается, когда количество камней в куче становится  не менее 29 .  В начальный момент в куче было $S$ камней, $1 \le S \le 28$.   Задание 19.  Укажите такое значение $S$, при котором Петя не может выиграть за один ход, но при любом ходе Пети Ваня выигрывает своим первым ходом.   Задание 20.  Найдите два таких значения $S$, при которых у Пети есть выигрышная стратегия, причём Петя не может выиграть за один ход, но может выиграть своим вторым ходом.   Задание 21.  Найдите значение $S$, при котором у Вани есть выигрышная стратегия, позволяющая ему выиграть первым или вторым ходом при любой игре Пети, но нет стратегии, которая гарантированно позволит выиграть первым ходом.

### Решение

### Шаг 2

Код для определения 'расстояния до победы'.
Win1 (Петя 1) -> 1
Lose1 (Ваня 1) -> 2
Win2 (Петя 2) -> 3
Lose2 (Ваня 2) -> 4

```python
def solve():
    # Массив результатов для чисел от 1 до 29
    # res[s] хранит: 1 (W1), 2 (L1), 3 (W2), 4 (L2)
    res = [0] * 300
    
    for s in range(28, 0, -1):
        m = [res[s+1], res[s*2]]
        
        # Логика: 
        # Если можно попасть в L (четное число в m) -> мы в W.
        # Берем минимальное четное (быстрая победа) + 1.
        loses = [x for x in m if x % 2 == 0 and x != 0] # x=0 это 'уже победа', не считается за ход
        # Стоп, если s*2 >= 29, то res[s*2] должен быть 0. 
        # Тогда ход в 0 - это победа за 1 ход.
        
        # Перепишем чисто:
        # Если есть ход в '0' (финиш), то это победа за 1 ход.
        if any(x == 0 for x in [s+1, s*2] if x >= 29):
             res[s] = 1
             continue
             
        # Получаем значения для потомков (если они < 29)
        # Если s*2 >= 29, это мы уже обработали (победа за 1 ход)
        vals = []
        for nxt in (s+1, s*2):
            if nxt >= 29: vals.append(0) # Финиш
            else: vals.append(res[nxt])
            
        # Стратегия
        # 1. Можем ли выиграть? (попасть в четное/L)
        loss_moves = [v for v in vals if v % 2 == 0]
        if loss_moves:
            res[s] = min(loss_moves) + 1
        else:
            # 2. Мы проигрываем (все ходы ведут в нечетное/W)
            res[s] = max(vals) + 1
            
    # Вывод ответов
    for s in range(1, 29):
        if res[s] == 2: print(f'19: {s}')
        if res[s] == 3: print(f'20: {s}')
        if res[s] == 4: print(f'21: {s}')
```

## Medium

*Тема: Теория игр (2 кучи)*

### Условие

Два игрока, Петя и Ваня, играют в игру с двумя кучами камней. Ходы: +1 в любую кучу или *2 любую кучу. Победа: сумма $\ge 77$. Начало: (7, S), $1 \le S \le 69$.   19:  Ваня выигрывает первым ходом при любой игре Пети.   20:  Петя выигрывает вторым ходом.   21:  Ваня выигрывает первым или вторым ходом.

### Решение

### Шаг 1

Код для двух куч. Функция принимает `(a, b)`.

```python
from functools import lru_cache

@lru_cache(None)
def g(a, b):
    if a + b >= 77: return 0
    moves = [g(a+1, b), g(a*2, b), g(a, b+1), g(a, b*2)]
    
    evens = [x for x in moves if x % 2 == 0]
    if evens: return min(evens) + 1
    return max(moves) + 1

for s in range(1, 70):
    res = g(7, s)
    if res == 2: print(f"19: {s}")
    if res == 3: print(f"20: {s}")
    if res == 4: print(f"21: {s}")
```

## Hard

*Тема: Теория игр (Ограничения)*

### Условие

Одна куча. Ходы:  +1, +4, *2 . Победа: $S \ge 60$.   Ограничение:  Запрещено делать ход, который повторяет ход, сделанный предыдущим игроком (например, если Петя сделал +1, Ваня не может сделать +1).  Найти S для заданий 19, 20, 21.

### Решение

### Шаг 1

Добавляем аргумент `prev` в функцию. Кодируем ходы: 0 (+1), 1 (+4), 2 (*2).

```python
from functools import lru_cache

@lru_cache(None)
def g(s, prev):
    if s >= 60: return 0
    
    moves = []
    if prev != 0: moves.append(g(s+1, 0))
    if prev != 1: moves.append(g(s+4, 1))
    if prev != 2: moves.append(g(s*2, 2))
    
    evens = [x for x in moves if x % 2 == 0]
    if evens: return min(evens) + 1
    if not moves: return 0 # Тупик (редко, но бывает)
    return max(moves) + 1

# Для старта prev = -1 (никакой ход не запрещен)
for s in range(1, 60):
    if g(s, -1) == 2: print(f"19: {s}")
    # и т.д.
```
