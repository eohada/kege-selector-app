## Easy

*Тема: Рекурсивные алгоритмы*

### Условие

Алгоритм вычисления значения функции $F(n)$, где $n$ — натуральное число, задан следующими соотношениями:  $F(n) = 1$, если $n = 1$;  $F(n) = n \cdot F(n-1)$, если $n > 1$.  Чему равно значение выражения $(F(2024) - F(2023)) / F(2022)$? В ответе запишите только целое число.

### Решение

### Шаг 1

Запишем функцию на Python. Так как числа большие (факториал 2024!), нам обязательно нужно увеличить лимит рекурсии.

```python
import sys
sys.setrecursionlimit(3000) # Лимит > 2024

def F(n):
    if n == 1:
        return 1
    else:
        return n * F(n - 1)
```

### Шаг 2

Вычислим выражение. Деление должно быть целочисленным (`//`) или обычным (`/`), если результат целое. Здесь факториалы, результат будет огромным, но при делении сократится.

```python
res = (F(2024) - F(2023)) // F(2022)
print(res)
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Полный код.

**Ручной способ (Математика):**

1. Функция $F(n) = n!$ (факториал).
Выражение: $\frac{2024! - 2023!}{2022!}$.

2. Вынесем $2023!$ за скобки в числителе: $2023! \cdot (2024 - 1) = 2023! \cdot 2023$.

3. Разделим на $2022!$. $\frac{2023! \cdot 2023}{2022!} = \frac{2022! \cdot 2023 \cdot 2023}{2022!} = 2023 \cdot 2023$.

4. $2023^2 = 4092529$.

**Ответ:** `4092529`

## Medium

*Тема: Рекурсивные алгоритмы*

### Условие

Алгоритм вычисления функции $F(n)$ задан соотношениями:  $F(n) = n + 3$, если $n   $F(n) = F(n-2) + n$, если $n \ge 3$ и чётно;  $F(n) = F(n-2) + 2 \cdot n$, если $n \ge 3$ и нечётно.  Чему равно значение функции $F(40)$? В ответе запишите только целое число.

### Решение

### Шаг 1

Напишем функцию на Python. Для ускорения используем декоратор `@lru_cache` (хотя для n=40 это не критично, но полезная привычка для ЕГЭ).

```python
from functools import lru_cache

@lru_cache(None)
def F(n):
    if n < 3:
        return n + 3
    if n % 2 == 0:
        return F(n - 2) + n
    else:
        return F(n - 2) + 2 * n
```

### Шаг 2

Вызовем F(40).

```python
print(F(40))
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Код решения.

**Ручной способ:**

1. Развернем рекурсию для четных чисел. $F(40) = F(38) + 40$. $F(38) = F(36) + 38$. 
Это арифметическая прогрессия.

2. $F(n) = F(n-2) + n$. 
$F(40) = 40 + 38 + 36 + \dots + 4 + F(2)$.
$F(2) = 2 + 3 = 5$ (т.к. $2 < 3$).
Сумма четных от 4 до 40: $\frac{4+40}{2} \cdot 19 = 22 \cdot 19 = 418$.
Ответ: $418 + 5 = 423$.

**Ответ:** `423`

## Hard

*Тема: Рекурсивные алгоритмы*

### Условие

Алгоритм вычисления функции $F(n)$ задан соотношениями:   $F(0) = 0$;  $F(n) = F(n/3)$, если $n > 0$ и $n$ делится на 3;  $F(n) = 1 + F(n-1)$, если $n > 0$ и $n$ не делится на 3.   Сколько существует таких чисел $n$, что $1 \le n \le 1000$, для которых $F(n) = 4$? В ответе укажите только число.

### Решение

### Шаг 1

Напишем функцию `F(n)` на Python. Лимит рекурсии можно не менять, так как глубина небольшая (деление на 3 быстро уменьшает аргумент).

```python
def F(n):
    if n == 0: return 0
    if n % 3 == 0:
        return F(n // 3)
    else:
        return 1 + F(n - 1)
```

### Шаг 2

Запустим перебор `n` в цикле `range(1, 1001)` и посчитаем подходящие.

```python
count = 0
for n in range(1, 1001):
    if F(n) == 4:
        count += 1
print(count)
```

---

### Альтернативные решения

**Решение программой (Python):**

1. Полный код.

**Ручной способ (Анализ):**

1. Функция считает сумму цифр в троичной системе счисления? Проверим.
Если $n$ делится на 3 (заканчивается на 0 в троичной), то $F(n) = F(n/3)$ (сдвиг вправо, удаление 0). Значение не меняется.
Если не делится (1 или 2), то $F(n) = 1 + F(n-1)$. Мы вычитаем 1 и прибавляем к результату 1. 
Это похоже на подсчет суммы цифр? Нет. 
Это похоже на подсчет количества единиц и двоек, но хитрым способом. 
$n=1 (1_3) -> F(1)=1+F(0)=1$.
$n=2 (2_3) -> F(2)=1+F(1)=2$.
$n=3 (10_3) -> F(3)=F(1)=1$.
$n=4 (11_3) -> F(4)=1+F(3)=2$.
$n=5 (12_3) -> F(5)=1+F(4)=3$.
Логика: операция $F(n/3)$ 'съедает' ноль на конце. Операция $1+F(n-1)$ уменьшает число на 1 и добавляет счетчик. 
По сути, это сумма цифр в троичной записи числа. 
$F(10_3) = 1$. $F(11_3) = 1+1=2$. $F(12_3) = 1+2=3$. 
Нам нужно $F(n)=4$. Значит, сумма цифр в троичной системе равна 4.

2. Ищем числа до 1000, сумма троичных цифр которых равна 4. 
$1000_{10} = 1101001_3$ (примерно $3^6=729$, $3^7=2187$. Значит до 6-7 разрядов). 
Максимальное число 1101001 ($1 \cdot 729 + 1 \cdot 243 + \dots$). 
Перебор вариантов (4=2+2, 4=1+1+1+1 и т.д.) сложен. Проще программой.

**Ответ:** `30`
