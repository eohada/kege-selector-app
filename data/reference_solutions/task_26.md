## Easy

*Тема: Обработка данных (сортировка)*

### Условие

В магазине проходит акция: при покупке товаров на сумму более N рублей покупатель получает скидку. Товары сортируются по цене. На самые дорогие K товаров предоставляется скидка 20%, на остальные — 10%. (Условие упрощено для примера).  В файле записаны: число N (количество товаров) и сами цены. Определите максимальную сумму скидки, которую можно получить.

### Решение

### Шаг 1

Считываем данные. Первое число — количество. Остальные — в список.

```python
with open('26_easy.txt') as f:
    lines = f.readlines()
    n = int(lines[0])
    prices = [int(x) for x in lines[1:]]
    prices.sort() # Сортируем по возрастанию
```

### Шаг 2

Допустим, по условию скидка на `n // 3` самых дорогих товаров. Берем срез `prices[-(n//3):]` и считаем скидку 20%. Для остальных — 10%.

```python
k = n // 3
expensive = prices[-k:]
cheap = prices[:-k]
discount = sum(expensive) * 0.2 + sum(cheap) * 0.1
print(int(discount))
```

---

### Альтернативные решения

**Решение в Excel:**

1. Скопируйте цены в столбец A. Отсортируйте (Данные -> Сортировка -> По убыванию).

2. Выделите первые K ячеек (самые дорогие). Посчитайте их сумму и умножьте на 0.2.

3. Посчитайте сумму остальных (ниже) и умножьте на 0.1. Сложите результаты.

**Решение программой (Python):**

1. Код выше.

**Ответ:** `2364088`

## Medium

*Тема: Обработка данных (сортировка)*

### Условие

В файле содержится информация о заявках на проведение мероприятий в конференц-зале. Для каждой заявки указаны время начала и время окончания. В один момент времени может проходить только одно мероприятие (интервалы не должны пересекаться, границы могут касаться).  Определите максимальное количество мероприятий, которые можно провести.

### Решение

### Шаг 1

Классическая задача на выбор отрезков. Жадный алгоритм: всегда выгоднее выбирать мероприятие, которое <strong>заканчивается раньше всех</strong> (чтобы оставить больше места для следующих).

```python
events = []
with open('26_events.txt') as f:
    n = int(f.readline())
    for line in f:
        start, end = map(int, line.split())
        events.append((start, end))

# Сортируем по времени ОКОНЧАНИЯ (второй элемент кортежа)
events.sort(key=lambda x: x[1])
```

### Шаг 2

Проходим по списку и берем заявку, если она не пересекается с предыдущей взятой.

```python
count = 0
last_end = -1

for start, end in events:
    if start >= last_end: # Если начало >= конца предыдущего
        count += 1
        last_end = end # Обновляем время окончания

print(count)
```

C1 = 1 (первое всегда берем).
C2 = ЕСЛИ(A2 >= (время окончания последнего взятого); 1; 0).

## Hard

*Тема: Обработка данных (сортировка)*

### Условие

В камере хранения $K$ ячеек. Приходят пассажиры сдавать багаж на определенное время (start, end). Багаж кладется в ячейку с  минимальным номером , которая свободна в момент `start`.  Определите, сколько багажа будет принято и номер ячейки, в которую положат последний принятый багаж.

### Решение

### Шаг 1

Здесь нам выгодно брать пассажиров, которые приходят РАНЬШЕ (сортировка по Start). 
Создадим список ячеек: `cells = [0] * K`. В `cells[i]` будем хранить время, когда ячейка освободится.

```python
with open('26_hard.txt') as f:
    params = f.readline().split()
    K = int(params[0])
    N = int(params[1])
    luggage = []
    for line in f:
        luggage.append(list(map(int, line.split())))

# Сортируем по времени прихода (start)
luggage.sort(key=lambda x: x[0])
```

### Шаг 2

Проходим по пассажирам. Для каждого ищем первую ячейку (с мин индексом), которая свободна (`cells[j] < start`). Если нашли — обновляем время освобождения (`cells[j] = end + 1`? Нет, обычно `end` — время, когда забирают, значит свободна она с `end + 1` или `end`). Уточните условие (в данную минуту еще занято или уже свободно). Допустим, `end` — минута, когда багаж ЕЩЕ там. Свободна с `end + 1`.

```python
cells = [0] * K
count = 0
last_cell_idx = 0

for start, end in luggage:
    for j in range(K):
        if cells[j] < start: # Ячейка освободилась ДО прихода пассажира
            cells[j] = end # Теперь она занята до end
            count += 1
            last_cell_idx = j + 1 # Номер ячейки (1..K)
            break

print(count, last_cell_idx)
```
