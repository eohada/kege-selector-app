## Easy

*Тема: Обработка последовательностей*

### Условие

В файле содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от -10 000 до 10 000 включительно.  Определите и запишите в ответе сначала количество пар элементов последовательности, в которых хотя бы одно число делится на 3, затем максимальную из сумм элементов таких пар.  В данной задаче под парой подразумевается два подряд идущих элемента последовательности.

### Решение

### Шаг 1

Считываем данные из файла в список. Используем генератор списков или map.

```python
with open('17_easy.txt') as f:
    nums = [int(x) for x in f]
```

### Шаг 2

Проходим по списку, рассматривая пары `(nums[i], nums[i+1])`. Диапазон цикла: `range(len(nums) - 1)`.

```python
ans = []
for i in range(len(nums) - 1):
    a, b = nums[i], nums[i+1]
    # Условие: хотя бы одно делится на 3 (a%3==0 or b%3==0)
    if (a % 3 == 0) or (b % 3 == 0):
        ans.append(a + b)
```

### Шаг 3

Выводим количество найденных пар (`len(ans)`) и максимальную сумму (`max(ans)`).

```python
print(len(ans), max(ans))
```

### Альтернативные решения

**Решение программой (Python):**

1. Полный код.

**Ответ:** `3291 19156`

## Medium

*Тема: Обработка последовательностей*

### Условие

В файле содержится последовательность целых чисел. Элементы последовательности могут принимать целые значения от -10 000 до 10 000 включительно.  Определите количество пар, в которых сумма элементов пары делится на минимальный элемент последовательности, кратный 19. Затем запишите максимальную из сумм элементов таких пар.

### Решение

### Шаг 1

Сначала найдем 'глобальное' число — минимальный элемент, кратный 19.

```python
with open('17_medium.txt') as f:
    nums = [int(x) for x in f]

# Фильтруем и находим минимум
min_19 = min([x for x in nums if x % 19 == 0])
```

### Шаг 2

Теперь проходим по парам и проверяем условие: сумма пары делится на `min_19`.

```python
ans = []
for i in range(len(nums) - 1):
    pair_sum = nums[i] + nums[i+1]
    if pair_sum % min_19 == 0:
        ans.append(pair_sum)

print(len(ans), max(ans))
```

## Hard

*Тема: Обработка последовательностей*

### Условие

В файле содержится последовательность целых чисел. Определите количество  четвёрок  элементов последовательности, в которых:   Ровно три числа больше 500;  Сумма всех четырёх чисел не превышает максимальное число в последовательности, оканчивающееся на  29 .   В ответе запишите количество таких четвёрок и максимальную из их сумм.

### Решение

### Шаг 1

Находим контрольное число: макс элемент, оканчивающийся на 29. Используем `str(x)` или `abs(x) % 100`.

```python
with open('17_hard.txt') as f:
    nums = [int(x) for x in f]

max_29 = max(x for x in nums if str(x).endswith('29'))
# Или математически для отрицательных: abs(x) % 100 == 29 (осторожно с отриц)
```

### Шаг 2

Перебираем четверки. Индекс до `len(nums) - 3`.

```python
ans = []
for i in range(len(nums) - 3):
    # Срез четверки
    quad = nums[i:i+4]
    
    # Условие 1: Ровно три > 500
    cnt_500 = 0
    for x in quad:
        if x > 500: cnt_500 += 1
    
    # Условие 2: Сумма <= max_29
    if cnt_500 == 3 and sum(quad) <= max_29:
        ans.append(sum(quad))

print(len(ans), max(ans))
```
