## Easy

*Тема: Обработка целых чисел*

### Условие

Назовем маской числа последовательность цифр, в которой также могут встречаться следующие символы:   символ «?» означает ровно одну произвольную цифру;  символ «*» означает любую последовательность цифр произвольной длины (в том числе пустую).   Найдите все натуральные числа, не превышающие $10^{10}$, которые соответствуют маске  1?215*4  и делятся на  2024  без остатка.  В ответе запишите в первом столбце найденные числа в порядке возрастания, а во втором столбце — соответствующие им результаты деления этих чисел на 2024.

### Решение

### Шаг 1

Перебирать все числа до $10^{10}$ слишком долго. Но нам нужны только числа, кратные 2024. Поэтому будем перебирать `range(2024, 10**10, 2024)`.

```python
from fnmatch import fnmatch

for x in range(2024, 10**10, 2024):
    if fnmatch(str(x), '1?215*4'):
        print(x, x // 2024)
```

## Medium

*Тема: Обработка целых чисел*

### Условие

Найдите 5 чисел, больших 500 000, таких, что сумма их  наибольшего  и  наименьшего  нетривиальных делителей (не считая 1 и самого числа) кратна 17.  Если у числа нет нетривиальных делителей, оно не учитывается.  В ответе запишите найденные числа и соответствующие суммы делителей.

### Решение

### Шаг 1

Напишем функцию поиска нетривиальных делителей. Перебор до квадратного корня.

```python
def get_divs(n):
    divs = set()
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            divs.add(i)
            divs.add(n // i)
    return sorted(divs)

count = 0
n = 500001
while count < 5:
    d = get_divs(n)
    if d:
        min_d = d[0]
        max_d = d[-1]
        s = min_d + max_d
        if s % 17 == 0:
            print(n, s)
            count += 1
    n += 1
```

## Hard

*Тема: Обработка целых чисел*

### Условие

Найдите все числа из диапазона [210 000; 285 000], у которых количество  чётных  делителей не меньше 120.  В ответе для каждого найденного числа запишите количество его чётных делителей и наибольший из них.

### Решение

### Шаг 1

Перебор диапазона. Для каждого числа ищем все делители, фильтруем четные.

```python
for i in range(210000, 285001):
    even_divs = []
    for d in range(1, int(i**0.5) + 1):
        if i % d == 0:
            # d - первый делитель
            if d % 2 == 0: even_divs.append(d)
            # i//d - второй делитель
            d2 = i // d
            if d2 != d and d2 % 2 == 0:
                even_divs.append(d2)
    
    if len(even_divs) >= 120:
        print(len(even_divs), max(even_divs))
```
