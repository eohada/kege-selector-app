# Исправление блока "Работ" - Начало выполнения

## Проблема
После нажатия кнопки "Начать выполнение" ничего не происходило. В консоли браузера видели:
- `POST /submissions/2/start` → **500 Internal Server Error**
- `SyntaxError: Unexpected token '<', "<DOCTYPE ... is not valid`

Ошибка 500 означает, что сервер возвращал HTML вместо JSON, а JavaScript пытался распарсить HTML как JSON.

## Решение

### 1. Backend (app/assignments/routes.py)

#### Функция `submission_start()` (строка 1589)
- **Добавлен**: `try-except` блок для ловли всех исключений
- **Добавлено**: Подробное логирование на каждом шаге:
  - Логирование начала операции
  - Логирование каждой проверки
  - Логирование успешного сохранения
- **Добавлена**: обработка ошибок БД с `db.session.rollback()`
- **Результат**: Теперь любые ошибки (БД, доступ, статус) вернут JSON с `500` и описанием ошибки вместо HTML ошибки

#### Функция `submission_submit()` (строка 1710)
- **Добавлен**: `try-except` блок для всей функции
- **Добавлено**: обработка исключений в основной логике
- **Улучшено**: обработка ошибок с откатом транзакции

### 2. Frontend (templates/submission_view.html)

#### Обработчик кнопки "Начать выполнение" (строка 430)
Улучшено:
- **Логирование**: `console.log()` на каждом этапе
- **Обработка статусов**: проверка `response.ok` перед парсингом JSON
- **Деталированная ошибка**: если сервер вернет ошибку, показываем HTTP статус
- **Обратная связь**: кнопка блокируется при клике и показывает "Загрузка..."
- **Обработка исключений**: `.catch()` с информативным сообщением об ошибке

#### Обработчик кнопки "Сдать работу" (строка 486)
Аналогично улучшены:
- Логирование на консоль
- Обработка HTTP ошибок
- Блокировка кнопки при клике
- Показ результата (оценка, процент)
- Информативные сообщения об ошибках

## Как тестировать

1. **Откройте браузер** с F12 (инструменты разработчика)
2. **Перейдите на страницу работы** в статусе "ASSIGNED"
3. **Нажмите "Начать выполнение"**
4. **Проверьте консоль** (вкладка Console):
   - Должны появиться логи вроде "Starting submission...", "Found submission..."
   - При успехе: "Successfully committed submission X"
   - При ошибке: детальное описание проблемы

5. **Проверьте сеть** (вкладка Network):
   - Запрос должен вернуть `200` и JSON типа:
     ```json
     {"success": true, "started_at": "2026-01-29T10:30:45"}
     ```

## Возможные причины ошибок (теперь будут в логах)

1. **`Доступ запрещен`** - Student ID не совпадает
2. **`Работа уже начата или сдана`** - Неверный статус (не ASSIGNED)
3. **`Дедлайн истек`** - Время истекло и `hard_deadline=True`
4. **Любая другая ошибка** - Будет в логе с `exc_info=True` (полный стектрейс)

## Файлы изменены

- `templates/submission_view.html` - обработчики событий кнопок
