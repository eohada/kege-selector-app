Описание задачи

Задание №5 из ЕГЭ по информатике направлено на проверку навыков выполнения простейших алгоритмов.[cite: 628] Это базовое задание, на решение которого отводится 4 минуты.[cite: 629, 634] Суть задачи обычно сводится к тому, что некий алгоритм принимает натуральное число N, преобразует его в новую систему счисления (чаще всего в двоичную), производит манипуляции со строкой и переводит результат обратно в десятичное число R.[cite: 635, 636, 640]

Базовые операции в Python для 5 задания

1. Перевод в двоичную запись и обратно

Для перевода числа в двоичную систему используется встроенная функция bin().[cite: 747] Она возвращает строку вида '0b101', где '0b' — технический префикс.[cite: 747] Чтобы избавиться от него, мы применяем срез [2:].[cite: 748]

n = 5
s = bin(n)[2:] # Результат: '101'

Для обратного преобразования строки с двоичной записью в десятичное число используется функция int(строка, основание).[cite: 763, 764]

r = int('101', 2) # Результат: 5

Продвинутые техники (Мастхэв для ЕГЭ)

Гайд по срезам (Slices)

Срезы в Python — это мощный инструмент для извлечения части строки (или списка). Общий синтаксис среза выглядит так: строка[start:stop:step].

  • start — индекс, с которого начинается срез (включительно).
  • stop — индекс, на котором срез заканчивается (не включительно).
  • step — шаг, с которым извлекаются элементы.

Примеры использования:

s = "0123456789"
print(s[2:])    # "23456789" (от индекса 2 до конца)
print(s[:4])    # "0123" (от начала до индекса 4, не включая 4)
print(s[-2:])   # "89" (два последних символа)
print(s[:-1])   # "012345678" (вся строка кроме последнего символа)
print(s[::-1])  # "9876543210" (строка задом наперед, шаг -1)

Перевод в любую систему счисления (Кастомная функция)

Если в задании просят перевести число не в двоичную, а, например, в 7-ичную, 3-ичную или 5-ичную систему, функция bin() уже не поможет. Нужно написать свою функцию на основе алгоритма деления "уголком".

def perevod(n):
    t = ''
    while n > 0:
        t += str(n % 7)  # Получаем остаток (младшую цифру)
        n //= 7          # Отсекаем обработанный разряд
    return t[::-1]       # Разворачиваем строку с помощью среза

Объяснение: Мы в цикле делим число n на основание системы (в данном случае 7). Остаток от деления — это очередная цифра нового числа. Но так как при делении столбиком мы получаем цифры с конца (от младших к старшим), итоговую строку t перед возвратом обязательно нужно перевернуть задом наперед с помощью среза [::-1].

Подсчет суммы цифр в строке: sum(map(int, s))

Иногда по условию задачи требуется найти сумму цифр в получившемся числе или строке. Чтобы не писать громоздкие циклы, используется элегантная конструкция sum(map(int, s)).

N2 = "101102"
c = sum(map(int, N2)) # Результат: 5

Как это работает: Функция map(int, N2) берёт строку N2, разбивает её на отдельные символы ('1', '0', '1'...) и к каждому применяет функцию int(), превращая их в числа. Затем функция sum() просто складывает получившийся набор чисел.

Разбор типовой задачи

Условие: Алгоритм принимает натуральное число N. Сначала определяется его двоичная запись.[cite: 635, 636] Затем:
• Если N чётное, в начало записи добавляется "10".[cite: 638]
• Если N нечётное, в начало добавляется "1", а в конец "01".[cite: 639]
Найдите минимальное натуральное число N, для которого результат R больше 516.[cite: 642]

Решение на Python:

Код выполняет последовательный перебор чисел, применяя алгоритм и проверяя выполнение условия R > 516.[cite: 735] Такой подход гарантирует нахождение минимального значения.[cite: 736]

def transform(num):[cite: 660]
    binary = bin(num)[2:][cite: 662]
    
    if num % 2 == 0:[cite: 663]
        result = "10" + binary[cite: 664, 666]
    else:[cite: 665]
        result = "1" + binary + "01"[cite: 667]
        
    return int(result, 2)[cite: 668]

n = 1[cite: 670]
while True:[cite: 671]
    r = transform(n)[cite: 672]
    if r > 516:[cite: 673]
        print("Минимальное число n:", n)[cite: 675]
        break[cite: 676]
    n += 1[cite: 677]

После запуска программы вычисляется минимальное значение N, для которого R > 516. Результат: N = 65.[cite: 737]

Ответ: 65[cite: 738]
