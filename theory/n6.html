Задание 6: Алгоритмы для Исполнителей (Turtle)

Задание 6 проверяет навыки анализа геометрических фигур, создаваемых алгоритмом. В Python это задание решается с помощью встроенной библиотеки turtle. Основная цель — определить количество целочисленных точек внутри или на границе фигуры.

1. Подготовка холста и базовая настройка

Для корректного решения на ЕГЭ важно учитывать, что стандартная Черепашка смотрит вправо (на восток), а в задачах она часто должна смотреть вверх (на север).

from turtle import *

tracer(0)  # Отключает анимацию (рисует мгновенно)
left(90)   # Поворот вверх, чтобы соответствовать условию задач
k = 30      # Масштаб (Scale) — увеличиваем рисунок в 30 раз

2. Основные команды исполнителя

Команда Описание
forward(n * k) Пройти вперед на n шагов (с учетом масштаба k)
back(n * k) Пройти назад
right(angle) Поворот по часовой стрелке на угол
left(angle) Поворот против часовой стрелки
penup() / pendown() Поднять/опустить хвост (не рисовать/рисовать линию)
Внимание: Все перемещения forward, back и goto обязательно умножаются на коэффициент k. Углы поворота умножать нельзя!

3. Отрисовка сетки точек

Чтобы посчитать количество точек с целыми координатами, необходимо нарисовать их поверх основной фигуры.

penup()
for x in range(-20, 20):
    for y in range(-20, 20):
        goto(x * k, y * k)
        dot(3, 'blue') # Рисуем точку размером 3
update() # Принудительно обновляем экран, если tracer(0)

4. Алгоритм решения задачи

  1. Импортируем всё из turtle.
  2. Устанавливаем tracer(0) для скорости.
  3. Задаем масштаб k (обычно 20–40, в зависимости от координат в задаче).
  4. Переписываем цикл из условия задачи (используем for).
  5. Поднимаем перо и рисуем сетку из точек вложенным циклом.
  6. Считаем точки визуально или (если область сложная) проверяем принадлежность математически.
Совет по оптимизации: Если область очень большая, вместо визуального подсчета используйте списки координат или логические условия if, чтобы проверить, попадает ли точка (x, y) в заданные границы.

5. Полный шаблон кода для ЕГЭ

from turtle import *

k = 30
tracer(0)
left(90)
down()

# Пример алгоритма из задачи:
for i in range(7):
    forward(10 * k)
    right(120)

penup()
for x in range(-5, 15):
    for y in range(-15, 5):
        goto(x * k, y * k)
        dot(4, 'red')

done() # Чтобы окно не закрывалось

6. Чек-лист проверки

  • Умножен ли каждый шаг forward на k?
  • Выставлено ли начальное направление (left(90))?
  • Достаточно ли большой диапазон в циклах range для отрисовки всех точек?
  • Включен ли tracer(0) для моментального вывода?
  • Внимательно ли прочитано условие: нужно считать точки внутри или на границе тоже?
