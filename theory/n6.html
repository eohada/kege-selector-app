Решение задания №6 ЕГЭ по информатике: Черепаха с Python

Описание задачи

Задание №6 из ЕГЭ по информатике 2025 года направлено на проверку навыков работы с простейшими алгоритмами управления исполнителями.[cite: 967] Это базовое задание, на решение которого отводится около 4 минут.[cite: 971] Исполнитель «Черепаха» перемещается по плоскости с декартовой системой координат.[cite: 973]

Важные начальные условия Черепахи:

  • Находится в точке с координатами (0, 0).[cite: 974]
  • Её голова направлена вдоль положительного направления оси OY (вверх).[cite: 974]
  • Хвост по умолчанию опущен, она оставляет след при движении.[cite: 974]

Шаг 1 Настройка холста и Черепахи

Начинаем код с подключения библиотеки, задания размеров окна и установки начального направления черепашки вверх.[cite: 1087] Для удобства масштабирования задаем коэффициент k = 10.[cite: 1051, 1106] Обязательно используем tracer(0), чтобы фигура рисовалась мгновенно.[cite: 1061, 1110]

from turtle import *[cite: 1053, 1098]

k = 10                 # Коэффициент масштаба[cite: 1057, 1106]

left(90)   # Устанавливаем направление вверх (по оси OY)[cite: 1060, 1108]

pendown()  # Опустить хвост, начать рисовать[cite: 1061, 1111]

Поднимаем хвост, чтобы перескочить на новую позицию без рисования линий, выполняем команды смещения и снова опускаем перо.[cite: 1129, 1130] Затем рисуем второй (более вытянутый) прямоугольник.[cite: 1152, 1171]

Шаг 4 Отрисовка сетки точек

Чтобы посчитать точки с целыми координатами внутри пересечения, необходимо замостить рабочую область точками красного цвета.[cite: 1172, 1173] Вложенные циклы for перебирают координаты x и y.[cite: 1183, 1184]

penup()[cite: 1079, 1182]
for x in range(-10, 60):  # Перебираем X[cite: 1081, 1186]
    for y in range(-10, 100): # Перебираем Y[cite: 1082, 1186]
