Решение задания №2 ЕГЭ по информатике: Таблицы истинности

Базовые логические операции и их запись в Python

Для успешного решения задания программным методом необходимо знать, как основные математические логические операции транслируются в код на языке Python. В алгебре логики 1 означает ИСТИНА (True), а 0 — ЛОЖЬ (False).

  • Логическое умножение (Конъюнкция, «И», ∧). Возвращает истину только если оба высказывания истинны. В Python реализуется оператором and. Пример: 1 and 0 вернет 0.
  • Логическое сложение (Дизъюнкция, «ИЛИ», ∨). Возвращает истину, если хотя бы одно высказывание истинно. В Python это оператор or. Пример: 1 or 0 вернет 1.
  • Отрицание (Инверсия, «НЕ», ¬). Меняет значение на противоположное. В Python записывается как not. Пример: not 1 вернет False (что эквивалентно 0).
  • Импликация (Следование, →). Ложна только в одном случае: когда из истины (1) следует ложь (0). В Python её можно элегантно заменить оператором меньше или равно: <=. Пример: 1 <= 0 вернет False.
  • Эквивалентность (Тождество, ≡). Истинна, когда оба высказывания равны друг другу (оба нули или оба единицы). В Python выражается оператором сравнения ==.

Шаг 1. Пишем программу для построения полной таблицы

Суть программного решения — заставить компьютер перебрать все возможные комбинации нулей и единиц для четырёх переменных. Для этого мы используем вложенные циклы for.

print('x y z w') # Выводим заголовок для удобства чтения
# Перебираем все возможные значения (0 и 1) для каждой переменной
for x in range(2):
    for y in range(2):
        for z in range(2):
            for w in range(2):
                # Аккуратно переписываем функцию из задания на Python.
                # Обязательно берем каждую логическую скобку в дополнительные скобки ()
                F = not (x <= z) or (y == w) or y
                
                # По условию задачи нас интересуют только те строки, где F = 0
                if F == 0:
                    print(x, y, z, w)

Объяснение кода: Функция range(2) генерирует последовательность чисел от 0 до 1, что идеально подходит для логических переменных. В строке вычисления F мы заменили импликацию (→) на <=, эквивалентность (≡) на ==, а логическое «ИЛИ» (∨) на or.

Шаг 2. Анализ вывода программы

Запустив этот скрипт, мы получим в консоли следующий результат:

1 0 1 0
1 0 1 1

Мы получили ровно три строки. Это значит, что наша сгенерированная таблица полностью соответствует по размеру таблице из условия. Теперь начинается этап логического сопоставления.

Анализ столбцов и сопоставление

1 Анализируем столбцы в нашей полученной таблице:

  • В столбце x находятся только единицы: три 1.
  • В столбце y находятся только нули: три 0.
  • В столбце z: две 1 и один 0.
  • В столбце w: две 1 и один 0.

2 Смотрим на таблицу из задания:

  • Посмотрим на Переменную 1: там уже стоят три единицы. Никакой другой столбец из нашего вывода не содержит трех единиц, кроме x. Значит, Переменная 1 — это x.
  • Посмотрим на Переменную 2: в ней есть одна единица (во второй и третьей строке) и один ноль. Из оставшихся переменных (y, z, w) нули и единицы есть только у z и w. Переменная y состоит только из нулей. Смотрим на таблицу из задания: в столбце "Переменная 3" уже есть 0 и 1, значит это не y. Единственный столбец, в который можно поставить три нуля — это Переменная 4. Значит, Переменная 4 — это y.
  • Осталось разделить z и w между 2 и 3 столбцами. Посмотрим на строки вывода нашей программы: там есть уникальная строка 1 0 0 1 (где z=0, w=1). Смотрим в таблицу задания: первая строка имеет вид 1 0 _ _. Так как y=0 стоит в 4 столбце, эта строка выглядит так: 1 (П2) (П3) 0(y). Единственная подходящая строка из нашего кода — это x=1, z=0, w=1, y=0. Значит, на месте Переменной 2 стоит 0, а на месте Переменной 3 стоит 1. Следовательно, Переменная 2 — это z, а Переменная 3 — это w.
