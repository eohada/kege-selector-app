Решение задания №3 ЕГЭ по информатике: Базы данных в Excel

Описание задания и теория баз данных

Задание №3 из ЕГЭ по информатике 2025 года проверяет умение работать с реляционными базами данных в Excel[cite: 34]. В этом задании требуется находить и анализировать информацию с помощью встроенных функций и формул[cite: 35]. Оно относится к базовому уровню сложности, и на его выполнение отводится примерно 3 минуты[cite: 39].

Основные понятия:

  • База данных (БД) — организованное хранилище данных, позволяющее эффективно их сохранять, управлять и извлекать[cite: 101].
  • Первичный ключ — однозначно определяет строку в таблице[cite: 106].
  • Внешний ключ — связывает записи разных таблиц, указывая на первичный ключ другой таблицы[cite: 106].

Типы связей между таблицами[cite: 107]:

  • Один к одному (1:1): Каждая запись в одной таблице может быть связана только с одной записью в другой таблице, и наоборот[cite: 109].
  • Один ко многим (1:N): Одна запись в первой таблице может быть связана с несколькими записями во второй таблице, но каждая запись во второй таблице может быть связана только с одной записью в первой[cite: 112]. (Именно этот тип чаще всего встречается в задании 3).
  • Многие ко многим (M:N): Записи в обеих таблицах могут быть связаны с несколькими записями в другой таблице[cite: 114].

Функция ВПР (VLOOKUP)

Функция ВПР находит заданное значение в первом столбце диапазона данных и возвращает соответствующее значение из другого столбца той же строки[cite: 124, 125]. Функция работает только по вертикали (строкам)[cite: 126].

Синтаксис функции: =ВПР(Искомое_значение; Диапазон_таблицы; Номер_столбца; [Тип_совпадения]) [cite: 127]

  • Искомое_значение — значение, которое нужно найти[cite: 130].
  • Диапазон_таблицы — область данных, в которой выполняется поиск (искомые значения должны быть в первом столбце)[cite: 133].
  • Номер_столбца — номер столбца диапазона, из которого возвращается результат[cite: 134].
  • Тип_совпадения — всегда используйте ЛОЖЬ (или 0) для точного совпадения[cite: 135, 136].

Разбор реального задания из демоверсии ФИПИ

Задание: Используя данные из базы в Excel, определите общую массу (в кг) всех видов зефира, поступившего в магазины, расположенные на проспекте Мира, за период с 5 по 19 июня 2023 года включительно. В ответе укажите только число (массу в килограммах)[cite: 97, 98].

База данных состоит из трёх таблиц[cite: 42]:

  1. Движение товаров: ID операции, Дата, ID магазина, Артикул, Количество упаковок, Тип операции[cite: 43, 44, 45, 46, 48, 51, 54].
  2. Товар: Артикул, Отдел, Наименование товара, Ед.изм, Количество в упаковке, Цена за упаковку[cite: 56, 58, 59, 60, 61, 62].
  3. Магазин: ID магазина, Район, Адрес[cite: 68, 70, 71, 72].

Шаг 1 Сбор данных в одну таблицу

Оптимально решать задачу, собрав все нужные данные в главной таблице — «Движение товаров»[cite: 154, 155]. Для этого используем функцию ВПР[cite: 156].

В столбец G добавляем Адрес магазина[cite: 162]:

=ВПР(C2; Магазин!A:C; 3; ЛОЖЬ)

Где C2 — ID магазина, 3 — номер столбца с адресом в таблице «Магазин»[cite: 166, 168].

В столбец H добавляем Наименование товара[cite: 184, 185]:

=ВПР(D2; Товар!A:F; 3; ЛОЖЬ)

В столбец I добавляем Единицу измерения[cite: 198]:

=ВПР(D2; Товар!A:F; 4; ЛОЖЬ)

В столбец J добавляем Количество в упаковке[cite: 199]:

=ВПР(D2; Товар!A:F; 5; ЛОЖЬ)

Растяните все формулы вниз двойным щелчком по правому нижнему углу ячеек, чтобы применить ко всему столбцу[cite: 176, 177, 200].

Шаг 2 Расчёт массы упаковок

Нам необходимо рассчитать массу зефира. Если единица измерения указана в граммах, нужно умножить количество упаковок на массу одной упаковки и перевести результат в килограммы (разделив на 1000)[cite: 205, 207]. Если товар измеряется в штуках, результат для нашей задачи равен 0[cite: 208].

В столбец K добавляем формулу[cite: 210, 211]:

=ЕСЛИ(I2="грамм"; J2/1000*E2; 0)

Логика: Проверяем ячейку I2 (Единица измерения)[cite: 218]. Если там "грамм", то делим массу упаковки (J2) на 1000 и умножаем на количество упаковок (E2)[cite: 221, 222]. Иначе возвращаем 0[cite: 223].

Шаг 3 Фильтрация данных

Выделим заголовки таблицы и включим «Фильтр» (вкладка Главная → Сортировка и фильтр)[cite: 234, 235]. Настроим условия[cite: 228]:

  • Дата: оставляем только числа с 5 по 19 июня 2023 года[cite: 229, 258].
  • Тип операции: оставляем только «Поступление»[cite: 231, 276].
  • Адрес магазина: выбираем магазины на проспекте Мира[cite: 232, 280].
  • Наименование товара: отмечаем галочками все виды зефира (в шоколаде, ванильный, воздушный, лимонный)[cite: 233, 301, 312, 313, 314, 315].

Шаг 4 Подсчёт общей массы

После применения всех фильтров останутся только те строки, которые подходят под условие задачи[cite: 326]. Кликните по заголовку столбца K (Масса), чтобы выделить его целиком[cite: 332]. Внизу окна Excel, в строке состояния, автоматически отобразится Сумма[cite: 332].
