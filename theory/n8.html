Задание №8 ЕГЭ по информатике: Упорядоченный список слов

Описание задания

Задание №8 из ЕГЭ по информатике 2025 года направлено на проверку знаний базовых понятий и методов, связанных с измерением количества информации. Для успешного выполнения этого задания требуется понимание ключевых терминов, таких как алфавит сообщения, длина сообщения, мощность алфавита и объём информации. На решение задачи выделяется 4 минуты, что соответствует средней сложности. Пример задания взят из открытого варианта ЕГЭ, опубликованного на сайте ФИПИ.

Условие задачи: Все пятибуквенные слова, составленные из букв русского алфавита: П, А, Р, У, С, записаны в алфавитном порядке и пронумерованы, начиная с 1.

Начало списка выглядит следующим образом:

1. ААААА 2. ААААП 3. ААААР 4. ААААС 5. ААААУ 6. АААПА

Вопрос: Под каким номером в списке идёт последнее слово, которое:
• содержит не более одной буквы «У»;
• не содержит двух букв «А», стоящих подряд.

Полезные советы при решении подобных задач:

1. Различие между мощностью алфавита и длиной сообщения:

  • Мощность алфавита — это количество различных символов, входящих в состав алфавита. В данном случае мощность равна 5 (буквы П, А, Р, У, С).
  • Длина сообщения — это количество символов в слове. Для этой задачи длина сообщения составляет 5 символов.

2. Использование методов работы со строками:

  • Для проверки, содержит ли слово не более одной буквы «У», используйте метод .count('У').
  • Для проверки отсутствия двух подряд идущих букв «А» используйте проверку подстроки "АА" not in слово.

3. Автоматизация перебора с помощью Python:

Встроенная библиотека itertools позволяет быстро и эффективно генерировать все возможные комбинации символов. Используйте функцию itertools.product для перебора всех вариантов слов заданной длины.

4. Оптимизация решения:

  • Сначала создайте отсортированный список всех возможных слов.
  • Затем применяйте фильтрацию по заданным условиям. Это сократит время выполнения задачи, особенно если потребуется перебрать большой объём данных.

Подробное решение задачи на упорядоченный список

Ниже приведён пример программы на Python, которая перебирает все возможные 5-буквенные слова, составленные из букв «ПАРУС», и проверяет каждое слово по заданным условиям. Программа выводит подходящие слова и их порядковые номера: 

from itertools import *

# Инициализируем счётчик
count = 1

# Перебираем все возможные слова
for i in product(sorted("ПАРУС"), repeat=5):
    if i.count("У") <= 1 and "АА" not in "".join(i):
        print("".join(i), count) # Выводим слово и номер
    count += 1

Давайте разберём работу этого кода шаг за шагом.

Шаг 1 Импорт модуля itertools:
Модуль itertools содержит полезные функции для работы с итерациями. В данном случае используется функция product, которая позволяет генерировать все возможные комбинации элементов с повторением.

Шаг 2 Инициализация счётчика:
Переменная count используется для подсчёта и нумерации слов. Начинаем с 1, так как первое слово будет под номером 1.

Шаг 3 Генерация всех возможных 5-буквенных слов:
Здесь создаются все возможные слова длиной 5 букв, используя буквы «П», «А», «Р», «У», «С». Рассмотрим подробнее:
• sorted("ПАРУС") сортирует буквы в алфавитном порядке, возвращая список: ['А', 'П', 'Р', 'С', 'У']. Это нужно для того, чтобы слова генерировались в алфавитном порядке.
• product(..., repeat=5) — генерирует все возможные комбинации длиной 5 символов (с повторением букв).
Примеры первых слов:
• Первое слово — ('А', 'А', 'А', 'А', 'А');
• Второе — ('А', 'А', 'А', 'А', 'П');
• Третье — ('А', 'А', 'А', 'А', 'Р') и так далее.
Всего будет сгенерировано 55 = 3125 слов, так как каждая из 5 букв может занимать 5 позиций.

Шаг 4 Проверка условий для каждого слова:
На каждом шаге проверяется, удовлетворяет ли слово следующим условиям:
• i.count("У") <= 1 — в слове может быть не более одной буквы «У».
• "АА" not in "".join(i) — в слове не должно быть двух подряд идущих букв «А».
Так как i — это кортеж (набор символов), преобразуем его в строку с помощью "".join(i), чтобы проверить наличие подстроки "АА".

Шаг 5 Вывод подходящих слов и их порядковых номеров:
Если слово прошло проверку, оно выводится в виде строки (после преобразования с помощью "".join(i)), а рядом указывается его порядковый номер.

Шаг 6 Увеличение счётчика:
Счётчик увеличивается на 1 в конце каждой итерации, чтобы на следующей итерации присвоить слову корректный порядковый номер.

Как работает программа:

  • На первой итерации генерируется слово ('А', 'А', 'А', 'А', 'А'). Оно не удовлетворяет условиям, так как содержит две подряд идущие буквы «А», поэтому не выводится.
  • На второй итерации генерируется слово ('А', 'А', 'А', 'А', 'П'). Оно также не удовлетворяет условиям, так как содержит две подряд идущие буквы «А».
  • Когда формируется слово ('А', 'П', 'А', 'П', 'А'), оно успешно проходит обе проверки: в нём нет двух подряд идущих букв «А», а количество букв «У» не превышает одной. Так как это слово соответствует заданным условиям, оно выводится на экран с порядковым номером 131.
  • Программа продолжает последовательно перебирать все возможные слова и проверять каждое из них на соответствие заданным условиям. Если слово удовлетворяет критериям, оно отображается на экране вместе с его порядковым номером.

В выведенном на экран списке последнее подходящее слово — «УСССС», и его порядковый номер равен 2969.

Ответ на задачу: 2969
