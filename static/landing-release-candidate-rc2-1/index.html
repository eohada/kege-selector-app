Условие отвечает на вопрос «если»

Условие превращает фразу из задачи в проверку Python. После проверки программа выбирает одну ветку: строки с отступом выполняются только тогда, когда условие истинно.

PYTHONПРИМЕР ИЗ МАТЕРИАЛА
score = int(input())
if score >= 60:
    print('зачёт')
else:
    print('нужно повторить')
Двоеточие открывает веткуОтступ показывает её границы
Важная детальВсе команды одной ветки имеют одинаковый отступ. Это часть синтаксиса Python.
ПРОСЛЕДИМ ВЕТКУПример из условия · локальный разбор
Ввод: 55→нужно повторить
Ввод: 60→зачёт

Границы важнее среднего случая

Для диапазона от 10 до 99 включительно подходят сами 10 и 99. Сравни случаи до границы, на ней и за ней.

10 <= n <= 99включительно

Что искать?Не потерялись ли крайние значения и совпадает ли условие со словами «включительно».

and требует, чтобы сработали обе проверки. Для or достаточно любой одной.
