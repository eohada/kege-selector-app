# ЕГЭ-2027 · Математический фундамент · Статьи 7–12 (v1)

Авторские статьи ChatGPT. Второй и последний пакет первой группы. Не менять уже размещённые статьи №1–6.

## Содержание

- `manifest.json`: схема импорта, тот же course slug и group name, статьи №7–12, все 18 SVG.
- `groups/01-foundation/*.md`: шесть самостоятельных, полноразмерных глав.
- `groups/01-foundation/assets/*.svg`: локальные иллюстрации.
- `CONTENT_AUDIT.json`: фактические размеры, состав и SHA-256 каждого Markdown-источника.
- `LOCAL_QA_REPORT.json`: только локальная **структурная** проверка. Штатный BooStudy/KaTeX validate в авторской среде недоступен и не заявляется выполненным.
- `AGENT_PROMPT_FIXES_AND_IMPORT.md`: полное задание на 4 UI/engine fixes + валидацию/импорт новых глав.

## Порядок для агента

1. Установить нужную dev/staging DB, проверить course.slug/id и существующие №1–6.
2. Штатный `validate` (ожидаем valid=true, latex_checked=true, issues=[]).
3. Штатный `preview` (только новые №7–12; первые 6 не обновлять).
4. `import-draft` без `--overwrite`, если preview не выявил конфликтов.
5. Ручная и автоматическая проверка статьи на desktop/mobile, включая MathLive, подписи, SVG, native GEOMETRY.
6. Никаких публикаций, автоактиваций и назначений учащимся.

## Редакционные решения

- Нет LEVEL: весь материал последовательно виден; renderer при наличии LEVEL скрывает внешний текст.
- В математических `answer` используются полные фигурные скобки LaTeX-дробей.
- В CHECKPOINT только один правильный вариант и стабильные keys.
- Интервальные задачи проверяются через выбор ответа, а не через ещё не полностью оттестированный ввод интервала.
- Подписи новых SVG — отдельный *курсивный* абзац после изображения; буквальное `Подпись:` в этих главах не используется. Отдельный багфикс рендерера для прежних статей обязателен.
- Формулы нормализованы в `\frac{a}{b}` там, где использована команда `\frac`.

Все изменения авторского содержания после импорта — только через согласованную редакцию. Случайно не публиковать материал при исправлении UI или БД.
