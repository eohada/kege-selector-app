# ЕГЭ-2027 · Группа 01 · Часть 1/2 (статьи 01–06)

Авторский Markdown-пакет для штатного CLI-импорта Theory.

- Курс: `ege-profile-math-2027` (сохраняет ключ из первой главы).
- Группа: `Математический фундамент`, position=1.
- В пакете: 6 отдельных статей, номера task_number 1–6.
- Статус всех статей: draft.
- `expected_structure`: **1 группа / 6 статей** — частичный пакет, не полнота всего курса.
- Продолжение группы: статьи 7–12 будут переданы отдельным пакетом; этот пакет их не удаляет.
- Статья 001 сохраняет прежний ключ `real-numbers`: при наличии черновика в **выбранной целевой БД** планируется обновление (после проверки конфликтов); при отсутствии — создание нового черновика. Не предполагать наличие прежней записи в текущей БД.
- Смысловые блоки, CHECKPOINT, INTERACTIVE, STEP_EXERCISE, SVG-изображения используют авторский контракт V1.

## Порядок работы агента

1. Проверить реальные настройки target dev/staging DB.
2. Выполнить `--mode validate`: только при `valid=true`, `latex_checked=true`, `issues=[]` идти дальше.
3. Выполнить `--mode preview`, проверить create/update/conflict и hashes.
4. Если статья 001 уже импортирована и изменилась, не применять `--overwrite` без сравнения со старой утверждённой версией. Не перезаписывать опубликованную статью.
5. Импортировать все статьи только `--mode import-draft`.
6. Проверить MathLive, работоспособность каждого шага, изображения, мобильный экран, отсутствие горизонтального overflow.
7. Не публиковать и не активировать курс без отдельного разрешения.
8. 17 неразобранных legacy failures из исходного QA остаются риском и не закрываются проверкой данного контента.

**Локальная проверка автора:** баланс специальных маркеров, уникальность ключей заданий, форматы SVG/XML, ссылки на все assets, ограничения UTF-8 и файла/manifest. **Штатный валидатор BooStudy, локальный KaTeX и браузерная проверка здесь недоступны и не заявляются как пройденные.**
