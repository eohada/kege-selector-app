Возможности для преподавателей

{{ ui_icon('nav.students', 'sm', decorative=true) }}Управление учениками

Создавайте профили учеников, отслеживайте их прогресс, храните информацию о целях и достижениях. Ведите историю уроков, домашних заданий и результатов. Все данные в одном месте, с удобным поиском и фильтрацией.

{{ ui_icon('nav.schedule', 'sm', decorative=true) }}Расписание и планирование

Удобное календарное расписание с поддержкой московского и томского времени. Массовое создание уроков, автоматическое отслеживание активных занятий, планирование на недели и месяцы вперед.

{{ ui_icon('nav.generator', 'sm', decorative=true) }}Генератор заданий КЕГЭ

Умный подбор заданий из обширной базы данных. Система автоматически исключает уже использованные задания, учитывает пропущенные и заблокированные варианты. Поиск по уникальному ID, фильтрация по типам заданий.

{{ ui_icon('nav.assignments', 'sm', decorative=true) }}Домашние задания и классные работы

Формируйте домашние задания и классные работы прямо на уроке. Добавляйте задания из генератора, отслеживайте статус выполнения, проверяйте результаты. Экспорт в Markdown для удобной работы.

{{ ui_icon('nav.stats', 'sm', decorative=true) }}Аналитика и отчетность

Детальное логирование всех действий, статистика по ученикам, отслеживание использования заданий. Полная история изменений для прозрачности работы и анализа эффективности обучения.

{{ ui_icon('action.export', 'sm', decorative=true) }}Интеграция и экспорт

Экспорт данных в JSON для резервного копирования и миграции. Импорт учеников и уроков из внешних систем. Интеграция с платформами для синхронизации данных.

С чего начать

1️⃣
Добавьте учеников

Перейдите в раздел "Ученики" и создайте профили для ваших учеников. Укажите их цели, уровень подготовки, категорию (ЕГЭ, ОГЭ, программирование, ЛЕВЕЛАП) и другую важную информацию.

2️⃣
Создайте расписание

В разделе "Расписание" запланируйте уроки для ваших учеников. Используйте массовое создание для регулярных занятий. Выбирайте удобный часовой пояс (московский или томский) для корректного отображения времени.

3️⃣
Используйте генератор заданий

В разделе "Генератор" создавайте подборки заданий КЕГЭ для уроков и домашних заданий. Система автоматически исключит уже использованные задания и предложит новые варианты. Ищите задания по уникальному ID.

4️⃣
Ведите уроки и ДЗ

Во время урока добавляйте задания в домашнюю работу или классную работу. Отслеживайте выполнение, проверяйте результаты, ведите заметки о прогрессе учеников.
