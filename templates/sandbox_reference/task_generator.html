Значение арифметического выражения 3 · 5^2026 + 2 · 5^1012 - 5^200 - 100 записали в системе счисления с основанием 5.

Какая цифра чаще всего встречается в этой записи? В ответе укажите количество таких цифр.

ЭТАЛОННОЕ РЕШЕНИЕ (PYTHON) 
# Решение задачи №14 через перевод числа в 5-ричную систему
num = 3 * (5**2026) + 2 * (5**1012) - (5**200) - 100
digits = {}

while num > 0:
    d = num % 5
    digits[d] = digits.get(d, 0) + 1
    num //= 5

print("Ответ:", max(digits.values()))
Правильный ответ: 1826
